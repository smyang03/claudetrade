## 합의 (양측 + 검증 일치)

1. selection 랭킹 층에 검증된 양(+)의 알파 없음 (AUC 0.507, 픽≈풀) — 제거해도 잃을 알파는 측정상 없음.
2. Claude 출구가 유일 실측 강점 (Claude/TARGET/TRAILING net +144.4 양월 양수 vs 자동방어 −214.7) — 매도/보유 전담 유지는 양측 합의.
3. 존하단 "한정" 지정가 격추. 비추격은 기존 존 규율(현재가 −0.5% 하단 존)+슬리피지 캡+cancel_if_open_above로 이미 담보.
4. ATR 룰존 재료 없음(커버리지 27%/21%) — 존 생성을 judge에 남기면 무효화.
5. 체결가품질 레버(존하단 지향 Δ+0.207)는 US 전용, 현 구조에 log-only 배선 완료 — 전환 논거 아님.
6. selection 제거의 토큰 절감 ≈ 월 1만원 = 반올림 오차 — 비용 논거 철회.
7. 룰 직결 후보 스트림의 forward는 gross +0.28(US 상위랭크) < 비용 0.5~0.7 — **이 전환 자체는 흑자 스위치가 아님**(net 중립 구조 정리). LOSS_CAP 좌측꼬리(−165.3)는 어느 쪽에도 남는 별개 문제.
