# 사전등록 초안 — 2027 Q1 후보: US 내부자 군집 시총 구간 차이 (2026-10-31, 미등록)

**상태: 초안이다. 등록은 2027 Q1 분기 창에서 운영자가 정한다**(`docs/operating_model.md` §4, 분기당 새 가설 ≤ 3).
이 문서를 커밋하는 시점까지 구간별 수익률은 계산하지 않았다. 이벤트 파일의 수익 칼럼(ret·iwm·spy·sz·szr)도 읽지 않았다.
등록 전에 바꿀 수 있는 칸은 맨 아래 "운영자 확인"뿐이다. 나머지는 이 초안 문구로 고정한다.

## 이미 알려진 사실 (사후 맞춤 경계)

- 묶음 결과는 이미 공개돼 있다(`k1_us_smartmoney_20260929.md`). U5r_all(재키잉 군집 ≥ 3그룹/30일) H60은 IWM 대비 +1.72%, OOS t 2.86이다. 거래대금으로 나누면 U5 계열의 효과는 **$1~5M에 몰려 있고, $5M 이상에서는 절반 이하로 줄고 t가 사라진다.**
- 그래서 "작은 구간 > 0"을 주 검정으로 두면, 이미 아는 양수와 이미 아는 크기 방향을 다시 확인하는 셈이 된다. **주 검정은 구간 간 차이**로 두고, 구간별 수준은 기술 통계로만 낸다.
- 시총과 거래대금은 상관이 높다(회전율 중앙값 0.95%/일). 이 검정이 거래대금 분할과 독립된 새 정보라고 주장하지 않는다. 새로 묻는 것은 하나뿐이다. **스프레드를 비용에 넣어도 작은 구간의 우위가 남는가.**

## 가설

| 항목 | 값 |
|---|---|
| 메커니즘 | 내부자 정보 우위는 분석가 커버리지가 얇은 소형주에서 크다. 다만 소형주는 스프레드도 커서 비용 후에 우위가 남는지가 문제다 |
| 표본 | `k1_us_20260929/events_U5r_all.csv.gz` 2,461건(2012-01~2026-06). L4 쉐도우의 동결 규칙(`tools/us_insider_cluster_shadow.py`, U5r_all)과 같다. 필터 $3·dv20 ≥ $1M·60세션 dedupe |
| 시총 | 시점 발행주식수 × 신호일 s 종가(수정 전). 주식수는 SEC companyfacts에서 s 전에 filed된 값 중 가장 최근 값이고, end ≥ s−400일이어야 한다. 우선순위는 dei EntityCommonStockSharesOutstanding → CommonStockSharesOutstanding → 가중평균 기본주식수다. 법인 번호(CIK)는 현재 티커 매핑을 쓰고, 누락분은 Form 4 원문의 당시 issuerCik로 보강한다 |
| 구간 경계 | **소형 < $2B** (이 안에서 < $300M·$300M~$2B를 보조로 나눈다) / **중형 $2B~$10B** / 대형 ≥ $10B. 관례 경계다. 고른 근거는 표본 시총 분포(10/50/90% = $243M/$1.14B/$9.9B)와 구간별 건수이고, 성과는 보지 않았다. 물가 조정은 하지 않는다 |
| 비용 | 이벤트별 왕복 = **0.44%(KIS 수수료 실측, 스프레드 미포함) + 스프레드**. 스프레드 = max(AR63, 0.10%)이고, AR63은 s 이전 63거래일 일봉 Abdi–Ranaldo 추정치다. 민감도로 Corwin–Schultz 21일과 AR63×2를 함께 낸다 |
| 진입·보유 | s 다음 세션 시가(t0_filing), H60 종가. L4와 같다 |
| 주 지표 | 이벤트 net 초과 = ret − 비용 − 규모매칭(sz60, dv20 십분위). **주 검정 = 소형 평균 − 중형 평균**이다. 진입일별 차이 계열(두 구간 모두 있는 날)을 Newey-West(lag 60)로 잰 t를 쓴다 |
| 보조 | 구간별 수준(규모매칭·IWM 대비), 소형 내부 두 칸, 대형, 민감도 비용 두 가지. 모두 판정에 넣지 않는다 |
| IS/OOS | IS 2012~2019 / OOS 2020~2026-06. K1과 같은 경계이고 다시 고르지 않는다 |
| 합격 | 차이 t ≥ 2.64 **그리고** IS·OOS 차이가 같은 부호(+) **그리고** 소형 구간 비용 후 IWM 대비 평균 > 0 |
| 기각 | 위 셋 중 하나라도 미달 |
| 검정 불가 | 시총 커버리지 < 85%(전체 89.1%, 판정 표본인 펀드 제외 2,230건 기준 96.6%), 또는 소형·중형 중 한 구간이 IS나 OOS에서 100건 미만 |
| 통과 후 | 실주문 없이 forward 확인 단계로 간다. L4 쉐도우 원장에서 소형 구간만 따로 센다. 만기 30건 시점에 IWM 대비 비용 후 > 0 이고 날짜 클러스터 t ≥ 2이면 L4 소액 단계 진입 시 **소형 우선 배분을 운영자에게 제안**한다. L4 기존 판정 기준(만기 30건, IWM 대비 t ≥ 2)은 바꾸지 않는다 |
| 반대 근거 | ① 거래대금 분할로 방향은 이미 알려져 있다. ② AR63은 46%가 0으로 잘리고 구간 순서가 비단조다(대형 0.21% > 중형 0.00%). 하한 0.10%로 막지만 추정 잡음이 크다. ③ 생존편향: Form 4 당시 심볼 가격 없음 약 41%(K1). 소형일수록 클 가능성이 있다 |
| 환산식 | L4 슬롯 금액 × (소형 비용 후 IWM 대비 초과) × 연 소형 신호 수. 판정 때 쉐도우 실측 건수로 계산한다 |

## forward 확인의 현실 일정

L4 쉐도우(U5r_all, tradable, dedupe 후)는 2026-07~10에 82건이 쌓였다. 월 약 20건이다. 소형(< $2B) 비중이 표본 기준 약 57%이므로 월 약 11건이 들어온다. 만기 30건까지는 등록 후 약 3개월에 H60(약 3개월)을 더해 **약 6개월**이 걸린다. 따라서 이 가설이 L4 배분에 반영되는 것은 빨라도 2027-07 이후다.

## 운영자 확인 (등록 전)

- [ ] Q1 슬롯 3개 중 1개를 이 가설에 쓸지 여부.

**범위 정의 (10-31 확정, 운영자 확인 항목에서 뺐다).** 표본은 SEC SIC 기준 **펀드(SIC 공란·0000 = 40법 등록 CEF·BDC)를 뺀 종목**으로 한다. 펀드는 시총이 순자산이라 구간 개념이 맞지 않는다. 판정 행은 이 정의로 고정한다.
MLP·REIT는 표본에 남기고 보조 행에서 따로 보인다. 근거는 L4 표본(이미 공개된 묶음 성과)을 유형별로 나눈 값이다(H60, IWM 대비 비용 후, 시총 구간은 보지 않음).

| 유형 | n | IWM 대비 (t) | IS ≤ 2019 | OOS 2020~ (t) |
|---|---|---|---|---|
| 전체(K1 재현) | 2,461 | +1.72% (3.03) | +0.99% | +2.45% (2.86) |
| 운영회사 | 1,990 | +1.86% (3.14) | +1.26% | +2.43% (2.60) |
| 펀드(BDC·CEF) | 231 | +1.85% (2.45) | +1.01% | +2.72% (2.48) |
| REIT | 181 | +0.58% (0.47) | +1.37% | −0.18% (−0.12) |
| MLP | 59 | +1.11% (0.34) | −6.31% | +10.02% (5.00) |

펀드는 운영회사와 성과 수준이 같다. 그래서 L4에서 펀드를 걸러낼 근거는 없고, L4 동결 규칙은 바꾸지 않는다. 이번 판정에서 빼는 이유는 성과가 아니라 시총 정의다. REIT의 약세는 결과를 본 뒤 나온 관찰이라 필터로 쓰지 않는다. 재현: `scripts/q1_fund_split.py`.
