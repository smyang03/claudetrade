# US 매매비용 절감 경로 조사 (2026-09-30)

범위: 웹 조사와 저장소 읽기만 했다. 코드·config 변경, 주문, 계좌 조회는 하지 않았다. 확인하지 못한 항목은 **미확인**으로 표시했다.

## 결론

1. 현재 비용 대부분은 **KIS 위탁수수료(편도 0.25%)**다. FX는 이미 0이고(USD 잔고 회전), 수수료 외 항목은 이 규모에서 잡음 수준이다. 비용을 줄이려면 수수료율을 바꿔야 한다.
2. 수수료만 보면 더 싼 곳이 있다. LS 이벤트 0.065%(2026년 재개 여부 미확인), 키움 이벤트 0.07%, 토스 0.1%(프로모션 여부 미확인) 순이다. 하지만 T1 조건인 **"API로 미국 개장 동시호가 주문(LOO 매수 + MOO 매도)"을 문서로 확인한 곳은 KIS뿐이다.** 키움 REST와 토스 오픈API는 미국 주식에 LOO/MOO가 없다. LS는 MTS에서 LOO와 MOO(매도)를 지원하지만 OPEN API 코드값은 미확인이다.
3. 지금 T1에 바로 쓸 수 있는 최저 비용은 **KIS 약 0.50% 왕복**이다. 0.10% 시나리오(t 3.13)에 가장 가까운 후보는 LS(약 0.13%)다. 다만 이벤트 자격과 API의 LOO/MOO 지원을 둘 다 확인해야 한다. 어느 선택지도 t 3.13을 보장하지 않는다.
4. IBKR는 주문 1건이 13만원(약 $94)일 때 최소수수료 $0.35 때문에 **오히려 더 비싸다**(왕복 약 0.75%). 주문 1건이 $140을 넘어야 KIS 0.25%와 같아진다.
5. 저장소 사실 하나를 덧붙인다. KIS LOO/MOO도 API 문서로만 확인됐고, **실체결은 0건**이다(`docs/reports/us_slippage_by_adv_20260928.md` §6). 어느 증권사로 가든 첫 과제는 소액 LOO 체결가와 공식 시가를 비교하는 전향 실측이다.

### 표에 대한 주의

- **키움과 토스는 확정 기각이 아니다.** 개장 전(09:30 ET 이전)에 넣은 DAY 지정가(토스)나 03 시장가(키움)가 개장 동시호가에 참여하는지, 아니면 프리마켓에서 시가가 아닌 가격에 체결되는지는 **미확인**이다. 계좌 없이는 검증할 수 없다. 프리마켓 체결은 백테스트의 open 전제를 깨므로 소액 전향 실측 전에는 쓰면 안 된다.
- 키움은 매도 쪽 MOC가 있다. T1 청산을 MOO에서 MOC로 바꾸면 진입만 남는 문제가 된다. 이것은 전략 변경이므로 운영자가 결정한다.
- LS의 "0.13%"도 0.10% 시나리오와 같지 않다. 판정 t는 해당 요율로 다시 계산해야 한다.

## 환전(FX) — 구조적 절감

- **USD 잔고를 유지하는 방식(현행)**: 거래당 FX 비용이 0이다. 비용은 입금할 때 한 번만 나고, 환율 변동 위험을 떠안는다. 유휴 달러 이자(외화RP 등)를 받을 수 있는지는 **미확인**이다.
- **원화주문·통합증거금**: 매수할 때마다 자동환전하고, 매도대금을 원화로 자동환전하는 설정이면 매도 때도 환전한다. 우대율 80%라면 편도 약 0.2%, 왕복 약 0.4%가 추가돼 수수료만큼 비용이 는다. 원화 자동환전은 **끄고 USD로 남겨야 한다.**
- **일괄 환전**: 증권사 대부분은 우대율을 정규 환전시간(평일 약 09:00~15:30 KST)에만 준다. 시간 외에는 가환율과 넓은 스프레드가 적용된다. 필요한 달러는 월 1회 정도 정규시간에 한꺼번에 환전한다.
- **IBKR로 옮길 때**: 원화를 직접 입금할 수 없어 은행 해외송금 수수료와 환전 스프레드가 추가된다. 100만원 북에서 송금 1회 수수료만 약 1.5~2.5%다(**미확인**, 은행마다 다름).

## 해외 증권사(IBKR) 이용 시 법·세무

- 외국환거래규정 제7-31조에 따르면 거주자가 비거주자로부터 증권을 취득할 때 한국은행 신고 대상이라는 검색 결과가 있다. 해외 증권사 계좌를 통한 개인 투자에 이 조항이 그대로 적용되는지, 예외가 있는지는 **미확인**이다. 전문가나 외국환은행 확인이 필요하다. [한국은행 자본거래 안내](https://www.bok.or.kr/portal/main/contents.do?menuNo=200405)
- 해외금융계좌 신고는 매월 말 잔액이 5억원을 넘을 때만 대상이라 현재 규모와는 무관하다. [국세청](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7819&mi=2513)
- 해외주식 양도세(250만원 공제 후 22%)는 국내 증권사와 같다. 다만 IBKR는 국내 증권사의 양도세 신고대행과 연간 손익 자료를 제공하지 않으므로 직접 계산해 5월에 신고해야 한다(**미확인**: 신고대행 서비스 존재 여부).

## 상위 2개 경로 — 운영자 실행 단계

### A. KIS 유지 + 비용 조정 (현 코드 그대로, 가장 빠름)

1. KIS 앱이나 명세서에서 **현재 USD 환전 우대율**을 확인한다. 원화 자동환전(통합증거금 매도대금)이 꺼져 있는지도 확인한다.
2. KIS 고객센터나 관리지점에 **해외주식 협의수수료**를 문의한다. 이벤트가 없다는 것이 협의가 불가능하다는 뜻은 아니다. 협의요율이 Open API 주문에도 적용되는지 반드시 명시적으로 묻는다.
3. USD 잔고를 유지하고, 필요한 달러는 정규시간에 일괄 환전한다.
4. T1 첫 LOO(32) 매수와 MOO(31) 매도의 체결가를 공식 시가와 비교해 기록한다. 현재 실체결 0건이므로 0.44% 전제의 검증은 여기서 시작된다.

### B. LS증권 계좌 추가 (조건 둘 다 확인되면 왕복 약 0.13%)

1. LS 고객센터에 두 가지를 확인한다. (a) 현재 진행 중인 해외주식 우대 이벤트(과거 "평생 0.065%·USD 92%")의 자격과 2026년 조건, (b) 그 우대요율이 **OPEN API 주문에도 적용되는지**. 2026 OPEN API 이벤트는 국내 상품만 대상이고 채널을 엄격히 나누므로 (b)가 관건이다.
2. OPEN API DevCenter의 `COSAT00301` 명세에서 `OrdprcPtnCode`의 미국 LOO 매수와 MOO 매도 코드값, 접수 가능 시간(MTS 기준 LOO는 07:10~개장 1분 전, MOO는 07:10~개장 31분 전 매도만)을 확인한다.
3. 조건이 모두 충족되면 비대면 계좌를 열고 이벤트에 신청한다. 정규시간에 소액 USD를 환전한다.
4. KIS와 병행해 소액(1주) LOO 매수와 MOO 매도를 전향 실측한다. 체결가와 공식 시가의 차이, 부분체결, 거부를 기록한다. 실측이 통과한 뒤 T1을 옮길지는 운영자가 결정한다. 브로커 추가는 코드 작업(주문·잔고·동기화 어댑터)을 수반한다.

3순위는 조건부로 키움이다. 이벤트 0.07%에 가입할 수 있고, 개장 전 03 시장가 주문이 개장가에 체결되는지 실측으로 확인되거나, 운영자가 청산을 MOC로 바꾸는 경우에만 해당한다.
