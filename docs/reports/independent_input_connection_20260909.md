# 독립 전략 입력 연결 — 2026-09-09

## 실제 완료

- 신규 `collect_independent_research_inputs.py`가 SPY/EFA/IEF/GLD를 yfinance로 수집한다. `auto_adjust=False`를 명시하고 `Adj Close`를 사용하며 원종가·배당·분할·capital gains를 함께 보존한다. 연구용 공급자 조정 가격이며 별도 브로커 가격과 독립 대사한 데이터는 아니다.
- 거래소 달력으로 최근 완결 253세션을 정하고 네 ETF에 동일하게 요구한다. 장중 미완결 봉 제거, 결측/중복/비정상 가격 차단. 조정 가격의 known_at은 이번 수신 시각이다. 과거 시점에 알았던 가격으로 소급하거나 과거 거래 성과로 집계하지 않는다.
- 첫 실제 실행: 4개 ETF 각각253봉 확보. 원장 기준 최종 완결 세션 2026-09-04. 현재 프로세스 시계는 2026-09-08 미국 장중(한국 09-09)이므로 최초 예정 개장 시각이 이미 지났다. 추세 상태는 `OBSERVING_ENTRY_WINDOW_CLOSED`, 진입 신호는0이다. 가격 부족으로 차단된 상태는 해소됐다.
- 미국장이 열린 후에도 추세 지표는 관측하되 지나간 시가의 신호를 다음 날로 이월하지 않는다. 월간 리밸런스 조건도 그대로 유지한다. 실적 후보는 진입 시각이 지나면 계속 차단한다.
- 일일 원장 래퍼 순서는 입력 수집 → 독립 연구 계산으로 연결했다. 기존 봇/주문 스위치/다른 전략의 원장/기존 earnings_calendar 수집 코드는 수정하지 않았다.

## 실적: 확보한 것과 미완료 구분

기존 Finnhub 키로 이미 쓰는 earnings-calendar 엔드포인트를 읽기 전용 호출했다. 키는 요청 헤더로 전달하고 원장/로그에 쓰지 않는다. 새 유료 API/계정 구매나 구독 변경은 없다.

첫 원본 스냅샷 440행 중 EPS 예상치215행, 매출 예상치210행, 실제 매출71행. 이는 중복 가능 일정 행 수이며 거래 표본/검증된 독립 사건 수가 아니다. 기존 EPS PIT 원장468행도 원래 first_seen_at과 함께 별도 보존했다.

매 수신 원본은 수신 UTC 시각+내용 지문 파일로 보존한다. 수정된 예상치가 들어와도 이전 스냅샷을 덮지 않는다. 기존 코드가 버리던 revenueEstimate/revenueActual을 원본 응답 안에 보존해 향후 발표 전후 비교 기반을 마련했다. 과거 발표 후 지금 받은 예상치를 과거 발표 전 정보로 변환하지 않는다.

**실적 전략은 아직 BLOCKED**: 이 엔드포인트만으로는 비교 가능한 반복적 희석 EPS 기준, 정확한 발표 시각, 동일 기간의 이전/신규 가이던스와 원문을 증명할 수 없다. 따라서 원시 캘린더를 신호로 변환하지 않는다. 빈 후보 목록을 '조건에 맞는 종목 없음'으로 표시하지 않고 입력 미완료로 구분한다.

다음 작업은 기업 IR/공시 원문의 가이던스를 공개/수신시각과 함께 보존하고, 지표·회계 기준·통화·회계연도를 맞춰 검증하는 것이다. 그 이후 발표 전 기대치 스냅샷을 사건별로 연결해야 한다. 가이던스 조건을 빼거나 가격 갭으로 대체하려면 새 전략 버전이 필요하며 이번에는 하지 않았다.

## 산출물

- `data/shadow/independent_research_inputs_v1.json`: 이번 수집 결과. 수집 실패 시 과거 성공을 새 성공으로 재사용하지 않고 실패 항목을 기록.
- `data/shadow/independent_research_sources/prices/`: 관측 시각별 조정 가격 스냅샷.
- 같은 폴더의 `fundamentals/`, `legacy_eps/`: 원본 실적 응답과 기존 EPS 이력의 내용 주소 방식 보관.
- `data/analysis/independent_research_report.json`: 연구 카드 입력.
- `data/shadow/independent_research_observations.jsonl`: 계산 결과와 입력 관측 이력. 체결/수익 원장 아님.
