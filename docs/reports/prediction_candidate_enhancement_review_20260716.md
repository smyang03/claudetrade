# 예측력·후보군 강화 종합 검토 (2026-07-16)

작성: Claude (웹 리서치 에이전트 2개 + 내부 DB 실측 결합). 분석 전용 — 라이브 미접촉.

## 0. 한 줄 결론

예측력의 병목은 모델이 아니라 **표본과 후보 축**이다. 현재 후보 소스는 전부 "이미 움직인 종목"(사후 축)이고, 검증 표본은 세션 40~60개에서 라운드마다 판정이 뒤집힌다(오늘 candidate_path lab 3라운드 실증). 따라서 강화 순서는 ① 사전 등록형 후보 축 추가(발견 지연의 구조적 해독제) ② 문헌 검증 피처 소수 추가 ③ 소표본 검증 규율 강제 — 이 순서다.

## 1. 내부 실측 진단 (오늘 확인)

| 항목 | 실측 | 함의 |
|---|---|---|
| 후보 소스 | US=most_actives(55k)/day_gainers(43k)/day_losers(17k), KR=volume_rank(39k)이 전부 | **전부 사후(reactive) 축** — 움직인 뒤 잡힘. 발견 지연(first_observed US 52%/KR 38%, 7/13 실측)의 뿌리 |
| KIS 수급 API | 종목별 외국인/기관 가집계(`foreign-institution-total`) **미배선** | 브로커가 공짜로 주는 KR 최강 실증 축을 안 쓰는 중 |
| DART | 뉴스 수집(preopen)만 연결 | 잠정실적·주요 공시의 T+1 사전 등록 축 미활용 |
| 시간축 라벨 | mfe_time 0/997, 7/10 이후 청산 1건 | forward 학습 루프가 표본 기근으로 정지 |
| lab 판정 안정성 | US생존→KR기각→US기각·KR반전 (3라운드) | 40~60세션은 발견용, 판정용 아님 → P0 prospective 수집이 전제 |

기존 판정과의 정합: "스크리너 랭킹 건드리지 마라(리랭킹 backfire, 6/27)"는 유지 — 아래 제안은 **기존 랭킹 재조정이 아니라 후보 소스(축) 추가**다. "픽≈풀(7/2)"도 유지 — 풀 확대가 아니라 축의 선행성 개선이 목적.

## 2. 후보군 강화 축 — 근거 강도 순

### A1. US 어닝 캘린더 사전 등록 (근거 최강·무료·완전 선행)
- 실증: 어닝 어나운스먼트 프리미엄(Savor & Wilson, JF 2016 — 발표 주간 연환산 ~9.9% 초과), PEAD 잔존(소형주·해석 어려운 뉴스), 동업종 선발표→후발표 전 드리프트(월 100bp+).
- 발표일이 **사전 공표**되므로 T-1 저녁에 후보 등록 가능 = 유일하게 100% 선행인 축.
- 데이터: Finnhub 무료(US, 90일 창), Alpha Vantage EARNINGS_CALENDAR. **이미 data/earnings_calendar.json 수집 중** — 후보 등록에만 연결하면 됨.
- 주의: CLAUDE.md PEAD 게이트 규율(입력 품질 기능, 출구 override 금지) 유지.

### A2. 52주 신고가 근접 (비용 0·양시장·전일 계산)
- 실증: George & Hwang(JF 2004) 월 ~0.6%, 모멘텀 지배, 국제 재현 다수. 메커니즘=앵커링 과소반응 → "돌파 전 근접"을 미리 잡는 논리가 학술적으로 성립.
- 일봉만으로 전일 밤 계산(KIS/pykrx). 원논문은 월 단위 보유 — 우리 보유기간 이식은 forward로만 판정.

### A3. KR 외국인 수급 (KIS API 이미 보유·국내 실증 최강)
- 실증: 외국인 보유+공매도 기반 신호가 분기 알파 2.22%(t=3.66), 7팩터 강건(PBFJ 2026). **국내 기관 6유형은 전부 예측력 없음 — 외국인만 쓸 것.**
- KIS `foreign-institution-total`(장중 추정) + pykrx 확정치(당일 18시). 추가 비용 0.
- 논문 지평은 분기 — 단기 이식은 shadow 필수.

### A4. 고거래량 충격 = "조용한 축적" (recency bias의 구조적 해독제)
- 실증: Gervais·Kaniel·Mingelgrin(JF 2001) 고거래량 프리미엄 — 비정상 거래량 뒤 1개월 상승, 2020년대 후속 재현. **가격이 움직이기 전** 포착 가능 = 사후 축의 정확한 보완.
- 일봉 거래량만으로 계산, 비용 0. 지평(주~월)과 우리 보유기간 차이는 forward로 판정.

### 보조/보류 축
- **락업(보호예수) 해제**: 해제 전후 CAR −1.5~−2% — 롱온리에선 **진입 회피 필터**로만(KR 예탁원/KIND 공시 사전 공표).
- **공매도/대차**: 근거 있으나 KR T+2 지연·US 일별 파일 커버리지 불완전 → 스윙 보조.
- **옵션 비정상 활동**: 학술 근거 강하나 무료 데이터 품질이 논문 조건과 괴리 → 보류.
- **US 프리마켓 스캐너**: 예측 엣지 근거 약함(gap-and-go 실증 빈약). 단 "발견을 개장 전으로 당기는" 배관 가치는 있음 — Alpaca 무료는 IEX ~2% 커버리지 한계.
- **VI 이력·프로그램 매매**: 예측력 실증 부재 — 후순위.

## 3. 예측력 강화 기법 — 근거 강도 순

### B1. 첫 5분 relative volume 피처 (최우선 시험 피처)
- Zarattini·Barbon·Aziz(SSRN 4729284, 2016–23, 7천 종목, 비용 net Sharpe 2.81) + QuantConnect 독립 재현(Sharpe 2.40). 핵심 변수 = **첫 5분 거래량 ÷ 직전 14일 같은 시간창 평균**("stocks in play"). OR은 짧을수록(5분) 좋음.
- 우리 개장+5분 진입 계약과 시점 정합 — lookahead 없이 후보 랭킹 피처로 즉시 시험 가능.
- 같은 논문의 **첫 5분봉 방향**도 검증된 진입 방향 변수.
- 반증 확인: **무조건부 갭 방향 추종·갭 페이드·지수 ORB는 전부 사망**(overnight-intraday reversal이 기본 상태). 갭 크기는 피처로만, 방향 가정 금지.

### B2. 소표본 검증 규율 (이번 lab 사고의 재발 방지책)
- **유효 표본 = 행이 아니라 세션 수**(같은 날 후보는 공통 요인 상관). 검증은 leave-session-out + purge, 판정 지표는 **세션별 rank IC 평균·부호 안정성**(top-3 net은 보조).
- **피처 예산 ≤5개**(EPV≥10 규칙), 모델은 정규화 선형 vs depth≤2 GBDT 두 개만. 시도 횟수 기록(메타 과적합은 CPCV도 못 막음 — DSR류 보정).
- 대형 실증조차 붕괴함("When Alpha Breaks": 2,277일 학습 LightGBM의 RankIC 0.064→0.010) — 40~60세션에서 모델 탐색 확대는 발견 확률만 부풀림.

### B3. Platt 보정으로 교체 (profit_path 데드락의 문헌적 해법)
- 확립된 결과: 보정셋 <1,000행이면 **isotonic이 과적합, Platt(sigmoid)가 우월**. 우리 profit_path의 isotonic clip 확률 상한(KR 0.49/US 0.30 < 임계 0.55 → 영구 미승격)은 이 문헌과 정확히 일치하는 소표본 증상.
- profit_path·us_swing·향후 경로 모델 전부에 적용 가능한 저비용 수정.

### B4. Reject option + 전략 레벨 게이트
- 다수 데이터셋에서 conformal 기반 거절(확신 없으면 미충원)이 유효. top-3를 "그날 3개 못 채워도 됨"으로 운영하는 형태와 정합.
- 종목 레벨 불확실성보다 **전략 레벨 게이트**(trailing 실현 rank IC + 피처 드리프트로 on/off, AUROC 0.72~0.75)의 실증이 강함 — shadow→enforce 승격 게이트 설계에 그대로 이식 가능(성숙 라벨만 사용).
- 불확실성 역수 사이징은 실패 실증 — 이산 캡/abstention만.

### B5. Meta-labeling 구조 (현 접근 유지 근거)
- "진입 엣지는 있는데 실현이 안 되는" 시스템에 정확히 부합하는 구조(우리 top-k 랭커가 이미 이 형태). 단 문헌 개선폭은 정밀도 +0.03~0.06으로 **완만** — 소표본에서 그 폭의 통계 확인 자체가 어려움을 전제.
- **competing risks/time-to-event 모델은 비권장**: 금융 인트라데이 실증 부재, 3-클래스 분류가 이미 단순형.

## 4. 실행 설계 — P0와 한 몸으로

P0(전체 후보 prospective 등록+장후 분봉 수집)에 위 축을 **후보 소스로 추가**하면 발견 지연·표본 기근·사후 축 세 문제를 한 배관으로 공략한다:

1. **장전 등록(T-1 밤~당일 08:30)**: 어닝 T-1(US) / 52주 신고가 근접 / 거래량 충격 / 외국인 수급(KR) / DART 잠정실적(KR) → `preregistered` 소스 태그로 후보 풀에 주입(기존 스크리너 축과 병행, 리랭킹 없음).
2. **개장 후 트리거**: 등록 명단 안에서 첫 5분 relative volume·첫 5분봉 방향으로 우선순위만 계산(shadow 기록).
3. **검증**: 신규 세션 30개, 세션별 rank IC + 소스별 forward 분해(사전 등록 축 vs 기존 사후 축의 +3.4% 엣지 비교). 판정 전 enforce 금지.
4. **저비용 즉시 수정**: profit_path 계열 보정을 isotonic→Platt로 교체(코드 소규모, shadow 산출물만 영향).

## 5. 운영자 결정 항목

1. P0 수집 범위(전체 vs top-N+해시 표본) — 기존 질문 유지.
2. 사전 등록 축 4종(A1~A4)의 후보 풀 주입 승인 — 스크리너 랭킹 불변 전제.
3. KIS 외국인 수급 API 배선 착수 여부(KR 1순위 축).
4. Platt 보정 교체 착수 여부.

모든 축은 논문 지평과 우리 보유기간이 다르므로, 기존 규율(shadow/forward에서 우리 실제 net으로 판정 후 enforce) 그대로 적용한다.
