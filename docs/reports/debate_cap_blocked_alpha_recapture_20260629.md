# 토론: cap이 막은 KR D+1 알파를 추격 아닌 경로로 잡을 수 있나

- 일자: 2026-06-29
- 명제: "cap이 막은 KR 종목의 D+1 알파는, 추격이 아닌 대안 진입 경로(원-cap 눌림 재진입 / 익일 시초 / 조건부 트리거 중 하나 이상)로 실측 net+ 포착이 가능하다."
- 형식: PRO/CON 입론 → 반박 → 사회자 직접 재검증 → 판정. 전부 read-only.
- 데이터: cap_exceeded 케이스(funnel action_routing_shadow), 분봉 `data/price/minute/kr/`, 라벨 `ticker_selection_log.db`. 측정창 2026-05-06~06-29.

## 판정: 조건부 미결 (큰 틀 CON, 단일 경로에서 미약한 PRO 신호)

"잡을 방법이 정말 없는가"의 답 = **거의 없다, 단 하나 미약한 신호.** 추격·눌림재진입·보유는 전부 net−. forward_1d 알파 자체가 비robust(기간 확장 시 소멸). 그러나 **D+1 시초 + 분봉 TP5/SL3 한 경로만 비용후 +0.97%**로 살아있다. enforce 불가(robust 미검증).

## 사회자 직접 재검증 (판정 가른 2지점)

### 검증1 — forward_1d 알파 robust성: CON 승

배경의 +4.6%는 좋은 구간 선택의 산물. 9일 확장하니 소멸. max_runup_3d +12%는 유지되나 max_drawdown_3d −9.6%·−2%손절 84%가 먼저 → lookahead. forward_3d −2.78%(win35%) 보유 시 손실.

### 검증2 — D+1 시초 진입 net 부호: PRO 승(조건부)
D+1 첫 분봉 open 진입 → 분봉 TP/SL 먼저닿은쪽 청산(전체기간, n=36):

PRO 숫자 재현됨. CON의 −1.49%는 "D+1 종가청산" 가정(다른 측정). **분봉 TP/SL 청산이면 양(+), 단 SL3(느슨)에서만.** SL2로 조이면 손절먼저 우세로 음전.

## 합의 / 불일치(해소) / 잔존리스크

**합의:** 추격(D0 cap완화) net−1.4%·손절먼저 32/36. 눌림재진입(P≤cap) net−1.3%. forward_3d 보유 음. max_runup은 lookahead.

**불일치→사회자검증 해소:** forward_1d robust=CON맞음. D+1시초 net부호=PRO맞음(TP5/SL3).

**잔존 리스크(enforce 차단 사유):** win53%(동전), median+5는 TP capped, SL파라미터에 부호민감, 표본36건·6월단일국면~2.5주, 비용 0.25% 가정.

## 결판 조건 (무엇을 더 측정)
1. 표본 누적 — cap케이스 D+1 분봉을 6월 외 2~3국면(분봉이 6/4~만 존재가 제약).
2. SL 민감도 — 진입직후 눌림 깊이 분포, SL을 ATR 비례로. 왜 SL3만 +인가 규명.
3. D+1 갭 분리 — 갭상승(+1.47%) 선반영분 제외 시 잔존 여부.

## 메커니즘 요약
알파를 D0 당일 추격으로 먹으려면 진입직후 눌림(−2~3%)에 손절로 잘린다. 하루 미뤄 D+1 시가에 사고 손절을 느슨히(SL3) 두면 그 눌림을 통과한 뒤 TP5를 먹는 구조 — 단 동전 수준이라 국면 누적 전 실거래 적용 금지.

## 후속 검증 (6/29, 세 전제 뒤집기 A/B/C + 사회자 재확인)

토론의 "조건부 PRO 신호(D+1 +0.97%)"마저 placebo에서 무너진 뒤, 세 전제를 뒤집어 재측정:

| 방향 | 결과 | 판정 |
|---|---|---|
| A 대상(일반종목+갭필터) | placebo 선정기여≈0(랜덤일+0.63%≈선정+0.66%), 갭필터<+0.1%p, 주차 비일관, 상위3날짜 제거시 +0.26% | 환상 |
| B 신호(과열리스크) | cap forward_3d −2.78% > baseline −4.67%(덜나쁨), dd3 −9.58% < base −12.94%. 분봉 cap직후 +2%먼저 56% | 미지지 |
| C 청산(trail) | D+1 trail gb3 mean +1.23 vs 고정 +0.97, 단 median −0.49·win42·**러너1건(+20.1) 제거시 +0.70**(고정보다↓) | 러너착시 |

**사회자 직접 재확인(verify_bc.py):** B — cap이 baseline보다 forward_3d/dd 모두 양호 → 과열 반증 확정. C — trail 우위는 러너 1건 의존, 제거 시 고정보다 못함 → 청산개선 엣지 없음.

**최종 메타 판정:** 추격·일봉·분봉·D+1·갭필터·과열신호·trail 7회+ 측정 전부 같은 곳 수렴 — 모든 "+"의 정체는 ①소수 러너(우측꼬리) ②6월 단일 상승국면. **사전 신호(cap·선정·갭)·청산개선·리스크신호 기여 전부 ≈0. 수익 종목 사전선별 불가, 청산으로도 못 살림. cap 유지 확정.**

**부산물(별개 주제):** 전체 KR 선정 baseline forward_3d −4.67%·max_drawdown −12.94%(n=1301) — KR 풀은 3일 보유 시 큰 손실, 짧게 끊을 때만 +. "KR은 길게 들지 말라"의 방증. 별도 추적.
