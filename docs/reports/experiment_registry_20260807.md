# 실험 등록부 (trial registry) — 2026-08-07 개설

목적: 여러 규칙·허들·파라미터를 시험한 뒤 좋은 것만 고르면 백테스트 과적합이 된다
(Bailey et al., deflated Sharpe 계열 논지). 방어는 **시도 횟수와 탈락 실험까지 기록**하는
것이다. 이 문서는 그 등록부다 — 새 탐색을 하면 여기에 셀 수·탈락 결과를 남긴다.

기록 규칙:
1. 탐색 시작 전 또는 직후에 등록 — 탐색 공간(셀 수), 데이터, 판정 기준.
2. 탈락도 기록한다. "살아남은 것만 문서화"가 과적합의 입구다.
3. 다중검정 방어 근거(사전 가설·독립연도 재현·단조성 등)를 명시한다.
4. 승자는 사전등록 문서(preregistered_falsification_criteria)로 승격 — forward가 최종 판정.
