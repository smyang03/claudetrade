# 사전 등록 — 급락 반등 레인 반증·확대 기준 (2026-08-04)

목적: "지금 당장 맞다고 못 한다"를 강하게 만드는 방법은 **틀렸을 때의 기준을 결과가 나오기 전에 고정**하는 것이다(사후 골대 이동 방지). 아래 기준은 forward 표본이 쌓이기 전에 등록됐다. 변경은 운영자 승인 + 변경 사유 기록으로만.

## US us_swing micro (일1건×30만, 슬롯3)

| 시점 | 판정 | 기준 |
|---|---|---|
| forward 30건 | **확대 허가** | net 합 > 0 AND 평균 알파(동일 구간 IWM 대비) > 0 → 일3건 재론 |
| forward 30건 | **정체** | net > 0 이지만 알파 ≤ 0 → "지수 매수 대비 무가치" — 확대 불가, 선별 개선 과제로 전환 |
| forward 30건 | **경고** | net ≤ 0 → 일1건 유지, 원인 분해(국면/슬리피지/선별) 후 운영자 보고 |
| forward 60건 | **반증** | net ≤ 0 지속 → 운영자에게 레인 중단·재설계 제안 (결정은 운영자) |
| 상시 | **즉시 점검** | 단일 거래 슬리피지(체결가 vs 신호시점 시세) > 1% 반복 3회 → 사이징·유동성 하한 재검토 |

- 알파 정의: 각 거래의 net − (진입~청산 동일 구간의 IWM 수익률). 산출: `tools/kr_fallen_gate_report.py` 계열 리포트.
- 표본 카운트는 day_losers 전용 전환(2026-08-03) 이후만. 구소스 혼합 신호·고정보유 회계(−239%p 계열)로 판정 금지.

## KR shadow 3파전 (R1 8조건 / R2 할인−25%+rv20 / R3 합집합)

| 판정 | 기준 |
|---|---|
| micro 승격 후보 | 게이트(15영업일+정산15건+2주분산) 충족 규칙 중 net>0·PF>1.2 최우수 규칙 |
| **R2 단축 조항** (2026-08-04 수정, 운영자 결정) | **R2에 한해 정산 요건 15건→10건.** 근거: 2025년 out-of-sample(규칙 적합 미접촉 연도)에서 R2 +6.43%/PF 5.07/알파 +3.62% 재현 — "사전 외부 데이터와 내부 live가 같은 방향" 원칙의 사전 절반 충족. R1은 같은 검증에서 −1.71%/알파 −2.49%로 부정적이라 15건 유지(강등 후보), R3도 15건 유지 |
| **국면 조건** (2026-08-04 추가) | 승격 규칙은 **시장하락 국면 표본에서 절대 net > 0 또는 (net > −2% AND 알파 > 0)** 이어야 한다. 미달 시 "상승·횡보 국면 한정 + 국면 게이트 부착" 조건부 승격만 가능 |
| 반증 | forward에서 세 규칙 모두 net ≤ 0 → KR 레인 재설계(조건 재탐색은 새 데이터로) |

- in-sample 참고치(R2 하락장 +1.92/α+8.78 등)는 기대이지 근거가 아니다 — forward가 미달하면 in-sample 수치는 폐기.

## 정상 변동 범위 (2026-08-04 부트스트랩 사전 등록 — 이 범위는 반증이 아니다)

30건 검증 구간에서 통계적으로 **정상**인 고통의 크기 (R3 분포 5,000회 재추출, 건당 30만):
- 연속 손실 **6건까지** (중앙값 3건, 95분위 6건)
- 구간 최대 낙폭 **−30만원까지** (중앙값 −13.7만, 5% 최악 −29.8만)

이 안의 손실 구간에서 전략을 의심하는 것은 소음을 신호로 읽는 것이다(7월의 실패 패턴). 이 범위를 **넘는** 연속 7건+ 손실이나 −30만 초과 낙폭이 나오면 그때 조기 점검(중단 아님)을 연다.

## 공통 규율

1. 판정 입력은 원장(net·알파·국면·사유코드)만 — 기억·인상·단일 사례(AXTI·FRMI) 금지.
2. 기준 미달인데 확대하고 싶은 유혹이 오면, 이 문서가 그 유혹의 반대 근거다.
3. 기준 충족인데 확신이 안 서면 그것도 기록한다 — 단 충족 시 기본값은 "정의된 다음 단계 진행".
