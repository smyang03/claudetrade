# 못 살리고 있는 것 3건 — 실측 분석과 반영 설계 (2026-08-06)

"시스템이 잘하는데 못 살리는 게 뭔가"에 대한 답을 실측으로 검증했다.
전부 계약 동결을 지키면서(라이브 무개입, shadow 관측만) 반영 가능하다.

---

## ① 검증 기계를 절반만 쓰고 있다 — 가장 큰 손실

라이브 슬롯은 희소하지만 **분석 대역폭은 공짜**다. 30건이 모이는 동안
다음 질문들의 답이 같이 준비될 수 있는데, 지금은 뉴스 3-arm 하나만 돌고 있다.

### ①-a rank 확대 근거 (sealed 293세션 실측)

```
rank1: n=293 평균 +1.402% 승률 51.2% PF 1.367
rank2: n=293 평균 +0.316% 승률 51.2% PF 1.075
rank3: n=293 평균 +0.444% 승률 51.2% PF 1.131
rank1 vs rank2~3 차이 +1.022%p (p=0.169 — 유의하지 않음)
```

**해석: rank1 우위는 방향은 맞지만 통계적으로 확정되지 않았다.**
8월말 A판정에서 "일3건 확대"를 하면 rank2·3을 사게 되는데, 그 둘의 기대값이
rank1의 1/4 수준일 수 있다. 확대가 **표본을 3배로 벌지만 건당 기대값은
희석**한다는 뜻이다. 이 트레이드오프를 지금 몰랐다면 확대 후에야 알았다.

→ **반영: forward에서 rank1~3을 모두 shadow 기록**(실주문은 rank1만).
   30건 시점에 "확대 시 예상 성과"를 실측으로 답할 수 있다.

### ①-b 허들이 제 값을 하는가 (확률 구간별)

```
prob <=0.45   n= 10 평균 -1.40% 승률 50%   ← 오늘 ULS 차단 구간(0.418)
prob 0.45~0.5 n= 11 평균 +5.68% 승률 73%
prob 0.5~0.55 n= 23 평균 +5.11% 승률 70%
prob 0.55~0.6 n= 28 평균 +6.73% 승률 64%
prob >0.6     n=221 평균 +0.25% 승률 47%   ← 대다수가 여기, 그런데 평범
```

**U자형이다.** 저확률 구간 차단은 옳지만(-1.40%), **모델이 가장 확신하는
구간(>0.6, n=221)이 오히려 평범**하다. 어제 기각한 "확률 역지표"와 같은
방향이며, 여기서는 단조가 아니라 중간 구간(0.45~0.6)이 최적이라는 형태다.

주의: sealed 코호트는 소스 필터(day_losers) 이전 혼합이고 다중검정 위험이
있다. 단독 판정 금지 — forward paired 관측으로만 검증한다.

→ **반영: 차단된 후보의 D5 사후 성적을 기록**(허들 검증의 유일한 방법).
   오늘 ULS가 첫 대상. 30건 시점에 "허들이 얼마를 벌어줬나/까먹었나"가 나온다.

## ② KR과 US가 서로 배우지 못한다 — 교차 검증에서 두 가지가 나왔다

### ②-a 단위 불일치 발견 (즉시 가치)

```
US realized_vol_20d_pct 중앙값 85  (연율화)
KR rv20                 중앙값 5.35 (일간)
```

두 레인이 같은 이름의 피처를 **다른 단위**로 쓰고 있었다. KR 조건(rv20<=8)을
US에 그대로 넣으면 0건이 나온다(실측). 향후 어떤 교차 작업이든 정규화
(`연율 / sqrt(252)`)가 선행돼야 한다는 것을 지금 알았다.

### ②-b 두 시장은 정반대다 — 실측으로 확정

**KR 데이터에 US 조건(장중 투매형) 적용:**
```
KR 급락밴드 전체        n=4056  평균 -0.41%
장중성분 <=-3%p        n=3464  평균 -0.94%   ← US thesis 방향
장중성분 <=-5%p        n=2778  평균 -1.34%
장중성분 <=-7%p        n=1730  평균 -1.69%   ← 강할수록 더 나쁨
갭 <=-2%p              n=1882  평균 +1.74%   ← US가 배제하는 쪽
갭 <=-4%p              n= 939  평균 +2.79%   ← 갭 클수록 더 좋음
[대조] KR 자체조건      n= 233  평균 +5.02%
```

**US 조건을 KR에 넣으면 부호가 뒤집힌다.** US는 "갭 없이 장중 투매"를 사고,
KR은 정반대로 "갭 하락(과잉반응)"을 사야 한다. 강도를 높일수록 각자 방향으로
더 벌어진다 — 우연이 아니라 구조적 차이다.

**US 데이터에 KR 조건(할인+저변동) 적용:**
```
US 급락밴드 전체        n=727  평균 +1.729%
disc<=-25 & rv_d<=8    n= 34  평균 -0.19%   ← KR 조건은 US에서 역효과
disc<=-25 (rv 무관)    n= 40  평균 +2.89%   ← 할인만은 US에서도 유효
저변동 단독(rv_d<=8)   n=597  평균 +1.35%  (전체 +1.81%보다 낮음)
```

**저변동 조건이 US에서는 오히려 손해다.** KR에서 핵심인 rv20이 US에서는
수익원을 잘라낸다. 반대로 "깊은 할인"은 양 시장 공통으로 유효하다(+2.89%).

→ **결론: 레인 통합은 하지 않는다.** 대신 두 가지가 확정됐다.
   1. 조건 이식 시도는 재론 금지 목록에 올린다(양방향 역효과 실측)
   2. **"깊은 할인"은 시장 중립 신호**다 — US rank 산정에 할인 깊이를
      관측 피처로 추가할 가치가 있다(shadow 검증 후)

## ③ 실패 기록을 학습에 안 쓴다 — 패턴이 보인다

반증 이력을 나열이 아니라 구조로 보면 일관된 선이 있다.

```
기각된 것 (전부 "예측"을 추가하려는 시도)
  바닥/경로 예측 · 국면 게이트 4패널 · 모델 확신도 · 후보 풀 조성
  Claude 선별(KR 역선별) · 조기 진입 · 추격 · 무기한 보유

살아남은 것 (전부 "구조"를 정한 것)
  조건 필터(day_losers, R2) · 계약(TP12/SL25/D5) · 크기(30만원)
  진입창(개장 5~30분) · 매일 반복
```

**예측은 8전 8패, 구조는 5전 5승이다.** 표본이 적어 확정은 아니지만,
다음 개선의 우선순위를 정하는 데는 충분한 신호다.

그리고 아직 안 판 구조 축이 남아 있다:
- 청산 구조 — tail-capture(TP 후 트레일링). 30건 후 예정
- 크기 구조 — 슬롯/금액 배분, rank별 차등 사이징
- 실행 구조 — 진입창 세분(5~15분 vs 15~30분 어디가 싼가)

→ **반영: 개선 아이디어 심사에 "예측인가 구조인가"를 1차 필터로 넣는다.**
   예측 계열은 8전 8패 이력을 근거로 기본 기각, 구조 계열은 shadow 우선 검토.

## 반영 설계 (계약 동결 유지, 전부 shadow)

| 항목 | 무엇을 기록 | 언제 답이 나오나 |
|---|---|---|
| rank1~3 paired | 매 세션 rank2·3의 계약 성과 | 30건 시점 = 확대 시 예상치 |
| 차단 후보 추적 | 허들에 막힌 후보의 D5 성적 | 30건 시점 = 허들 손익 |
| 진입창 세분 | 체결 시각대별 shortfall | 실체결 20건 시점 |
| 할인 깊이(US) | rank 산정 밖 관측 피처 | 30건 시점 |

**지금과 달라지는 것:** 8월말 판정에서 "확대할까?"만 답하는 대신,
"확대하면 얼마가 되나 / 허들을 조정해야 하나 / 창을 좁혀야 하나"까지
같은 날 답할 수 있다. 표본을 두 번 기다리지 않는다.

**달라지지 않는 것:** 라이브 주문, 계약, 실행 소유권 — 전부 그대로다.
