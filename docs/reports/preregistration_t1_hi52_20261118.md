# 사전등록 — T1 52주 고점 대비 위치(hi52) forward 검증 (2026-11-18)

운영자 지시 11-18 "2번 진행": 분기 가설 슬롯(Q4 3/3 사용)의 **운영자 예외**로 등록한다. 결과를 보기 전에 고정했다. 첫 20세션 정산(11-19)보다 앞선다.

## 발견 경위(인샘플, 판정 아님)
T1 라이브 규칙 선택분(M2 ≥ 0.02, $3, 거래대금 $5M) 2019–2026-08, 3,542건 중 탐색 약 30칸에서 1칸이 남았다.
- hi52 = 진입 직전 종가 / 직전 252세션 최고 종가. 이전 연도 분포 20분위 이하를 low로 둔다.
- low +4.43% vs 나머지 +0.59%(net, IWM 초과 20세션). 20세션 블록 클러스터 t 3.12. 가격·점수·ret60·vol20 통제 시 +2.4%p(t 2.33), 적자·ret5·12개월 모멘텀·52주 저점 동시 투입 시 +2.8%p(t 2.57).
- 연도 8/8 양수. 한 해씩 빼면 t 2.65~3.74. 2014년 이전 상장 생존 종목만 보면 +3.4%p(t 2.34). 2022년 이후 +2.1%p(t 1.98).
- 점수 미달 이벤트에서는 효과 0이다. 선택분 안에서만 나타난다.
- 탐색 칸 수를 감안하면 문턱은 t ≈ 3.1이다. 원 t는 경계이고 통제 후 값은 미달이다. 그래서 **후보**다.
- 불리한 관찰: 라이브 보유 10종목(만기 0건) 중 손실 3종목(VRRM 0.14·STLA 0.34·NVTS 0.27)이 모두 low였다. 수익 1·2위(LBTYA 0.62·LQDA 0.53)는 비low였다.

## 고정 규칙
- **컷**: hi52 ≤ **0.486**(2026년 기준 확장창 20분위, 고정 상수). 252세션 미만 이력 종목은 있는 만큼 쓰고 `hi52_n`을 기록한다.
- **표본**: `data/shadow/us_earnings_t1_shadow.jsonl`의 `selected_I1` 신호 중 2026-09-29 이후 세션. 발견 표본(~2026-08) 밖이다.
  - 11-18 이전 신호는 yfinance 수정 종가로 소급 계산한다(`tools/research/research_t1_hi52_forward_20261118.py backfill`).
  - 11-18 이후 신호는 쉐도우 채점 시 `obs.hi52`로 기록된다.
- **결과 지표**: 같은 원장 `settle` 행 hold=20의 `net_excess`(시가→20세션 시가, IWM 초과, 비용 0.44%).
- **검정**: low − 비low 평균 차. 20세션 블록 클러스터 t(진입 세션 거래일 순번 // 20). 보조 지표는 중앙값 차와 세션 1위(`selected_I2`) 부분집합이다.
- **합격**: n_low ≥ 50 **그리고** 차 > 0 **그리고** t ≥ 2.0.
  - **기각**: n_low ≥ 50에서 차 ≤ 0, 또는 n_low ≥ 100에서 t < 1.0.
  - 그 밖은 계속 관측한다.
- **판정 시점**: n_low가 50건에 이를 때(예상 2027-01~03). 중간 점검은 월 1회 기술 통계만 한다(판정 아님).

## 실행과의 관계
- 합격 전에는 라이브 T1 매수·비중을 바꾸지 않는다.
- 합격 후 실행안(low 비중 확대 등)과 금액은 **운영자가 결정**한다. 대상군의 꼬리 비율이 더 높으므로(7.3% vs 6.5%) 최악 손실 산수를 함께 제시한다.
