## 5. 결론

1. Jev를 예측에 쓰는 6개 레버(꼬리형 질문, 입력 데이터, pairwise, few-shot, 패러프레이즈, 사용처 3종)의 사전등록 1차 지표가 전부 바(t 2.64 + IS 부호 + 연도)를 못 넘었다. round1과 같은 결론이 예측 목적에서도 재현된다.
2. few-shot(state형·criteria형)과 패러프레이즈 평균은 **음수 방향**이다. 예시와 문구를 더해도 Jev가 수익률 분포를 학습하지 않는다. 문서 그대로(가중치 고정, 문맥으로 학습 안 됨)다.
3. pairwise tie-breaker는 2021–24에 +, 2025–26에 크게 −다. 세션 내 오라클 여지(+14.7%p)는 크지만 Jev도 절대점수도 그것을 잡지 못한다.
4. 꼬리형 질문은 상승 꼬리가 아니라 **분산**을 예측한다(new_driver·weak_or_unclear는 하위 10%도 같이 올린다). 롱 전용 T1에는 쓸모가 없다.
5. 살릴 것 하나: **이전 분기 대비 diff 질문(d_outlook_improved)**. 보조 칸이고 IS 부호가 반대라 채택할 수 없지만, 이번 라운드에서 유일하게 방향성 있는 비대칭 신호다.
6. KR 공급계약·유상증자 diff: 기각(k_signif t 1.32, 후반 0).
7. **현재 자본 월 증분: 0원.** 채택된 규칙이 없다. 참고로 d_outlook_improved를 사이징에 쓴다고 가정하는 것은 IS 부호 반대라 근거가 없어 산출하지 않는다(산출 불가: 사전등록 외 사후 선택 + IS 반대 부호).
