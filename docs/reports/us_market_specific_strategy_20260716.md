# 미국장 전용 전략·운영 개선 판정 (2026-07-16)

작성 목적: 한국장 로직의 복제나 미국 후보의 무조건 확대가 아니라, 미국장 데이터 계약과
보유 구조에 맞는 별도 수익 레인을 확정한다.

재현 산출물:

- `tools/us_market_shape_strategy_review.py`
- `reports/us_market_shape_strategy_review_20260716.json`
- `reports/us_market_shape_open15_ledger_20260716.csv`

모든 시뮬레이션은 US 왕복 비용 0.50%, 동일 분봉에서 목표/손절 동시 도달 시 손절 우선,
결정시점 이후 첫 완전 분봉 시가 진입을 사용한다. 라이브 주문 권한은 없다.

## 1. 결론

미국장은 그대로 두지 않는다. 다만 개선 방향은 `개장 추격 매수 확대`가 아니다.

미국장 최종 구조는 다음 4개 레인이다.

| 레인 | 역할 | 현재 판정 |
|---|---|---|
| SCHG/BIL 코어 | 장기 베타와 추세 방어 | 기본 자본 레인 유지 |
| US_SWING_5D | 일봉 상대강도 기반 5거래일 독립 알파 | rank-1·30만원·한 슬롯 micro 유지 |
| PathB intraday | 회사별 기회성 전술 | 후보 확대 금지, 기권 우선 |
| Event/second-day challenger | 실적 후 드리프트·전일 in-play 이월 | 기존 registry 위 shadow로 구축 |

즉 미국장은 `코어 + 저회전 swing + 드문 전술 + 이벤트 challenger` 구조다. 한국장의
split-runner·수급 구조를 복제하지 않는다.

## 2. 개장 추격 확대를 하지 않는 이유

최신 `candidate_path_labels_lag5_v1.csv`는 후보를 안 뒤 개장+5분 이후 첫 완전 분봉에
진입한다. 7월 고정 holdout에서 전체 후보의 비용 후 평균은 다음과 같다.

| 경로 | 전체 후보 평균 |
|---|---:|
| 30분 TP 1.6% / SL 2.5% | -0.532% |
| 30분 TP 2.3% / SL 2.5% | -0.554% |
| 30분 TP 3.6% / SL 2.5% | -0.543% |
| 60분 TP 1.6% / SL 2.5% | -0.637% |
| 60분 TP 2.3% / SL 2.5% | -0.668% |
| 60분 TP 3.6% / SL 2.5% | -0.695% |

기존 시스템 점수로 상위 3개만 골라도 최선 셀은 30분 TP 2.3%의 -0.020%로 비용 후
본전 이하이며, 다른 셀은 음수다. expanding walk-forward에서 60분 TP 2.3%가 평균
+0.144%였지만 세션 블록 하한은 -0.196%, 7월 월별 값은 -0.142%로 안정성 관문을
통과하지 못한다.

따라서 미국장 매수 부재를 해결한다며 현재 PathB 후보를 넓히거나 top-k를 늘리면,
최신 실행 가능 라벨 기준으로 음수 풀을 더 많이 사게 된다.

## 3. 개장 +15분 확인도 아직 수익 규칙이 아니다

감사 DB의 point-in-time post-open snapshot을 사용해 개장 8~15.5분 사이 가장 풍부한
관측치만 골랐다. 그 관측 뒤 다음 완전 분봉에 진입해 121건을 재생했다.

| 규칙 | n | 대표 60분 TP2.3/SL2.5 평균 | 세션 하한 |
|---|---:|---:|---:|
| 개장+15분 전체 | 121 | -0.654% | -1.158% |
| ret5/ret10 양수 + VWAP 위 | 31 | -0.617% | -0.831% |
| 촉매 + 위 조건 | 10 | -0.743% | -0.998% |
| controlled pullback | 27 | -0.851% | -0.874% |

표본이 3세션뿐이므로 영구 기각 근거는 아니지만, 오늘 enforce할 근거도 아니다.
특히 `양봉 + VWAP 위 + 촉매`라는 그럴듯한 조합도 현재 표본에서는 개장 고점 추격을
막지 못했다.

외부 연구도 개장가가 소매 관심 종목에서 일시적으로 높고 이후 장중 반전될 수 있음을
보여준다. 미국장 개선은 개장 강도 자체보다 `전일 계획 + 이벤트 + 다음날 지속성`에
초점을 둬야 한다.

## 4. 현재 가장 미국장다운 공격 레인: US_SWING_5D

이 레인은 일봉 상대강도·유동성·시장 벤치마크를 사용하고 최대 5거래일을 보유한다.
PathB와 자금·슬롯·출구 소유자가 분리되어 있다.

역사 point-in-time OOS:

- 293세션
- top-3 평균 +1.357%, PF 1.512
- 상위 3일 제거 후 +1.080%
- 비용 스트레스 후 +1.057%
- 단, 블록 하한 -0.152%

실행 계약 rank-1 counterfactual:

- 평균 +1.402%, PF 1.367
- 2025 평균 +0.052%, 2026 평균 +6.330%로 국면 편중 존재
- 블록 하한 -0.171%
- 최악 -27.18%: 25% catastrophe stop의 갭 위험이 남아 있음

따라서 정식 승격이 아니라 현재의 bounded micro가 적절하다.

- 주문 상한 30만원
- rank-1 한 종목
- 동시 한 슬롯
- 개장 5~30분
- 확률 0.55, 예측 net 0.25% 이상
- 절대 갭 3%, 기준가 이탈 1%, 추격 0.5% 제한

현재 SMCI shadow 계약은 2026-07-10 진입, 5거래일 계약상 2026-07-16 성숙이다.
`PENDING`은 스테일이 아니라 정상 보유다. 오늘 미국장 종가 데이터가 들어온 뒤
성숙·슬롯 해제되는지가 다음 운영 관문이다.

## 5. 바로 적용한 운영 개선

`tools/us_swing_preflight.py`를 수정했다.

1. 셸이 `.env.live`를 직접 로드하지 않아도 `config/v2_start_config.json`의
   `US_SWING_AUTHORITY_MODE`를 읽는다. 기존의 잘못된 `configured=shadow` 표시를
   제거했다.
2. handoff·submit·live ACK 조합을 실제 상태로 표시한다. 현재는
   `WIRED_LIVE_ACK_CONFIGURED`다.
3. 활성 한 슬롯의 진입일·수량·예상 성숙일을 표시한다. 정상 보유를
   `slot_occupied_pending`만 보고 스테일로 오판해 강제 해제하는 위험을 줄였다.

주문 조건, 예산, 종목 선택, 청산 규칙은 바꾸지 않았다.

## 6. 다음 미국장 전용 challenger

### P1. Earnings D+1~D+3

실적 발표 당일 갭을 추격하지 않고 발표 시각·surprise·가이던스를 구조화해 다음 세션부터
평가한다. PEAD는 학술적으로 반복 관측됐지만 우리 벤더의 EPS 커버리지가 낮으므로,
`earnings_calendar`와 SEC/Finnhub 원장을 먼저 확장한다.

승격 전제:

- 발표 전/후 시각 구분
- EPS와 매출 surprise 동시 보유
- D+1 시가 진입 가능성
- 0.50% 비용과 갭 슬리피지 반영
- 30세션 이상, 블록 하한 양수

### P2. Second-day RVOL continuation

당일 개장 강도를 사는 대신, 전일 `in-play` 종목을 다음날 사전 등록한다.

- 전일 시간대 정규화 RVOL
- 전일 종가가 VWAP·중간값 위
- 전일 고점 대비 반납 제한
- 다음날 갭 과대 시 기권
- 후보 registry의 `registration_basis`로 사전 고정

현재 `time_normalized_rvol` 배관은 존재하지만 역사 커버리지가 거의 없으므로 prospective
shadow가 선행한다.

### P3. Nasdaq NOII

Nasdaq의 NOII는 개장 9:25~9:30 ET에 opening imbalance와 예상 교차가격을 제공한다.
미국 개장 가격발견에 직접적인 데이터지만 유료·라이선스 피드다. 무료 대체값을 NOII로
오인해 배선하지 않는다. 피드를 확보할 때만 기존 preopen registry의 한 필드군으로
추가하고 별도 후보 파이프라인은 만들지 않는다.

## 7. 운영 게이트

1. 오늘 밤: SMCI 5일 shadow 성숙과 슬롯 해제 확인.
2. 다음 세션: 새 rank-1 신호가 한 슬롯 계약으로 정상 선정되는지 확인.
3. US swing forward: 세션 5, matured 15, 평균 net>=0, PF>=1 통과 전 operator micro
   이상 확대 금지.
4. 개장+15분 arm: 최소 30세션 prospective 축적 전 enforce 금지.
5. PathB broad pool: 최신 비용 후 OOS가 음수인 동안 확대 금지.

## 8. 기존 대비 달라진 운영 방식

| 이전 인식 | 변경 후 |
|---|---|
| 미국장도 일반 후보 모델을 개선하면 됨 | 미국장은 코어·5D swing·전술·이벤트로 분리 |
| 매수가 없으면 개장 후보를 늘릴 수 있음 | 개장+5/+15 비용 후 음수라 확대 금지 |
| 7/10 슬롯은 스테일일 수 있음 | 7/16까지 정상 5거래일 계약으로 명시 |
| preflight configured shadow 표기 | runtime config 기준 micro 요청과 연구 demotion을 분리 표기 |
| 그럴듯한 촉매/VWAP 규칙을 바로 적용 | point-in-time ledger에서 검증 후 shadow만 |

최종 판정: 미국장을 그냥 두는 것이 아니라, 수익 근거가 없는 개장 추격을 버리고
`SCHG/BIL 코어 + bounded US_SWING_5D + 선택적 PathB + PEAD/second-day challenger`로
미국장 고유 구조를 확정한다.
