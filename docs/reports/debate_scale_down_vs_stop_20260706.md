## 핵심 통찰 — 이미 "소프트 스로틀" 상태
현재 reward_risk 컷 + REQUIRE_TRADE_READY_BLOCK로 **fill이 거의 0**이다. 즉 지금 이미 "손실 ~0, 검증 ~0"의 멈춤에 가까운 상태. 그래서:
- **현상유지(스로틀)** = 손실 0 · 검증 0 (PRO의 스로틀 갈래)
- **검증하려면** = 게이트 완화 + 소액 → fill 재개 → 검증 시작 + 소액 출혈 (CON)
- **중단** = 인프라 off = 비가역

## 갈림 = 옵션가치 (데이터가 크기만 주고 결정은 운영자)
- **PRO "양갈래 음NPV":** 검증하려면 활성국면 출혈 감수(US −0.5~−1.0), 안 하면 표본 0. 방어 최선이 본전이라 검증 도달 전 출혈 > 상한 이득 → US는 중단급 축소.
- **CON "소액 옵션가치":** 소액이면 출혈 월 수만원 캡, 라이브 forward는 비가역(끄면 못 얻음) → 소액 유지 + funnel(게이트 완화).
- **결판 명제:** "wait-cost < 방어 최대이득(본전)인 시평 안에 forward 검증이 완료되나?" → red-tape 비-6월 n≥20 도래가 현 페이스로 수개월~무기한(6월 편중 50/53). **데이터는 '느리다'까지, '가치 있나'는 운영자 리스크선호.**

## 실행 함의 (데이터 지지, 승인은 운영자)
1. **US 주문금액 대폭 축소** — 출혈원. 예: 50만→10만(최악월 손실 월 ~8만 캡). 역산 근거(최악월 실측 −42.8만/5).
2. **KR 유지·관찰** — 유일 비음 세그먼트(단 n=36 미검증, 승자 아님).
3. **검증을 원하면 게이트(REQUIRE_TRADE_READY 등, 가역 config) 완화로 fill funnel 확보** — 안 하면 소액 존속도 학습 0. 이건 운영자 결정.
4. **전면 중단은 데이터 미지지** — 단 "현상유지=이미 스로틀(손실0 검증0)"이라 중단과 실질 손익 차이는 인프라 on/off뿐.

## 정직 flag
- US 손실 −29.5만은 실재하나 US 6월 단일월(−42.8만)에 집중 — 국면 confound. US 6월 빼면 통산 +13.3만.
- forward "검증 계속"은 게이트가 fill을 내야만 유효. 현재 게이트로는 소액 존속도 학습 0.
- KR +0.325는 n=36·중앙값 −0.94 = 최소악·미검증이지 검증된 엣지 아님.
- 어느 선택도 흑자 아님(천장=본전). 이 토론은 "얼마나 잃으며 무엇을 배우나"의 문제.
