# 사전등록 초안 — 2027 Q1 후보: MSCI Korea 분기 리뷰 신규 편입 (2026-10-31, 미등록)

**상태: 초안이다. 등록은 2027 Q1 분기 창에서 운영자가 정한다**(`docs/operating_model.md` §4, 분기당 새 가설 ≤ 3).
이 문서를 커밋하는 시점까지 편입 종목의 수익률은 계산하지 않았다. 가격 파일은 받았지만 봉 존재 여부만 셌다.
등록 전에 바꿀 수 있는 칸은 맨 아래 "운영자 확인"뿐이다.

## 이미 알려진 사실 (사후 맞춤 경계)

- 문헌: MSCI 국가지수 편입은 발표 다음 날 +3.4%, 이후 효력일까지 +4.5%다(J. Empirical Finance 2019, `strategy_research_scan_20261005.md` §1). 2026-08 LG이노텍 +6.3%(기사).
- L7(KOSPI200·KOSDAQ150 정기변경)은 같은 메커니즘(패시브 수요)으로 통과했다(t 4.82). 다만 엣지는 KOSDAQ150 쪽이고 KOSPI200 단독은 t 1.79다. MSCI 편입 종목은 대형주라 KOSPI200 쪽에 가깝다 — 통과를 기대할 근거와 의심할 근거가 같이 있다.
- 표본 겹침: MSCI 편입 88건 중 L7 편입과 30일 안에 같은 종목인 경우는 **2건**뿐이다(성과 아닌 명단 대조). L7과 사실상 독립 표본이다.

## 가설

| 항목 | 값 |
|---|---|
| 메커니즘 | MSCI Korea 추종 패시브 자금은 리밸런싱일 종가에 신규 편입 종목을 산다. 발표~리밸런싱 약 12거래일의 선행 매수 |
| 표본 | `data/analysis/q1_kr_passive_2027/msci_korea_changes.csv` action=add 88건, 리뷰 51회(2014-02~2026-08) 중 편입 있는 37회. 종목코드는 DART 명칭 이력과 대조 완료(172 직접 일치·31 사명 변경) |
| 진입 | **KST 발표일 당일 또는 그 이후 첫 KR 거래일 시가**(장전 시장가). MSCI는 미국 장 마감 후 발표하므로 KST로는 다음 날 장전이다. 발표일이 휴장인 회차 2개(2015-08-14 임시공휴일, 2024-05-15 부처님오신날)는 다음 거래일 시가 |
| 청산 | 리밸런싱일(MSCI "as of the close of") 종가, 그날이 휴장이면 그 이전 마지막 KR 거래일 종가. 장 마감 동시호가 시장가 |
| 비용 | 왕복 0.25%(L7과 같다) |
| 벤치 | 규모매칭(dv20 십분위, L7 엔진 `research_kr_index_inclusion_20261030.py` Book 그대로)이 주, 069500이 보조 |
| t | 리뷰 클러스터(같은 리뷰의 편입 종목 평균 = 1관측, 37개) |
| IS/OOS | IS 2014~2019(15회) / OOS 2020~(22회) |
| 합격 | 클러스터 t ≥ 2.64 **그리고** IS·OOS 같은 부호(+) **그리고** 양 클러스터 과반 |
| 기각 | 위 셋 중 하나라도 미달 |
| 검정 불가 | 진입·청산 봉이 있는 편입이 90% 미만, 또는 가격 있는 클러스터 < 30 |
| 보조(판정 제외) | ① 발표 직전 종가 → 진입 시가 갭(우리가 못 먹는 몫의 크기) ② 069500 대비 ③ 리밸런싱 후 H20 반전(편출 115건 포함 — L7 보조와 같은 형식) ④ L7 겹침 2건 제외 |
| 통과 후 | L7과 같은 계약이므로 L7 도구에 MSCI 회차를 붙이는 안을 운영자에게 제안한다(회차당 금액은 운영자 결정). 명단 입력은 L7과 같은 수작업 절차로 한다(MSCI 데이터 이용 약관은 확인하지 않았다) |
| 반대 근거 | ① 대형주 — L7에서 KOSPI200 단독은 t 1.79였다 ② 발표 반응의 상당 부분이 장전 갭으로 들어가 우리 진입 전에 끝날 수 있다(보조 ①로 크기를 본다) ③ 2024 이후 국내 공매도 금지 기간(2023-11~2025-03)이 OOS 일부를 덮는다 ④ 변경 없음 리뷰 10회 중 9회는 MSCI 명단 단일 출처(국내 기사 미확인) |
| 환산식 | 회차당 투입 × 회차 평균 초과 × 연 약 3회(37회 / 12.5년) |
