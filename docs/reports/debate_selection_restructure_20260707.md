# 토론 판정: Selection 재편(rule 압축 + Claude 가격플랜/매수타이밍 + 분업 매도)은 옳은 재편이고 성패는 쟁점1·2에 달렸는가 (2026-07-07)

- 명제: "①폭넓은 스크리너 → rule이 trade_ready 압축(Claude select_tickers 제거) → ②Claude는 후보별 가격플랜+매수타이밍만 → ③매도는 결정론 TARGET(주력)+hold advisor(오버레이) 분업 — 이 현 구조보다 수익성 방향으로 옳고, 성패는 쟁점1(rule 압축 전략)·쟁점2(가격플랜 payload)에 달렸다."
- 설계정의 초안: `docs/reports/design_definition_draft_20260707.md`
- 방식: PRO/CON 독립 입론(read-only) → 사회자 직접 sqlite 재검증. 데이터: `data/ml/decisions.db` v2_learning_performance CLOSED(net 有 n=314, 2026-04-27~07-03), 교차 `data/v2_event_store.db` v2_path_runs.

---

## 판정

**명제 (a) "옳은 재편이다" = 부분 찬성** — 무알파 selection 제거 + 검증엣지 보존 분업은 **안전한 정리(refactor)로서 옳으나, 그 자체로 수익 레버가 아니다(net 중립).**
**명제 (b) "성패는 쟁점1·2에 달렸다" = 기각** — 성패는 쟁점1·2가 아니라 **① US 비용(구조적) ② 엔트리측 손실(LOSS_CAP, 산 직후 하락) ③ 측정 불가(데이터 위생)**에 달렸다. 특히 **쟁점2(payload 결정론화)는 검증된 유일 엣지를 깰 위험**이라 방향이 반대다.

한 줄: **재편은 해도 되는 정리지, 흑자로 만드는 레버가 아니다. 하려면 (1) 측정 배관부터 깔고(pool_role 공란·KR fee 오라벨·mfe 23% 커버리지) (2) Claude 가격플랜은 유지해 TARGET 엣지를 보존하며(payload 결정론화 금지) (3) select_tickers 랭킹만 shadow 동등성 확인 후 제거한다.**

## 2. 합의 / 불일치 / 미검증

**합의 (양측·검증 일치)**
- select_tickers(Claude 종목선정)는 무알파(AUC 0.507) — 제거해도 성과 하락 위험 낮음. 다만 그것이 **개선은 아님**.
- 검증된 매도 엣지의 83%는 **결정론 TARGET**(hold advisor 아님). "전부 hold advisor로"는 +138 폐기 → **분업(결정론 TARGET 주력 + hold advisor 오버레이)이 데이터가 지지하는 유일 배치.** (명제 ③은 옳다.)
- 가격플랜은 selection과 같은 프롬프트 산물 → select_tickers 제거 시 **Claude 가격플랜 생성은 반드시 보존.**

**불일치 → 사회자 판정**
- 쟁점1(rule 압축이 개선인가): **미결로 판정.** pool_role 공란(V4)이라 rule 압축의 net 기여를 측정 불가. select_tickers가 무알파여도 "스코어 랭킹이 net 상위"는 별개 명제·미입증. **rule 압축은 위험 낮은 중립 스왑이지 수익 레버가 아니다.**
- 쟁점2(payload 결정론화가 성패 소재인가): **기각.** TARGET 승자(+5.13, 견고 V3)는 **부풀린 목표에 도달해** 러너를 태운 결과. sell_target을 ATR/저항으로 낮추면 이 구간을 **잘라낸다**(CON). 반면 진짜 드레인 LOSS_CAP은 mfe≈0이라 목표 변경과 무관(V6). **payload 결정론화는 net을 못 올리고 유일 엣지를 깰 위험.** reward_risk 게이트 장식화는 사실이나 net 레버가 아니라 게이트 무결성 이슈.
- "성패가 쟁점1·2에 달렸다"(PRO) vs "비용·손실·국면에 달렸다"(CON): **CON 우세.** US 비용 −0.33/거래(V5)·LOSS_CAP 엔트리손실(V6)이 net을 지배. selection 재편은 이 둘을 1%p도 안 건드림 = **net 중립 리팩터**(CON 규정 타당).

**미검증 (재편 전 선결 = 측정 배관)**
- pool_role을 채워야 rule 압축 전/후 net 귀속 가능(현재 100% 공란).
- KR fee 오라벨(43건 0.5) 수정 전 KR net 판정 불가.
- mfe 커버리지 23% → 엔트리품질·capture 판정 저출력.
- select_tickers 제거 후 TARGET 도달 분포 불변 여부 = **shadow 동등성으로만 확인 가능**(사전 증명 불가).

## 3. 명제별 최종 답변

- **③ 분업 매도**: 데이터가 명확히 지지(TARGET 주력, hold advisor 오버레이). hold advisor 권한 확대는 반대 — 그 소산 INTRADAY_SELL은 −37.9(n=28, 승률 14%)로 드레인(단 counterfactual상 죽을 포지션의 저가 기록이라 신규 손실은 아님, 7/7 검증). **buy_time_confirm(쟁점4)은 DB 귀속 불가 → 이 재편에서 건드리지 않는다.**
- **① rule 압축 / ② payload**: 성패 소재 아님. ①은 측정 불가한 중립 스왑, ②는 엣지 파괴 위험. **명제 (b) 기각.**
- **(a) 재편 방향**: select_tickers(무알파) 제거 + Claude 가격플랜 보존 + 분업 매도는 **안전한 정리로서 옳다.** 토큰·레이턴시·자기검열층을 줄인다. **단 수익 전환은 아니다.**

## 4. 재편을 한다면 — 안전 실행 순서 (수익 방향 유지)

명제가 "흑자 레버"는 아니어도 "안전한 정리"로서 가치가 있으므로, **하려면 이 순서**:

1. **[선결·측정] 배관부터**: `candidate_pool_role` 채우기(재편 전/후 귀속 가능하게) + **KR fee_pct_round_trip 오라벨 수정**(43건 0.5→KR 실측) + mfe 백필 이어가기. 이거 없이 재편하면 **개선 여부를 영원히 모른다.**
2. **[보존] Claude 가격플랜 유지**: select_tickers의 "종목 랭킹"만 제거, "가격플랜(존/목표/손절) 생성"은 Claude가 계속. **payload 결정론화(ATR 목표)는 하지 않는다**(V3·V6 근거). 검증엣지 TARGET 보존.
3. **[shadow] rule 압축 동등성**: rule trade_ready 세트 vs 현행 Claude trade_ready 세트를 **동시 shadow 로깅**해 후보풀·진입분포·(백필된 pool_role 기준) forward-net 동등성 확인 후에만 Claude 랭킹 제거.
4. **[분업 확정] 매도**: 결정론 TARGET 주력 + hold advisor 오버레이 현행 유지. 권한 확대 금지.

## 5. 진짜 수익 레버는 어디에 (재편 밖)

selection 재편이 net 중립이므로, 흑자 방향은 여전히 **비용·엔트리손실·저회전**:
- **US 비용**: net 드래그 −0.33/거래가 구조적. 이 DB의 net은 이미 FX≈0 반영(US net −36.9, 설계의 −74보다 나음) → **FX 실측 확정 시 US는 본전권에 근접.** 남는 건 회전 축소(진입 1건 회피=+0.33).
- **엔트리손실**: LOSS_CAP(mfe≈0)은 예측 불가(무알파)라 못 고름 → 손실 **크기**를 줄이는 red-tape·변동성 타게팅 사이징이 유일 핸들.
- **KR**: 흑자 미확립(fee 버그 수정·비용모델 확정 후 재판정). 증거로 쓰지 말 것.

## 6. 토론이 생산한 새 지식 (메모리 승격)
1. **검증엣지 재확정(decisions.db 정본)**: TARGET +138.5(n27, 100%승, **outlier 아님** ex-top2 avg +4.47), CLAUDE_SELL +28.0. 나머지 −250. hold advisor는 엣지의 14%뿐.
2. **재편은 net 중립 리팩터** — 손실은 엔트리측(LOSS_CAP mfe≈0)·비용(US −0.33)이지 selection 배관 아님.
3. **payload 결정론화 금지 근거 강화**: 부풀린 목표가 러너(+5.13)의 원천, ATR 결정론화는 이를 절단.
4. **데이터 위생 3결함**(재편 선결): pool_role 100% 공란·**KR fee 오라벨(43건 US 0.5)**·mfe 23% 커버리지.
5. KR "흑자 +11.72"는 비용모델(0.09 가정) 의존 — 거래세 반영 시 음전, 견고하지 않음.
