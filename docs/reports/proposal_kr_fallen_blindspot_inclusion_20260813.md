# 제안: KR fallen 사각(장중 회복형 R4) 후보 편입 — 사전등록

작성 2026-08-13. **미승인 제안** — 승인 문구: "사각 편입 승인". 승인 전 live 행동 변화 없음.

## 1. 배경 (실측 완료)

스캔 포함 기준(당일 종가낙폭 ≥5.27%)과 R4 갭 기준(−4%)의 어긋남으로, 갭 하락 후 장중
회복한 R4 형태(gap≤−4 & ma20_disc≤−15) 종목이 그물 밖이었다. 이중 소스 검증:

| 소스 | 표본 | 평균 net/건 | 승률 | SL |
|---|---|---|---|---|
| 외부(네이버, 2026-01~08) | 105 | +5.69% | 76% | 2 |
| 내부(정본 캐시+정본 정산, backfill) | 105 | +6.55% | 76% | 2 |

월별 3~7월 전부 양수(+1.83~+9.85). 관측 원장은 08-13부터 forward 가동 중(커밋 9b03897).

## 2. 실효 증분 (동일 창 재구성, 캐시 2~8월 57후보세션)

- 포착(R2/R4) 세션 48 / 사각 세션 28 — **사각 단독 9세션** (일1건 캡 기준 실효 증분 ≈ 월 1.4건, 세션 커버 +19%)
- 사각 단독 top1(할인깊은순) 정산 9건: **+5.91%/건, 승률 6/9**
- 겹침 19세션 중 5세션은 사각이 할인 더 깊어 1순위 대체(E5 검증 랭킹의 일관 적용)

기대치는 "월 +1~2건 × 건당 +5%대"의 완만한 증분이다. 과대 포장 없음.

## 3. 설계

- **스위치**: `KR_FALLEN_BLINDSPOT_ENTRY_ENABLED=true` (기본 false).
  `.env.live`+`config/v2_start_config.json` 두 소스 일치, 재시작 후 effective-config 실측까지가 활성 조건(관례).
- **브리지**(`runtime/kr_fallen_order_bridge.py` `_load_candidates`): 플래그 on일 때
  사각 원장(`kr_fallen_blindspot_shadow.jsonl`)의 직전 세션 행도 로드해 동일 `rule_flags` 평가.
  `KR_FALLEN_ACTIVE_RULE` 문자열·파서는 **불변** — 사각 행은 R4 형태이므로 R4가 활성일 때만 자연 편입.
  행에 `_capture_path="blindspot"` 태그. 같은 종목이 양쪽에 있으면 본 원장 우선. 통합 정렬은 할인 깊은 순(현행 E5).
- **불변 항목**: 일1건·슬롯3, TP12/SL25/D5·30만, 진입창 개장 2~20분, 극단 갭업 가드(+10%), 재진입·중복 가드 전부 그대로.
- **귀속**: handoff history `_matched_rules`에 `R4b` 표기 + 주문 selected_reason 태그 —
  실거래 정산에서 사각 경유분을 분리 집계 가능(순증분 분해).

## 4. 사전등록 반증 기준 (게이트)

1. 사각 경유 **실거래 정산 10건** 누적 net ≤ 0 → 스위치 off (관측 원장은 유지)
2. 사각 경유 월 net **두 달 연속 음수** → off (US_GAP_PULLBACK 관례)
3. SL(−25%) 2건 도달 시 중간 점검 보고 (자동 off 아님)

## 5. 리스크 (정직 고지)

- 진입가: 회복 지속 시 D+1 시가가 높음 — 백테스트가 이미 D+1 시가 기준이라 net에 반영, 상단은 갭업 가드가 차단.
- 6월 약세(+1.83%/건, n=34): 다발월에 증분 효율 저하 가능. 반증 기준 2가 방어.
- 1순위 대체(겹침 19 중 5): 본 원장 후보 대신 사각을 살 수 있음 — 검증된 랭킹(할인 깊은 순)의 일관 적용이며, 귀속 태그로 사후 분해 가능.
- 검증 표본은 시뮬 정산(D+1 시가 가정)이지 live 체결이 아님 — 그래서 실거래 10건 게이트를 둔다.
