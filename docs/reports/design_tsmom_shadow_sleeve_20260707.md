# 설계: 저회전 TSMOM 추세추종 sleeve — shadow 병렬 검증 (2026-07-07)

지시: "2번 — 별도 저회전 TSMOM 바스켓을 진입 없이 shadow로 병렬 운용해 우리 net 기준으로 검증." 운영자 옵션 2 채택.
근거: `docs/reports/gross_alpha_hunt_verdict_20260707.md` §5d — TSMOM(12m 모멘텀) 다국면 Sharpe 1.24·EW 초과 +4.7%/yr·하락장 방어, 저회전이라 비용 생존. 우리 단기추격 시스템과 정반대 게임.
성격: **설계 문서(분석). 라이브 코드 미변경.** 적용은 운영자 승인 후.

## 0. 이 sleeve가 검증하는 것 / 못 하는 것

- **검증**: "우리가 접근 가능한 종목·우리 실제 비용(수수료·FX·거래세)·우리 시장(KR/US)에서, 장기 TSMOM 추세추종 저회전 바스켓이 net 양수 + 우리 현 시스템/벤치 대비 우위인가."
- **못 함**: 백테스트의 생존편향(현 구성종목)은 forward가 부분 해소하나 완전 제거 못 함. 절대수익 크기는 상단치. **판정 기준은 항상 우리 실제 net(우리 보유기간·비용).**
- **핵심 원칙**: 이건 현 시스템을 대체하는 결정이 아니라, **자본 투입 전 페이퍼로 게임 전환을 실측**하는 실험이다. 라이브 경로·brain·risk·주문과 완전 격리.

## 1. 2-arm 구조 (빠른 확정 + 느린 OOS)

```
Arm A (즉시, 오프라인 백테스트) ── 우리 실제 비용모델·KR+US·다국면 재확인
   └─ 통과 → Arm B 착수 정당 / 실패 → 중단(운영자 보고)
Arm B (forward 페이퍼 sleeve) ── 월 리밸런스 실시간 추적, 우리 net, 판정게이트
   └─ N개월+하락장 통과 → 소액 라이브 sleeve(운영자 결정) → 점진 스케일
```

Arm A가 선결(빠르고 싸다). Arm B는 Arm A 통과 시에만.

## 2. Arm A — 오프라인 백테스트 (우리 비용모델, 즉시)

트랙① 백테스트를 **우리 실제 비용·KR 포함·우리 판정기준**으로 재실행. 신규 코드 = read-only 분석 스크립트 1개(`tools/tsmom_sleeve_backtest.py`, 라이브 무접촉).

- **유니버스**:
  - US: S&P500 + 유동성 상위(현 data/price/us 교집합). 안정·광역·day_gainers 아님.
  - KR: KOSPI200 + KOSDAQ150 유동성 상위(data/price/kr 교집합). **트랙①은 US만 했으므로 KR은 여기서 처음 검증** — KR gross 음수라 KR TSMOM이 사는지 별도 확인 필수.
- **신호(파라미터 고정, 서치 금지)**: 12-1 모멘텀(트레일링 12개월 수익, 최근 1개월 제외) + 200d MA 위 필터, 롱온리. 상위 5분위(또는 상위 N=20~30 분산) 선택, 동일가중, 월 리밸런스.
- **비용모델(우리 실측)**: US 왕복 0.50% + FX(환전내역 확정 전이면 0.20 상한/0 하한 양쪽 제시) / KR 왕복 0.21%(수수료+거래세). 회전×비용을 net에서 차감.
- **판정(pre-registered)**: (a) net CAGR·Sharpe, (b) 벤치(EW·SPY/KOSPI) 대비 초과·t, (c) 국면별 방어(하락기 EW 대비), (d) **우리 현 시스템 통산 net(−80)과 대비**. 시장별 분리.
- **통과 조건**: US·KR 각각 net 양수 + 다국면 방어 재현 + 상승장 반납이 전체 net을 음전시키지 않음(TSMOM은 상승 참여했음). 실패 시(특히 KR 음전) 해당 시장 중단.

## 2b. Arm A 실행 결과 (2026-07-07, `tools/tsmom_sleeve_backtest.py`, 우리 비용모델, 2016~2026)

리포트: `docs/reports/tsmom_sleeve_backtest_result.json`. 파라미터 고정(12-1 모멘텀+200dMA, 상위5분위, 월리밸런스). 비용=우리 실측(US 0.50%RT+FX{0,0.20}, KR 0.21%RT).

| 시장 | 전략 | CAGR(net) | Sharpe | MDD | EW 대비 초과(t) |
|---|---|---|---|---|---|
| **US** (S&P500 500종목) | TSMOM | 19.65% | 1.02 | −24.9% | **+1.89%/yr (t 0.61)** |
| | EW 벤치 | 17.81% | 1.01 | −27.8% | — |
| | SPY | 15.5% | 0.95 | −24.1% | — |
| **KR** (유동주 246종목) | TSMOM | 31.64% | 1.09 | **−44.7%** | **+5.53%/yr (t 1.22)** |
| | EW 벤치 | 26.74% | **1.17** | −30.4% | — |
| | KOSPI | 17.15% | 0.82 | −34.1% | — |

**정직한 판정 — TSMOM은 명확한 알파가 아니다:**
- **양 시장 모두 EW 초과가 통계 비유의**(US t0.61, KR t1.22). 생존편향은 EW·TSMOM을 같은 유니버스로 똑같이 부풀리므로 이 **상대 비교는 survivorship-통제** → 그런데도 유의성 없음 = **모멘텀 틸트가 EW 대비 robust 알파를 못 준다.**
- **KR에선 TSMOM이 EW보다 risk-adjusted 열위**(Sharpe 1.09<1.17, MDD −44.7%≫−30.4%). 모멘텀 집중이 KR 변동·드로다운만 키움. KR 2023-25 +269pp는 outlier.
- **비용은 확실히 이긴다**(회전 ~60%/월, FX 0.20 비관에도 US 18.82%): 저회전이라 비용 강건 — 우리 일중 회전과 정반대. 이건 mechanically 확실.

**하지만 진짜 대비가 드러났다 (설계의 실제 근거로 교체):**
- **양 시장 EW 저회전 롱홀드 바스켓 = net +17.8~26.7%/yr**(비용 차감), 지수도 상회. **같은 시장에서 우리 현 시스템은 net 음수.** 즉 **손실원은 시장이 아니라 우리의 고회전 능동매매**다. (KR "gross 음수"는 KR 시장이 아니라 우리 day_gainers 회전 탓임이 여기서 확인 — KR EW 바스켓은 +26.7%.)
- ★단 EW 절대치(+18~27%)는 **생존편향 상단치**(현 구성종목·상폐 제외). 실제는 하향.

**수정된 결론**: Arm A는 **TSMOM(모멘텀 신호)을 명확한 레버로 확정하지 못했다**(EW 대비 비유의, KR은 열위). 확정한 것은 ①**저회전이 비용을 이긴다**(mechanically) ②**저회전 분산 롱홀드가 우리 고회전 능동매매를 크게 상회**(단 survivorship 상단치). → sleeve의 핵심 가설을 "TSMOM 알파"에서 **"저회전 분산 롱홀드로 회전·매매강도를 죽인다"**로 교체. 모멘텀/추세는 MDD 관리 오버레이(US에서만 소폭 도움)로 격하. Arm B는 TSMOM **과 함께 순수 EW 분산홀드를 동등 벤치로** 추적해 우리 net 기준 판정.

## 2c. 생존편향 통제 심화 (2026-07-07, `scratchpad/deepen.py`) — 저회전 가설의 실체 규명

회전빈도·분산도·비용 sweep + **지수(생존편향-free, 실투자 가능 ETF) 바닥**으로 저회전 가설을 통제.

| 지표 | US | KR |
|---|---|---|
| **지수 buy&hold (생존편향-free 바닥)** | **CAGR 15.5%** Sharpe 0.95 | **CAGR 17.1%** Sharpe 0.82 |
| EW 저회전 홀드(전종목) | 17.8% (회전 1~2%/reb) | 26.7% (회전 2%/reb) |
| TSMOM | 19.6% | 31.6% (Sharpe·MDD는 열위) |
| 비용 민감도(월EW) | 0%=17.8 / 우리=17.8 / 2×=17.7 | 전부 26.7 |

**규명된 사실:**
1. **생존편향-free 바닥 = 지수**(SPY +15.5%/yr, KOSPI +17.1%/yr, net, 2016~2026). 실제 매수 가능(ETF)하고 생존편향 없음. **같은 기간 우리 능동 시스템은 net 음수.**
2. **EW의 지수 초과분(US +2.3%p, KR +9.6%p)이 생존편향 거주지.** 특히 KR EW +26.7%는 "현 유동주 246"이 죽은 종목을 뺀 탓 = **과대**. 정직한 "저회전 분산홀드" 값은 EW(+18~27%)가 아니라 **지수(+15~17%)에 가깝다.**
3. **비용은 저회전에서 무의미**(EW 회전 1~2%/reb → 0/우리/2× 비용 전부 동일 CAGR). 저회전이 비용 이기는 mechanism 확정. 우리 문제는 고회전.
4. **TSMOM/모멘텀은 생존편향 통제 후 지수·EW 대비 robust 추가 없음**(US 19.6 vs 15.5 지수, KR은 Sharpe 열위). 모멘텀 신호는 레버 아님.
5. **분산도·리밸런스빈도 무관**(EW N=10~all, 월~연 전부 ~17%): 저회전이면 어떻게 짜든 지수 근처.

**★결정적·정직한 결론**: 생존편향을 통제하면 "저회전 분산홀드"의 실체 = **지수 수익(+15~17%/yr net)**이다. 이건 **알파가 아니라 2016~2026 상승장 베타**다(2022 약세장 슬라이스에선 지수도 −8%). 즉:
- **survivorship-clean·robust 발견 = "우리 고회전 능동매매가 패시브 보유 대비 가치를 파괴한다"**(음의 알파). 레버는 트레이딩 엣지가 아니라 **회전 축소 / 패시브 노출**이다.
- 그러나 그 패시브 수익은 **상승장 베타(국면 의존, 반복 보장 없음)** — "그냥 지수 사면 번다"가 아니라 "우리 능동매매가 지수보다 못하다"가 정확한 명제.

**이건 운영자 전략 결정 사안이다**(중단·방향전환=운영자): ① 능동 시스템의 음의 알파를 인정하고 저회전·패시브 광역노출로 전환(베타 포획+churn 드레인 제거, 단 국면의존 베타) vs ② 능동 시스템 유지(천장이 패시브 아래임을 인지). 데이터는 ①이 ②보다 이 표본에서 나았다고 말하나, ①의 수익은 알파가 아니라 베타다.

## 3. Arm B — forward 페이퍼 sleeve (기존 shadow 관행 위에)

`data/shadow/` 관행(codex_shadow: portfolio jsonl + snapshots + excess_report) 차용, 메서드 id `tsmom_sleeve_v1`. 신규 코드 = 트래커 도구(라이브 경로·주문·brain 무접촉, 오직 가격 읽기 + 페이퍼 장부 기록).

### 3.1 데이터·신호 파이프라인
- 가격 소스: 기존 `data/price/{us,kr}` 일봉(일 1회 갱신 잡 존재 가정 — 없으면 도구가 yfinance/KIS로 종가 append, read-only 확장). 분봉 불필요(일봉·월 리밸런스).
- 매 리밸런스일(월 1회, 예: 매월 첫 거래일 장 마감 후) 신호 계산 → 목표 바스켓 확정.

### 3.2 페이퍼 장부 (data/shadow/tsmom_sleeve_portfolio_{YYYYMM}_{MKT}.jsonl)
- `book_rebalanced` 이벤트: 리밸런스일, 시장, method=tsmom_sleeve_v1, 선택 종목·목표비중·기준가(리밸런스일 종가)·신호값(모멘텀·MA거리), 가정 비용(진입 회전×비용).
- 페이퍼 자본 = 명목 고정(예: US $10k, KR 1천만원 — 실측용 스케일, 실제 자금 아님). 동일가중 분산.

### 3.3 스냅샷·MTM (data/shadow/tsmom_sleeve_snapshots_{...}.jsonl)
- 일 1회(장 마감 후) 보유 바스켓 종가 MTM, 누적 net(비용 차감), 벤치(SPY/KOSPI) 동시각 대비 excess 기록.

### 3.4 excess/net 리포트 (data/shadow/tsmom_sleeve_net_report_{MKT}.json)
- 월별·통산 net(우리 비용모델), Sharpe, MDD, 벤치 대비 초과, 하락월 방어. codex_shadow_excess_report.py 패턴 재사용.

### 3.5 격리 계약 (필수)
- 라이브 진입·주문·brain.json·risk_manager·action_routing 무접촉. 페이퍼 장부는 data/shadow/ 전용 파일에만 기록.
- 현 시스템 자본·포지션과 무관(가상 명목). 실패해도 라이브 무영향.
- read-only: 가격 CSV 읽기 + shadow 파일 쓰기만.

## 4. 판정 게이트 (Arm B, pre-registered)

**최소 관측**: 6개월 + 최소 1회 시장 조정(하락월) 포함. 이상적 12개월.

**graduate(소액 라이브 sleeve 검토, 운영자 결정) 조건 — 전부 충족**:
1. 통산 net(우리 비용모델) 양수, 시장별 분리 양수.
2. 벤치(SPY/KOSPI 매수보유) net 대비 우위 or 동등+저MDD.
3. 하락월에 벤치 방어 재현(Arm A 국면분해와 방향 일치).
4. 현 시스템 동기 net 대비 우위(같은 기간 라이브 net과 비교).

**kill 조건(어느 하나)**: 통산 net 음수가 6개월+하락장 포함에도 지속 / 방어 미재현(하락월에 벤치보다 더 빠짐) / Arm A와 부호 상반.

**중립/연장**: 상승장만 겪어 방어 미검증이면 하락장 도래까지 관찰 연장(정지 아님).

## 5. 현 시스템과의 관계 (자본·운영)

- **shadow 단계: 자본 0**(페이퍼). 현 시스템 그대로 운영, 병렬 관측만.
- **graduate 시**: 신규 소액 라이브 sleeve로 시작(현 시스템 자본 전용 아님, 별도 배정 — 운영자 결정). 현 시스템 축소·대체 여부는 sleeve 라이브 실측 후 별도 판단(운영자만).
- 두 시스템은 다른 게임(단기 vs 장기)이라 공존 가능. sleeve는 현 시스템의 위생·측정 배관과 독립.

## 6. 정직한 한계·리스크

- **생존편향**: 유니버스 정의(현 구성종목)에 상방 편향. forward가 부분 해소. 절대수익은 상단치로 읽는다.
- **롱온리**: TSMOM 볼록성의 절반만(하방 숏 프리미엄 못 먹음). 방어는 "현금/미보유"로만 = 상승 미참여 반납.
- **t 1.82 경계**: Arm A 초과가 통계 경계 → forward가 진짜 판정. 백테스트 수치 인용 시 "상단치·경계" 병기.
- **KR 미검증**: 트랙①은 US만. KR TSMOM은 Arm A에서 처음 확인 — 음전 가능(KR gross 음수 이력). 시장별 독립 판정.
- **느림**: 월 리밸런스라 판정에 6~12개월. 이건 저회전의 본질(비용 이기는 이유)이자 검증 비용.
- 규율 유지: 파라미터 서치 금지(고정값), OOS(forward 자체가 OOS), outlier·국면 분해, 우리 실제 net 기준.

## 7. 실행 순서 (운영자 승인 후)

1. **Arm A 백테스트** (`tools/tsmom_sleeve_backtest.py`, read-only): US+KR, 우리 비용모델, 다국면. 결과 리포트. **KR 통과 여부가 관문.**
2. Arm A 통과 시 **Arm B 트래커** (`tools/tsmom_sleeve_tracker.py`, shadow 전용): 월 리밸런스 페이퍼 장부·일일 MTM·net 리포트. cron 또는 세션 훅으로 일 1회.
3. 6~12개월 forward 누적 → 판정 게이트 평가 → graduate/kill/연장 (운영자).

## 8. 승인 필요 사항 (운영자)
