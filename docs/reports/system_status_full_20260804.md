# 시스템 전체 현황 — 실패의 목록, 살아남은 것, 방향 (2026-08-04)

운영자 요청으로 작성한 전면 현황 정리. 개별 수치의 정본은 각 링크 문서.

## 1. 큰 그림

6~7월의 시스템은 "Claude 실시간 선정 + 다층 게이트" 복잡계였고 통산 적자였다. 두 달간 수십 개 가설을 실측으로 기각한 끝에 8/1 전면 재구성으로 **"급락 저평가를 코드로 골라 소액 비대칭 계약으로 수확"** 단일 축에 도달했다. 현재는 검증 표본 축적 단계이며 첫 실측들(FRMI +9%대 진행, KR 1호 정산 TP +11.75%, R2 2년 재현)이 방향을 지지한다.

## 2. 실패로 판정된 것 — 다시 하지 않는다 (전부 실측 근거)

**선정·예측 계열:**
- Claude 실시간 종목 선정 — KR 역선별(−4.65%), US 무의미
- confidence 점수 — 예측력 없음(r=−0.04, n=271)
- 진입 선정 강화 전반 — 데드엔드 판정(KR 신호 부재, US gross가 비용 아래)
- 스크리너 리랭킹 · 조기 진입(개장 0~15분 최악) · 문구 주입 · 브레인 예측 개선
- KR 알파모델 — 리프트 없음(p=0.70)
- US 하드필터 단독 매매 — 2025 OOS에서 절대 수익이 4월 1개월 의존(제외 시 −0.35%), 깔때기로만 유효

**보유·청산 계열:**
- 조기익절(목표 40%) — 역대 최대 손실원
- 무기한 보유 — 만장일치 기각(미청산 37~49%가 −24~−47% 물림, "우위"는 강세장 창 편향)
- 트레일링 완화(42조합 전멸) · TP+20/D10(월별 부호 반전) · 급등 추격(전 국면 음수 EV)

**정의 계열:**
- 단순 하락상위 매수 — 36조합 전부 음수
- 얕은 할인(−15% 단독) — 무가치(−0.02~−0.38)
- 60일 장기 창 — 구조적 하락주를 잡아 전부 음수
- recall 확장 — 완화 시 +4.53→+0.33 붕괴. 놓친 반등의 82%는 모멘텀형(다른 레인의 동물)
- gainers/actives 소스 — 역선별 (AXTI 손실 신호 3건의 출처)

**방법론·운영 계열 (돈만큼 비쌌던 교훈):**
- 하루 수익으로 전략 판정 (AXTI 오판의 원죄)
- shadow 회계 ≠ 실거래 규약 (−239%p 착시)
- lookahead 변종 — "완전관측 창" 강세장 편향 · preopen 기준가 편향 · t+2 시뮬값 라이브 주입
- 단편 시뮬로 라이브 방향 뒤집기 (하루 3회 사건)
- 마스터 스위치 도입 시 검증기 미갱신 (가디언 BLOCK_START 사건)
- 해시 고정 계약 파일 수정 (top_k 사건 — 매수 차단 직전 e2e가 적발)
- 장중 유니버스 시세 루프 (KIS 레이트리밋 사고)

## 4. 현재 구조

```
[실매수]  US us_swing micro만 — rank1×30만×일1건, 슬롯3 (forward 1/30 진행)
[shadow]  KR 3파전(R1 강등 후보/R2 본명/R3) 매일 16:10 · US top10 기록
[차단]    기존 전 경로(PathA/PathB/코어 신규) 3중 방벽 — 복원은 플래그
[대기]    KR micro 브리지 — 완성·탑재·3중 게이트 off
[판정]    preregistered_falsification_criteria_20260804.md 가 확대·반증·정상변동 고정
[관측]    Claude = mode 라벨(haiku)·매도리뷰(sonnet)만, 일 ~$1.3
```

## 5. 방향 — 세 개의 시계

1. **US**: 매일 rank1 매수 + top10 기록 → 8월 말 30건 판정 (net>0 AND 알파>0 → 일3건 / 알파≤0 → 지수 대비 무가치 정체)
2. **KR**: rv20 정상화(8월 말) → 9월 초 R2 10건 게이트 → 승인 시 micro 개시 (브리지 준비 완료)
3. **판정**: 확대·중단·강등 전부 사전등록 기준 자동 — 사람의 역할은 게이트 도착 시 승인

## 6. 정직한 리스크

- 표본이 얇다 (US forward 1건, KR 정산 1건) — 낙관 신호는 방향이지 증명이 아님
- 양 시장 모두 하락 국면 취약 — 실전 대형 하락장 통과는 미경험(시뮬만)
- R2 in-sample 우위의 forward 미재현 가능성 — 게이트가 그 방어선
- 정상 변동(연속손실 6건·낙폭 −30만)은 반드시 온다 — 그때 사전등록 문서가 버팀목

**요약: 두 달의 실패 목록이 단일 축을 깎아냈고, 그 축은 통계·비용·국면·OOS를 통과한 상태로 표본을 쌓는 중이며, 커지는 조건과 죽는 조건이 모두 미리 적혀 있다.**
