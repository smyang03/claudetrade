# 현재 시스템 수익성 전략 발굴 — 2026-07-15

## 결론

기존 GQMT 통합안은 그대로 보존한다. 이번 분석에서 현재 PathB 원장만으로 새로 살아남은 전략은
**KR Split-Exit Runner**다. KR 포지션이 고정 수익구간에 처음 도달하면 정수수량의 50%를 확정하고,
나머지 50%는 기존 target/runner 출구에 맡긴다. US에는 같은 정책을 승격하지 않는다.

모든 신규 결과는 오늘 발견한 post-selection 결과이므로 `SHADOW_ONLY`다. 라이브 설정·주문·DB는
변경하지 않았다.

재현 계약:

- 실행: `python tools/split_exit_runner_lab.py`
- 원장: `reports/split_exit_runner_lab_20260715.json`
- 원장에는 DB 경로·크기·수정시각, 파라미터 sweep, 월별 합계, 정수수량별 51건 ledger가 포함된다.

## 1. KR Split-Exit Runner

고정 계약:

- 대상: KR PathB, 수량 2주 이상
- 첫 활성: 진입가 대비 +3.6%
- 실행: `floor(qty * 0.5)`를 한 번만 매도
- 잔여: 현재 target·profit ladder·pre-close 소유권 유지
- 손절: 현재 계약 유지; 넓히지 않음
- 비용: KR 왕복 0.21%, 추가 체결 스트레스 0.30%를 부분매도 비중에 적용

실제 체결 원장 중 MFE·목표가·정수수량이 있는 51건을 재생했다. 34건에서 부분매도가 정수수량으로
실행 가능했다.

| 구간 | 현재 net 합 | Split-Exit 합 | 비고 |
|---|---:|---:|---|
| 전체 | -11.10%p | **+38.84%p** | 실행 가능 34/51 |
| 2026-04 | -25.20 | **+10.33** | 부호 전환 |
| 2026-05 | -5.93 | **+5.34** | 부호 전환 |
| 2026-06 | +19.20 | **+22.34** | 기존 승자 보존 |
| 2026-07 | +0.83 | **+0.83** | 표본 1 |

견고성:

- 상위 수익 3건 제거 후: **+21.73%p**
- 상·하위 3건 동시 제거 후: **+31.63%p**
- 부분체결에 추가 0.30% 슬리피지 스트레스: 정수수량 실비중 **+34.06%p**, 더 엄격한 명목 50% 차감 **+33.74%p**
- 활성점 3.0/3.6/4.0/4.5%, 매도비중 50% 전부 월별 양수
- 위 활성점들의 총합 범위: +38.84~+44.63%p
- 위 활성점들의 상위 3건 제거 합: +21.73~+26.33%p

50%보다 66%가 과거 수치상 높았지만 러너 보존과 탐색 편향을 고려해 50%를 고정한다. 33%는
4~5월 부호가 음수라 제외한다.

현재 배포된 `early_target`은 peak-trail에 의한 전량청산이고, 이 전략은 고정구간 부분청산이다.
서로 다른 전략이므로 KR에서 함께 전량청산 신호를 내면 안 된다. 구현 시 KR early-target의 소유권을
`partial_once -> remaining_runner` 상태기로 바꿔야 한다.

## 2. US Entry Quality Shield — shadow 후보

US에서 `zone_pos >= 0.67`이면서 목표거리가 5% 이상인 체결은 48건 평균 -1.03%였다.

| 구간 | N | 평균 net |
|---|---:|---:|
| 4~5월 | 16 | -0.30% |
| 6~7월 | 32 | -1.40% |

양 구간에서 같은 부호다. 이 셀만 0.25배로 줄이고 KR Split-Exit을 합성한 역사 원장은 US 전체
+14.63%p였지만, 상위 3건 제거 후 -23.94%p이고 6월도 -27.99%p라 enforce 근거는 아니다.

다음 shadow 계약은 차단이 아니라 다음과 같다.

- 존 상단+고목표 체결은 0.25배 가상 비중
- 동일 주문을 존 중단/하단 passive limit arm과 병렬 기록
- 미체결 승자 손실까지 포함해 `filled arm net - missed winner opportunity`로 판정

## 3. 국면 적응형 방어 — 아직 승격 불가

전일 QQQ 추세, 진입 순간 SPY tape, 진입 전에 확정된 동일 버킷 손실, 존 추격을 점수화했다.
기존 `QQQ<MA20` 도구가 당일 종가를 사용한 lookahead 결함이 있어 전일 데이터로 다시 계산했다.

- 고정 점수 배분: 6~7월 -67.33 -> +5.33%p, MDD -89.47 -> -22.73%p
- 그러나 4~5월 -21.58 -> -44.33%p로 승자를 훼손
- 최근 확정손익으로 방어신호를 켜는 온라인 버전도 전체 -42.00%p로 흑자 전환 실패

따라서 tape·반복손실·시장추세는 전역 게이트가 아니라 shadow 위험축으로만 유지한다.

## 4. 새로 검증했으나 기각한 전략

### profit_path early-tier 재라벨

65,070 US·39,547 KR runtime-authoritative 경로를 expanding train, 하루 purge, 날짜블록 OOS로
재학습했다. 당일 후보를 사후순위로 고르는 lookahead를 제거하고, 신호 도착순으로 확률기준을 넘는
첫 3개만 선택했다.

초기 KR 성과는 평균 +2.64%였으나 `minute_partial`, 저유동성, 후보가 대비 1% 초과 체결을 제거하자:

- US sequential p80: 평균 -0.537%, 합성 tier -0.659%
- KR sequential p80: 평균 +0.253%지만 상위 3건 제거 합 -40.27%p, 합성 tier -0.804%

데이터 미완료 급등주에 의존한 결과이므로 현재형은 기각한다.

### 부분 위험회수 2R 러너

실체결 분봉에서 +4% 도달 시 절반매도·잔여 본전스톱·2% trail을 보수적으로 재생했다.
기본 정책 대비 변화는 US +0.009%p/거래, KR -0.035%p/거래로 실질 개선이 없었다. 기각한다.

### auto-sell 검토 우회

`profit_review_triggered_at`은 실제 매도신호가 아니라 사전 이익검토 시점이라 지연으로 해석할 수 없다.
실제 proxy인 `auto_sell_review_price_native -> actual_exit_price`로 고치면 보호출구 179건의 평균
오버슈트는 +0.026%p에 불과했다. 우선순위에서 제외한다.

### KR volume_rank 단독 확대

실거래 17건 합 +10.26%p였지만 상위 3건이 모두 같은 날의 TARGET 승자였고, 상위 3건 제거 후
-8.29%p다. 관찰은 계속하되 확대하지 않는다.

### gap-over-zone continuation

`cancel_if_open_above` 취소 후 종가 성과는 US 8건 +3.53%, KR 2건 +4.97%였다. 가능성은 있으나
표본이 10건이고 대부분 눌림 없이 상승해 기존 PathB 지정가와 다른 전략이다. 별도 0.10배 shadow
continuation arm으로만 수집한다.

## 5. 현재 시스템 통합 방향

우선순위:

1. **KR Split-Exit Runner shadow 배선**: 주문 권한 없이 trigger·가상 부분체결·잔여 runner를 기록한다.
2. **KR forward 승격 관문**: 실행 가능 부분청산 n>=15, 비용 후 delta>0, block LCB>0,
   상위 3건 제거 후 양수.
3. 통과 시 KR만 MICRO. US는 제외한다.
4. US zone-quality 0.25x와 passive-limit arm을 병렬 shadow한다.
5. gap-over-zone continuation은 독립 전략 ID·자금·exit owner로 수집한다.
6. 기존 US ladder A/B와 early-tier forward는 계속 관찰하되 신규 전략과 원장을 섞지 않는다.

최종 전략 ID 제안:

- `PATHB_KR_SPLIT_RUNNER_V1`
- `PATHB_US_ZONE_QUALITY_SHADOW_V1`
- `PATHB_GAP_ESCAPE_CONTINUATION_SHADOW_V1`

핵심은 매수를 무작정 늘리는 것이 아니다. KR에서는 실제로 반복 검증된 중간 봉우리를 절반 현금화하고
러너를 보존하며, US에서는 손실이 반복된 체결 품질 셀의 위험만 낮추는 비대칭 구조다.
