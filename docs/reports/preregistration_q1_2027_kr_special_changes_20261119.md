# 사전등록 — 2027 Q1 슬롯 3/3: KOSPI200·KOSDAQ150 수시변경 대체 편입 (2026-11-19)

**상태: 등록 (2026-11-19, 운영자 "추천안으로 진행").** Q1 남은 슬롯 1개를 쓴다(`docs/operating_model.md` §4). 아래 기준은 이 커밋 이후 변경 금지 — 변경은 "개정" 섹션 추가로만.
이 문서를 커밋하는 시점까지 수시변경 명단은 수집 중이고, 편입 종목의 수익률은 계산하지 않았다.

## 이미 알려진 사실 (사후 맞춤 경계)

- L7(정기변경 편입, 발표 다음 날 시가 → 효력일 전날 종가)은 통과했다: 규모매칭 초과 +4.80%/회차 t 4.82. 몸통은 KOSDAQ150(t 4.06)이고 KOSPI200 단독은 t 1.79였다(`kr_index_inclusion_test_20261030.md`).
- MSCI Korea 편입은 같은 메커니즘인데 기각됐다(t 0.65). 발표 반응이 진입 전 장전 갭으로 들어갔기 때문이다(`q1_2027_verdicts_20261031.md`).
- 특례편입(대형 신규상장)은 L7이 이미 같은 계약으로 산다. 이 등록에서 뺀다.
- 수시변경 대체 편입(구성종목 상장폐지·합병·관리종목·KOSDAQ→KOSPI 이전상장으로 빈자리를 예비종목으로 채움)은 L7 표본에서 빠져 있었다. 검정한 적이 없다.

## 가설

| 항목 | 값 |
|---|---|
| 메커니즘 | 지수 추종 패시브 자금이 효력일 직전 대체 편입 종목을 산다. 대체 종목은 예비종목(시총 하위 경계)이라 정기변경 편입보다 작고 유동성이 낮다 → 수요 충격이 클 수 있다 |
| 표본 | `data/analysis/q1_kr_special_changes/kr_special_changes.csv`의 편입 행(네이버 뉴스 수집, 2012~2026). 정기변경·특례편입과 같은 날·같은 종목이면 제외 |
| 진입 | 발표 시각이 장 마감 후·미상이면 발표일 다음 거래일 시가, 장 시작 전이면 발표일 시가, 장중이면 다음 거래일 시가 |
| 청산 | 효력일 전 거래일 종가. 진입일 ≥ 청산일(보유 0세션)이면 해당 건 제외(표본 수로 보고) |
| 비용 | 왕복 0.25%(L7과 같다) |
| 벤치 | 규모매칭(L7 엔진 `research_kr_index_inclusion_20261030.py` Book.size_bench 그대로)이 주, 지수 ETF(069500/229200)가 보조 |
| t | 발표일 클러스터(같은 날 발표된 편입 종목 평균 = 1관측), 평균의 t |
| IS/OOS | IS 2012~2019 / OOS 2020~ |
| 합격 | 클러스터 t ≥ 2.64 **그리고** IS·OOS 같은 부호(+) **그리고** 양 클러스터 과반 |
| 기각 | 위 셋 중 하나라도 미달 |
| 검정 불가 | 가격 있는 클러스터 < 25, 또는 진입·청산 봉이 있는 편입 < 80% |
| 보조(판정 제외) | ① 발표 직전 종가 → 진입 시가 갭 ② 지수별(KOSPI200/KOSDAQ150) ③ 사유별(이전상장 대체 vs 상폐·합병 대체) ④ 효력일 시가 → H20 반전 |
| 통과 후 | L7 도구에 수시변경 회차를 같은 계약으로 붙이는 안을 운영자에게 제안한다(금액은 운영자 결정). 명단 입력 경로(수동 CSV 또는 뉴스 자동 파싱)도 함께 제안 |
| 반대 근거 | ① 발표~효력이 짧아(수일) 진입 전 갭으로 끝날 수 있다(MSCI와 같은 실패 경로) ② 대체 종목은 작아 체결 슬리피지가 0.25%를 넘을 수 있다 ③ 뉴스 수집이라 누락·편향(기사화된 건만)이 있다 ④ 상폐·관리종목 사유 회차는 시장 스트레스와 겹친다 |
| 환산식 | 회차당 투입 × 클러스터 평균 초과 × 연간 클러스터 수 |
