## 2. 설계안 — 수익이 나는 시스템으로 가는 경로

산술: 흑자 조건 = (거래당 엣지 − 거래당 비용) × 빈도 × 사이즈 > 0. 선정알파·국면예측이 0이므로 **엣지 항은 못 올리고, 비용·사이즈·배분·꼬리 capture로 이긴다.**

### D1. 자본 재배분 — KR 주축화 + US 소액 검증 재개 (최우선)
- **KR**: 유일한 엣지>비용 스트림. 주문금액 50만 → **75만 점진 증액**(1단계). 가드레일: 월 실현손실 캡(예: −15만원 도달 시 50만 원복), 슬리피지 실측(fill단가 vs 주문가, 증액 전후 비교), 2주 단위 재판정. 근거가 P(양수)=0.70으로 미확립이므로 "점진 + 자동 철회조건"이 필수.
- **US**: 주문 50만 → **10만 소액** + 진입 스로틀(reward_risk 컷) 완화로 fill 재개. 최악월 손실 −8만원 캡 수준에서 red-tape·zone-fill의 forward 검증 표본을 산다(7/6 토론 옵션②). 지금 상태(fill≈0)는 손실도 0이지만 검증도 0 = US 개선이 영구 미결.
- 이것은 시장 예측(스위칭)이 아니라 **비용 구조가 확정한 정적 배분**이다.

### D2. 흐름 개편 — rule 후보선정 + Claude는 매수·매도 시점만 (운영자 제안 채택)
- Selection에서 Claude 제거: 무알파 확정 축이므로 성과 중립 + 토큰비용·레이턴시 절감 + trade_ready류 자기검열 층 제거.
- 후보선정 rule 초안(전부 기검증 재료): 원채널 스크리너 소스 유지 + catalyst 게이트(KR enforce 기검증) + 유동성/변동성 하한 + red-tape(US). **rule에 새 예측 조건을 넣지 않는다**(7/6 스캔: 진입조건 OOS 양월양수 0).
- Claude 배치: 매수 시 = 체결가 품질(zone 하단 대기, US 최악셀 회피 Δ+0.207 기측정) / 매도 시 = 현행 유지·강화(검증된 유일 엣지).
- 단계: 1단계 = selection Claude를 rule로 대체(가격플랜은 현행 유지, 소수술). 2단계(선택) = 존·손절·목표 ATR 결정론화(대수술, 별도 승인).
- 이행 시 보존 필수: red-tape(US enforce), catalyst enforce(KR/US), 브로커 truth 동기화, HALT/quarantine.

### D3. 꼬리 확대 — 배선된 실험의 판독·전환이 병목 (새 코드 아님)
- ladder A/B(러너 보호 vs 소폭익절): 표본 도달 시 판독 → Δ>+0.3이면 유지.
- zone-fill(체결가 품질): shadow 확증 후 US enforce 전환(미체결 양날 확인 후).
- red-tape: US 세션 실발동 forward 확증(6월 편중 해소).
- **D1의 US 소액 재개 없이는 셋 다 표본이 안 쌓인다** — D1이 D3의 전제.

### D4. US 비용 직접 공략
- 수수료 0.50RT는 브로커 고정(기확인, 혜택 없음). 남는 것: **FX 왕복 환전 회피**(달러 잔고 상시 운용으로 환전 스프레드 항 제거 — 현행 파이프라인이 거래마다 환산하는지 실측 필요) + 회전 자체 축소(US 진입 1건 회피 = 기대 +0.33).
- 장기 옵션(운영자 결정): US를 "지수 추종 + 개별주 소액 검증"으로 이원화 등 구조 대안은 in-repo 증거 밖.

### D5. 위생·드레인 감사 (소형)
- **CLAUDE_INTRADAY_SELL 판독**: 신설 출구가 −16.6 드레인(승률 12%). 분봉 재생으로 "그 시점 안 팔았으면 LOSS_CAP였나, 회복이었나" 판정. 역효과면 off.
- 섹터 동시발화 캡 부활: MAX_SECTOR_POSITIONS 죽은 config(기감사 H1). 6월 상관 붕괴 동시피격 완화용 싼 위생.
- KR 저변동+zone하단+저conf 포켓(6월 +1.7, OOS 불가): forward shadow 라벨만 지정해 자동 누적.

### 우선순위와 의존관계
```
D1(재배분·소액재개) ─┬─> D3(꼬리 실험 판독) ─> enforce 전환
                     └─> US forward 표본 축적
D2(흐름 개편)  — D1과 독립, 병행 가능 (1단계 소수술만)
D4(FX 실측)   — 즉시 가능 (측정만)
D5(위생)      — 즉시 가능 (소형)
```

### 정직한 산술 (기대치 관리)
- KR 현 페이스(월 ~18건 × +0.325% × 50만) ≈ **월 +2.9만원**. 75만 증액 시 ~+4.4만, 100만 시 ~+5.9만. 흑자 전환은 산술적으로 가능하나 절대금액은 작다. 스케일은 KR 사이즈에서만 나온다(빈도 확대는 기각 — 거부된 후보 forward 음수 기검증).
- US는 소액 검증 통과(red-tape+zone-fill로 몸통손실 < 꼬리+비용) 전까지 손익 기여를 기대하지 않는다.
