# SHADOW 전략 검증 준비 상태 — 2026-09-11

## 결론

운영 연결은 완료되어 있다. 봇과 대시보드는 정상이며, 실주문 권한은 계속 차단되어 있다. 다만 아직 정상적인 가상 체결 표본이 없어 수익성 판단이나 실매매 승격은 금지한다.

## 현재 확인값

- `/api/selection_shadow`: HTTP 200, `SHADOW_ONLY`, `forward_quote_v1`
- 봇 heartbeat와 대시보드 heartbeat 정상
- DB `PRAGMA integrity_check`: `ok`
- 가상 체결/보유/청산: 0건
- 실주문·기존 계좌·기존 포지션·기존 유령 원장: 변경 없음
- KR 2026-09-11: `INPUT_INCOMPLETE` / `BLOCKED`, 원본 1,769개·후보 53개
- US 2026-09-10: 후보 1개였으나 `CACHE_ONLY` 시세 부족으로 체결 없음

## 승격 전 고정 게이트

아래 조건을 모두 충족하기 전에는 어떤 규칙도 실주문으로 승격하지 않는다.

1. 최소 20~30개의 완전한 정규 세션 표본
2. 규칙별 실제 가상 체결 30건 이상
3. 수수료 반영 후 미청산 포함 NAV 기대값 양수
4. baseline·random_k1·random_k3를 동일 세션·동일 자본으로 비교
5. 최대낙폭, 연속손실, stale quote 비율을 별도 확인
6. `INPUT_INCOMPLETE`, `ENTRY_WINDOW_MISSED`, `NO_VERIFIED_QUOTE` 세션을 성과에서 제거하지 않고 공개
7. 신규 전략 하나만 양수인 경우에도 자동 승격하지 않고 다음 검토 승인 필요

## 제한 사항

현재 결과는 수익률 0%가 아니라 **아직 유효한 체결 표본 없음**이다. 과거 가격을 채우거나 결손 종목을 임의 제외해 표본을 만들지 않는다. 실주문 스위치, 기존 원장, 계좌 설정은 이 준비 작업에서 변경하지 않았다.
