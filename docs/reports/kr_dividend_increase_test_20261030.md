## 구현 (기준은 사전등록 그대로)

- 수집기는 `tools/research/research_kr_dividend_20261030.py`다. 산출물은 `data/analysis/kr_dividend_20261030/`에 둔다(커밋 안 함).
  - list: `pblntf_detail_ty=I001`로 받았다. 배당결정은 수시공시 서식이라 pblntf_ty=I에서 I001만 받으면 된다. 2019-01-01~2026-09-29는 `kr_event_20260930/list`(같은 파라미터)를 재사용했다. 새로 받은 구간은 2014-01-01~2018-12-31과 2026-09-30~10-29다.
  - 원문: `document.xml`의 원본 zip을 `raw/{rcept_no}.zip`에 캐시했다. 웹 뷰어(dart.fss.or.kr) 본문은 `raw/{rcept_no}.web.txt`다. 상태 색인은 `docs_index.jsonl`이고 `ok` / `nofile_*` / `err_*`로 적는다. 연도 층화 round-robin으로 받았다.
  - 파싱 필드는 배당구분(결산/분기/중간), 배당종류, 1주당 배당금(보통주), 시가배당률(보통주), 배당기준일이다. 결과는 `events_parsed.csv`, `coverage.csv`, `coverage_summary.json`에 있다. API 원문과 웹 원문을 둘 다 받은 2건(20160302600233·20160302800683)으로 파싱 결과를 대조했고 일치했다. 웹 원문만 받은 2건은 육안 확인만 했다.
- **전년 DPS:** ① 같은 회사·같은 배당구분의 직전 회계기간 원공시 DPS(가장 이른 본)를 쓴다. 결산배당은 기준일 월이 5월 이하이면 FY를 연도−1로 잡는다(2024년 이후 기준일 후행 체계 대응). 분기·중간배당은 (기준일 연도, 분기)로 맞춘다. ② ①이 없는 결산배당 가운데 시가배당률이 2% 이상인 건만 `alotMatter`(FY−1 사업보고서 11011, 보통주 주당 현금배당금 당기)로 보완한다. ②는 10-31 재수집 때 실행했다(alotMatter 388건 조회). 정정본 값으로 빈칸을 채우지 않는다. 전년 DPS가 0이거나 결측이면 배당 개시로 보고 주 행에서 제외한다.
  - 사전등록 표의 데이터 행은 전년 DPS를 alotMatter로 적었다. 구현은 직전 원공시를 1순위, alotMatter를 보완으로 쓴다. 이유는 셋이다. 이벤트 단위 DPS(결산 대 결산)와 같은 정의다. 분기 배당사는 alotMatter 연간 합계와 맞지 않는다. 호출도 절약된다. 판정 규칙(≥ +20%·≥ 2%)은 바꾸지 않았다.
- 검정: 진입은 접수일 이하 마지막 거래일 다음 시가, 보유 H20, 비용 0.25%다. 규모매칭 벤치는 kr_event_20260930의 Book(dvol20 ≥ 20억 적격, 십분위)을 그대로 옮겼고 KOSPI200은 069500이다. 공시 종목 전체 기저도 함께 낸다. t는 진입일 클러스터 NW(lag 19)다. 가격은 네이버 fchart 수정주가 2,743종목, 2014-08-05~2026-10-29(KIS 미사용)다.
- t 문구는 모호하다. §3은 t가 전기간인지 OOS인지 정하지 않았다. 스크립트는 **전기간 t를 판정값**으로 쓰고 OOS t와 IS 부호를 같이 낸다. 둘이 갈리면 운영자 판단 항목이다. 모집단 문턱(D 적격)도 kr_event 관례를 따른 것이고, 전체 모집단 값을 병기한다.

## 한계

- **생존편향:** DART list에서 상폐 종목은 종목코드가 비어 있고, 네이버에도 가격이 없다. 가격이 없어 탈락한 건은 연 6~54건이다(2016년 54건이 최다, 최근으로 갈수록 줄어 2026년 6건). 값은 대체하지 않았다. 절대수익은 상한으로 읽는다.
- 네이버 fchart는 3,000봉에서 잘린다. 그래서 2014-08-05부터 받았다. 2015년 1월 진입분은 dvol20 워밍업이 빠듯하다(s ≥ 25봉 조건 충족).
- 웹 뷰어(dart.fss.or.kr)는 04:50경 프로세스 2개(약 2 req/s)로 돌리자 연결 차단(Remote end closed)을 당했다. 라이브 봇은 opendart.fss.or.kr만 쓰므로 영향이 없다(05:00 list 호출 정상 확인). **다음 판에서는 웹 뷰어를 쓰지 않고 OpenAPI만 쓴다.**
- 'vs 배당공시 전체'는 같은 진입일의 다른 배당 이벤트 평균을 뺀 값이다(자기 자신 제외). 같은 날 다른 이벤트가 없으면 결측이라 n이 조금 줄어든다.
- 전년 DPS 결측(배당 개시로 제외)에는 '전년 원문 미수집'과 '전년 원문은 있으나 DPS가 −'가 섞여 있다. 다음 판에서 둘을 나눠 센다.
- 분리과세 요건 분할(보조)은 산출하지 못했다. 배당성향(순이익)을 수집하지 않았다.
- OpenAPI 호출은 10-30에 약 7,950회, 10-31에 5,666회였다(디스크 카운터 `calls_2026103*.json`).
- 10-31 1차 실행은 collect를 마친 뒤 PC 메모리 부족으로 test 전에 강제 종료됐다. test만 따로 다시 실행했다(rc 0).
