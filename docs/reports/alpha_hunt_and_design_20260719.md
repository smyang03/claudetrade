# 알파 탐색 상세 검토 + 설계 (2026-07-19)

작성: Claude. 내부 DB 실측(v2_learning/canonical_performance, 일봉) + 외부 웹 리서치(학술·실무, 인용) 결합. 분석·설계 전용 — 라이브 미접촉. 재현 스크립트: scratchpad(loss_profit_decomp.py·alpha_hunt.py·max_lottery_test.py).

## 0. 한 줄 결론
**알파가 없는 게 아니라, 있는 알파를 죽이고 있다.** 내부 실측과 외부 문헌이 같은 지점을 가리킨다 — per-trade 진입 예측(무엣지, r=0.04)을 버리고 **① 후보 풀 구성(저비용 스크린/틸트) ② 회전율 축소(멀티데이·볼록 sleeve) ③ 경로 기반 출구(키스톤)** 로 전환.

## 1. 내부 실측 — 손익 구조 (v2, 4/27~7/06)

- **gross vs net**: US gross **+0.167%/건** → 왕복비용 0.5% → net −0.229%. **미약한 gross 신호는 실재, 비용 hurdle 아래.** 전체 gross +0.056%(양수), net −0.293%.
- **보유기간**: US 당일청산 net **−396k원(−0.48%)** vs US 멀티데이 **+101k원(+1.70%)**. 손실은 인트라데이 churn, 흑자는 멀티데이 볼록 홀드. (단 멀티데이는 생존편향 — "다 오래 들면 +1.7%" 아님.)
- **승리 엔진**: CLOSED_CLAUDE_PRICE_TARGET만 실질 흑자(+256k, 14건, +4.68%, MFE 8.4%). 상위 5 winner가 흑자 전부.
- **손실 지배**: CLOSED_LOSS_CAP −434k(40건, −2.69%). 이 중 **~62%가 MFE≥0.5% 반납분**(녹색 갔다 뱉음=포착 실패), ~38%가 MFE<0.5%(선별 실패).
- **−2% 캡이 winner 죽임**: TARGET winner 27건 중 17건이 진입 후 −2%를 뚫고도 회복(평균 MAE −4.43%). 정적 캡 완화는 이미 기각(6/29, loser 손실 더 커짐) → 진입 예측으론 못 가림.
- **국면**: MODERATE_BULL+CAUTIOUS_BEAR만 = 거의 손익분기(−10k) vs 전체 −332k. MILD_BULL avg −1.52%(최악). momentum 전략 승률 18%.
- **★MAX/로또 시그니처(우리 net 확인)**: LOSS_CAP 진입 전 MAX 평균 17.1% vs TARGET 12.3%. MAX 상위30% 코호트 net **−0.85%**(vs 중간 +0.04%). **급등폭 큰 종목 추격이 손실원.**

## 2. 외부 리서치 — 우리 제약서 살아남는 검증 구조

총평: 롱온리·고비용·소액 개인이 실제로 사는 알파는 거의 전부 **저회전 횡단면 틸트/스크린**("무엇을 보유하느냐"). 비용 hurdle 넘는 가장 강건한 레버 = **회전율 축소** — 우리 멀티데이 +1.70% 실측과 일치.

**살아남음(미사용, 이식가능)**:
1. **MAX/로또주 회피 네거티브 스크린** (Bali/Cakici/Whitelaw 2011, JFE) — 최근 1M 최대일간수익 상위 종목 이후 월 −1%+ 언더퍼폼. 회전율 0(배제 규칙), 비용 무관. **우리 데이터로 실증됨(§1).**
2. **저변동성/저베타 롱온리 틸트 (US)** (Soebhag/Baltussen/van Vliet 2025) — long leg net +2.70% 생존. 밸류 조건부. KR BAB는 비용 후 死 → US 우선·KR shadow.
3. **퀄리티/총이익성 틸트** (Novy-Marx 2013) — 저회전, 모멘텀과 음상관(분산축). 단독 알파 완만.
4. **Turn-of-month 지수 오버레이** (McConnell/Xu 2008) — 월 ~1왕복 저비용. 기존 멜트업 수확과 중복 확인 필요.

**반증(우리 비용/무엣지서 死)**: 오버나잇·종가매수(일일 0.5% 비용에 소멸), PEAD(비용 70~100% 잠식), 52주고가(1/2~2/3 잠식), KR 외국인 수급 per-trade(예측 약함, "온도계지 나침반 아님" — shadow 유지 맞음). 단 Jacobs/Müller(2020): 비-US(KR)는 공표 후 decay 덜함 → KR 잔존 프리미엄 여지.

## 3. 설계 — 3트랙 (전부 shadow→forward→운영자 승인→enforce)

### Track 1 (즉시·최저비용·우리 데이터 확인됨): 후보 풀 구성
- **1a. MAX 회피 스크린**: 후보별 `max_daily_ret_21d` 산출(일봉 보유). 상위 분위(예: MAX>16% 또는 상위 decile) 관측 태그 → shadow로 "배제 코호트 vs 잔여" forward net 비교 → 확인 시 **네거티브 스크린(배제, 랭킹 불변 — 6/27 존중, 회피 필터라 리스크 비대칭 안전)**.
- **1b. 저변동성 틸트(US)** + **1c. 퀄리티 틸트**: 후보 관측 필드 추가(foreign_flow 패턴 복제 — QUALITY_FEATURE_KEYS + screener_quality emit까지 **연결 완결**). 밸류 필터 결합.
- 판정: 코호트별 세션 rank IC + 배제 반사실 net. 피처 예산 ≤5 규율.

### Track 2 (구조·배치): 회전율 축소 + 볼록 sleeve 확대
- 평가 기준을 **건당 forward → sleeve 레벨 rank IC/net**로 전환(표본 기근 우회). gross +0.167%를 회전 축소로 비용 위로.
- 검증된 볼록/멀티데이 트랙(TSMOM 코어)에 자본·빈도 배치, 인트라데이 churn(−396k원) 축소. **운영자 배치 결정 사항.**

### Track 3 (키스톤·병렬 축적): 경로 기반 출구
- prospective는 이미 배선(pathb_runtime.py:12911 observed_peak/low_at → mfe_time/mae_time). 7/10 신설+빈도붕괴로 표본 0.
- **소급 분봉 리플레이 백필**(분봉 부분커버 ~50%)로 mfe_time/mae_time + 초기경로 피처 산출 → 멀티데이 winner vs loss_cap이 **첫 15/30/60분에 갈라지는 신호** 검증.
- 있으면 **비대칭 출구**(초기 leash 넓게+실패 path 조기컷 — 정적 캡완화 아님). 없으면 캡틀 유지. 처리량 한계라 1순위 아닌 병렬 축적.

## 4b. ★외부 데이터 검증 (yfinance, 2014~2026, US 72종목 + 지수 2005~) — 1차 설계 정정

검증 스크립트: scratchpad/external_validation.py, external_validation2.py. 유니버스=현존종목(생존편향, 횡단면·조건부 상대비교로 부분완화).

- **T1 MAX 회피 — 월간형 반증, 단기형 확인**: 월간 高MAX 5분위가 오히려 아웃퍼폼(+2.67 vs +1.09%/월; 대형주 불장서 高MAX=모멘텀승자). **그러나 우리 호라이즌(스파이크 다음날 진입 5일보유)**: 스파이크>8% 5일 −0.23%, **>12% −1.62%(승률45%)** vs 무조건부 +0.36%. → **재구성: "큰 단일일 급등(>8~12%) 추격 금지"가 외부·우리호라이즌서 확인.** 월간 MAX 스크린은 폐기, 단기 anti-chase로 대체.
- **T2 저변동 — 알파 아님, 손실축소만**: 위험조정도 高vol Q5 Sharpe +0.192 > 低vol Q1 +0.132(원수익도 高vol 우위). 단 低vol 평균손실 −4.18% vs 高vol −11.19%(2.7배). → 수익원 아님, **손실 크기 축소 틸트로만** 강등.
- **T3 퀄리티 — 검증 불가**: yfinance 무료 펀더멘털 커버 부족(point-in-time 아님). 문헌 근거만, 우리 데이터 확인 못 함 → 보류.
- **T4 turn-of-month — KR만**: S&P +0.047 vs +0.040(미미), KOSPI +0.092 vs +0.042(2배·승률55%). → US 폐기, **KR 오버레이만** 근거.

**정정된 우선순위**: ①**anti-chase 스크린**(큰 급등 직후 진입 회피, 단기 외부확인) ②회전율↓·볼록 sleeve(월간 모멘텀 실재→오래 보유, 인트라데이 churn 제거) ③turn-of-month **KR** 오버레이 ④저변동=손실축소 보조 ⑤경로 키스톤(mfe_time). 저변동 알파·퀄리티·US turn-of-month·월간 MAX는 외부 검증서 탈락/보류.

## 5. 규율
모든 축은 논문 지평≠우리 보유기간이므로 shadow/forward에서 **우리 실제 net으로 판정 후 enforce**, 운영자 승인. MFE는 낙관 상한. 표본 pnl_krw_net 157/pnl_pct_net 315(백필 불완전). 일부 셀 n<5 — 과적합 금지. 스크린은 리랭킹 아닌 배제(6/27 존중).
