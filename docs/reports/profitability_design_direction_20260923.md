## 3. 살릴 것 — 패닉 ETF 밤 (유일한 사전등록 통과 축)

| 항목 | 현재 |
|---|---|
| 백필 | 233740 n 247 · +0.706% · t 3.37 · 승률 65% |
| 다중검정 | 분모 96~301 전 구간에서 Bonferroni 기각(생존 경계 N ≤ 57) |
| forward | 4건(2세션 × ETF 2종) 전부 음수 · P(≤0승 \| 65%) = 0.015 |
| 사전등록 판정 | **신호 20건 정산 후** 세션 초과 > 0 · 승률 ≥ 55% · 15:19 어긋남 ≤ 25% |
| 판정 시점 | 남은 18신호 ÷ 연 20~23회 ≈ 9.5~11개월 → **2027-07~08 전후** |
| 비용 체력 | 손익분기 왕복비용 0.706% = 실제 비용의 14배 — 비용 가정에 안 뒤집힌다 |

- **할 일은 기다리는 게 아니라 forward 20건을 오염 없이 채우는 것이다.** 규칙 변경(문턱·배수)은
  판정을 무효화하므로 하지 않는다. 사이징 3배(+1.16%p, 최악 1박 −38.9%)는 판정 후 문제.
- 반증은 사전등록 조항으로만 한다. forward 4건 0승은 n이 작아 기각 사유가 아니다.
- 실투자 전환 시 기대치(백필 그대로 재현되는 낙관 가정): 100만 × 연 +13.5%p = 연 13.5만(월 1.1만).
  **현금 파킹과 같은 크기다** — 그래서 둘을 대체재가 아니라 **파킹 위에 올리는 층**으로 설계한다
  (신호일 15:20 파킹 ETF 일부 매도 → 233740 매수 → 익일 시가 매도 → 파킹 복귀).

   매도 순서. (코어 3종과 별개, 장기보유 규칙 불변.)
