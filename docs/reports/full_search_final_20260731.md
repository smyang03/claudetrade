## 4. ★ 데이터 함정 (앞으로 반드시 지킬 것)

1. **`audit_candidate_outcomes` 30/60분을 피처 리서치에 쓰지 마라.** status='audit_sparse'(샘플 3~4개)이고 분봉 실측과 **상관 KR 0.354 / US 0.248**. 이 소스로 낸 결론 4건이 부호까지 뒤집혔다. → **`candidate_counterfactual_paths`(분봉 60봉)를 표준 소스로 쓴다.**
2. **`audit_candidate_rows`의 80.9%가 체결 이후 UPDATE**됐다(130/298은 체결 이후 생성). `known_at`은 관측시각일 뿐 값 확정시각이 아니다. 단 **PREOPEN 행은 예외**(updated>created 0%).
3. **종목-일당 평균 13~16배 중복.** `(market,ticker,session_date)` dedup 필수.
4. **관측 수(n)가 아니라 유효 세션일로 판정하라.** n=228인데 유효일 3일인 조합이 엄격 필터를 통과했다.
5. 5분위 계산 시 `sort(key=lambda x:x[0])` 필수(동률 net 2차정렬 → 승률 0%/99% 가짜신호).
6. **US 세션은 KST로 두 날짜에 걸친다.** 창은 `[session_date 20:00, +1일 08:00]`.
7. `forward_1d/3d/5d`는 **세션 종가 앵커**라 우리 진입 앵커와 다르다. US 갭다운 forward_1d +0.415는 재측정 시 −0.35로 전멸.
