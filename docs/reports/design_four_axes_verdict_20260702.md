# 4축 개선 설계 토론 판정 + 생존 설계안 (2026-07-02)

**형식**: 설계자(PRO) vs 레드팀(CON) 독립 병렬 분석 → 충돌 지점 사회자 직접 재현 → 생존 축만 설계안.
**전제**: 오늘 3자토론 확정 사실(예측축 사망, US 중앙거래<비용, 통산 -0.25 잔존) 위에서 신규/추가 방향 4축 검증. 전 과정 read-only.
**축**: A 국면조건부 노출 / B 보유기간·회전 구조 / C KR/US 자본 재배분 / D 신규 모듈(TAIL_CAPTURE_CARRY).

---

## 1. 판정 요약

| 축 | 판정 | 근거 (양측 수렴 or 사회자 재현) |
|---|---|---|
| **A. 국면노출** | **판정불능 — 유일 생존, 계측 설계만 승인 대상** | β보정 후 gross 초과수익 생존(+0.61~0.72, 76% 양수) BUT 비용 차감 시 소멸(+0.02, 52%), 세션 클러스터 t=0.44. 표본 전부 강세 4세션(약세 0). 헤드라인 +2.44%는 비재현(전수 재생 raw +0.95) |
| **B. 회전구조** | **기각 (2단 사망)** | ①보유일 버킷 = 출구경로 confound 확인(동일 출구사유 내 격차 붕괴, 계산법 바꾸면 부호 역전, closed_at 커버리지 3%) ②대체 레버 "손실출구 후 재진입 격리"는 사회자 재현서 변별력 0: 손실출구후 재진입 n=13 med -0.572 vs 베이스라인 n=86 med -0.867 — **베이스라인보다 나쁘지 않음** = 무변별 cut = 기각된 빈도축 거울상 |
| **C. 재배분** | **기각 (산술적 무의미)** | KR 6월 흑자 = 6/17 하루 8건(+20.1pp)이 전부, 나머지 합 -3.9pp. 부트스트랩 CI [-0.53,+2.62]. KR 캡 이용률 ~5% — binding은 자본이 아니라 후보흐름. 자본 2배 줘도 살 것이 0건 |
| **D. CARRY** | **킬 대기 (계측 수리만)** | shadow 로깅 경로 자체가 부재(mode!=enforce면 would_carry 판정 skip), tail_capture jsonl 6/26 이후 중단, 구모듈 결정 28/28 전부 SELL. 소급 counterfactual n=6 오버나이트 **음수**(med -0.27). 설계 근거였던 단방향 sim(+33%p)은 이후 분봉 양방향 replay가 반증한 계열 |

**한 줄 결론: 행동(매매) 레버는 4축 모두 없음. 생존물은 계측 3건 + 트립와이어 문서화 — 전부 매매 무변경.**

## 2. 생존 설계안 (구현 시 전부 행동 0 = 매매 무변경, 운영자 지시 후 착수)

### D1. A축 계측: REQUIRE_TRADE_READY_BLOCK 블록→종가 β보정 누적 도구
- **무엇**: `tools/require_ready_block_close_path_review.py` 신설 — 기존 `neg_context_block_close_path_review.py` 패턴 복제, 소스만 RTRB 이벤트로. 퍼티커 β보정(6개월 일봉, β 캐시) + **세션 클러스터 단위 집계 강제**(이벤트 풀링 금지 — 같은 세션 종목 동조로 유효표본은 세션 수), regime별 분리, 좌꼬리(≤-5%)율.
- **왜**: "강세장 과보수"는 8레버 전멸 속 유일하게 반증 안 된 스레드. 단 승격 근거는 사망(잔여알파 +0.61 < 비용 0.70, t=0.44) — 결론은 데이터 누적만이 낸다.
- **shadow 전환 문턱(양측 합의로 고정)**: 비강세 국면 포함 US ≥20세션 누적 AND 세션평균 β-adj 알파 > +0.70%(비용) AND t≥2. KR은 블록 n=3이라 논외(별도 n≥20).
- **킬 기준**: 다국면 누적 β-adj med < +0.3 / 비강세 구간 med < 0(neg_context형 반전) → 축 폐기, 게이트 유지 확정.
- **경고(레드팀)**: 블록 코호트의 절반이 메가캡 반복(TSLA 4세션 등) — "완화"의 실체가 메가캡 베타 추가매수면 레짐 정적컷 거짓양성과 동형. regime·종목농도 분리 리포트 필수.

### D2. B축 잔존 위생: 보유시간 필드 영속화
- **무엇**: `closed_at`(현 커버리지 3%)·`minutes_to_close`(3.7%) 등 보유기간 필드를 CLOSED 시점에 항상 영속화. observed_mfe 영속화(W26 84.6%)와 동일 패턴.
- **왜**: 회전 축 부활 조건(레드팀 binding constraint) = "커버리지 ≥95%에서 두 계산법이 같은 부호". 지금은 어떤 보유기간 분석도 프록시 위에 서 있어 부호가 계산법에 의존.
- 이것은 수익 레버가 아니라 측정 위생 — 기대효과를 주장하지 않는다.

### D3. D축 계측 수리: would_carry 로깅 + funnel 로그 중단 점검
- **무엇**: ①pre_close 스캔 시 mode 무관하게 would_carry 판정(자격+net/MFE/regime)을 jsonl에 기록 ②`logs/funnel/tail_capture_*.jsonl` 6/26 이후 중단 원인 점검.
- **킬 기준(선고정)**: would_carry n≥25에서 오버나이트→익일시가 med ≤ 0(소급 -0.27 재현) → CARRY 즉시 폐기. med > +0.3(갭리스크 프리미엄)일 때만 enforce 논의 개시.
- 발생빈도 ~0.7건/주 → 판정까지 수개월. 로깅 몇 줄 이상의 투자 금지(양측 합의).

### D4. C축: 신규 작업 없음 — 트립와이어만 문서화
- 재배분 논의 재개 조건: ①KR 체결 재개 후 ②6/17 제외 KR net mean>0을 n≥30에서 확인 ③KR 체결/일이 현 배분 자본 소진점 실도달. 셋 전 자본이동 금지. 주간 시장별 net 집계는 기존 `tools/net_profitability_review.py`로 충당.

## 3. 기각 명시 (재론 방지)
- **보유일 자르기/연장**: 출구경로 confound + 측정필드 부재. 부활 조건은 D2 완료 후 두 계산법 동부호(n≥30/시장).
- **손실출구 후 재진입 격리**: 사회자 재현서 변별력 0 (재진입 med -0.572 vs 베이스라인 -0.867). PRO의 -19.9pp는 5월 uniform-cost 포함 창으로 net_est 코호트서 비재현.
- **재배분 즉시 실행 / CARRY enforce / 쿨다운 전역 연장**: 각각 산술 무의미·데이터 0·수익재진입 코호트 오폭.

## 4. 방법론 기록
- PRO가 스스로 기각한 것(신뢰 지표): "보유일 자르기는 가짜 레버", "CARRY 로깅 이상 설계는 억지".
- CON 재현 규율이 잡은 것: +2.44% 헤드라인 비재현(원보고서 자체에 부호충돌 병기돼 있었음), 세션 클러스터 vs 이벤트 풀링, 메가캡 농도.
- 사회자 1차 쿼리 실패 사례: exit 시각으로 plan_json에 없는 필드 참조 → 쌍 0건. 올바른 필드 = `entry_filled_at`/`sell_order_sent_at`. 재발 방지: v2_path_runs 시계열 분석은 이 두 필드 기준.
- 공통 한계: 전 축이 "6월 단일국면 + net_est 41% 커버리지" 위 — 승격 판단 시 이 selection 명시 필수.
