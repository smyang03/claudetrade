# 토론 판정 — 저빈도는 자기충족 구조적 결함인가 (2026-06-30)

- 형식: 12관점 찬반토론(PRO 2 / CON 2 + 사회자 직접 검증), read-only
- 명제: "현 전략(눌림→비대칭 꼬리)이 모든 검증(국면·DB·논리)에서 '맞다'고 나오는 건 낮은 진입빈도(KR 수일째 ~0)를 정당화하는 자기충족이고, 기다리는 '깨끗한 눌림' 출현확률이 실제로 낮다 = 구조적 결함이다."

## 판정: 명제 **반대(기각)**

저빈도는 자기충족 결함이 아니라, 반증가능하게 작동하는 손실회피 선별의 결과. 단 KR 표본이 얇아 엣지가 통계적으로 검증 불능이라는 PRO의 알맹이는 유효(결함이 아니라 측정 한계).

## 사회자 직접 검증 (판정 가른 데이터)

게이트 단계별 forward_3d (평균 vs 중앙값):

| 단계 | KR | US |
|---|---|---|
| trade_ready=0(품질미달) | med -6.14%, 69%neg (n7710) | med 0.00, 50%neg (n8982) |
| trade_ready=1 +실매수 | med +0.53%, 45%neg (n20) | med +3.20%, 33%neg (n15) |
| trade_ready=1 +안산 | mean +2.53 / **med -3.30**, 64%neg (n110) | mean +0.73 / med +1.09 (n408) |

- **PRO-B "거부한 눌림 +2.53%로 더 올랐다"는 평균 착시** — 같은 모집단 중앙값 -3.30%, 64% 음수. 평균만 affordability로 못 산 비싼 급등주 outlier(+16.85)가 끌어올림.
- **결정적 반증**: 품질통과 중 산 것이 안 산 것보다 양 시장 모두 중앙값 우위(KR +0.53 vs -3.30, US +3.20 vs +1.09) = 체결 단계가 더 나은 부분집합 선택. "눌림 놓침" 정반대.

## 합의 / 기각 / 살아남은 알맹이

| 구분 | 내용 |
|---|---|
| 합의 | KR 빈도 진짜 얇다(전환율 0.29%, 64% 0진입일, 산 것 n20) |
| 합의 | "0 매수"는 Path A 착시 — Path B 6월 KR 18건 net +0.955% |
| 기각: 자기충족 | forward 후보 87% backfill = 반증가능(PRO-B 자인) |
| 기각: 손실회피 작동 | 안-산 품질미달 KR med -6.14%, 69%neg = 거른 게 실제 빠짐 |
| 기각: 눌림 놓침 | 산 것 > 안 산 것(중앙값, 양 시장) = 체결이 잘 고름 |
| 기각: 빈도가 레버 | US 빈도충분(92% fill·~6건)인데 net -0.642% = 늘려도 더 나쁨 |
| 살아남음 | KR 엣지 표본 얇아 통계 검증불능(n18~20, +0.955%≈0). 결함 아닌 측정한계 |
| 살아남음 | 진짜 레버는 빈도 아닌 US 비용/capture(cost-truth 재확인) |

## 운영자용 한 줄
"매수 0이니 출현확률 낮은 결함 아니냐" → 아니오. 게이트는 반증가능하게 작동(거른 게 빠짐), 체결은 통과분 중 더 나은 걸 선택. KR 얇음은 손실회피 결과지 결함 아니며, 빈도 늘린 US가 적자라는 게 결정적 반증. 레버는 "더 사기"가 아니라 US 비용/capture.
