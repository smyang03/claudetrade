## 3. 실패에서 나온 것 (운영자 질문의 핵심)

### ① 45전략이 지수를 못 이겼다는 사실 자체가 방향이다

종목 선택 축은 KR·US 양쪽에서, 급락·내부자·자사주·어닝·거래량 다섯 계열에서 전부 0이다.

연도매칭 벤치 기준). **선택을 버리고 타이밍으로 간다**는 뜻이다.

### ② 원 net → 초과 부호 역전이 다수다 = 우리가 번 건 대부분 베타였다

`c_kr_insider_k1` +2.79% → −0.75% · `c_kr_insider_cluster` +0.25% → −3.64% ·

게이트 v3(§4 오늘 반영)가 이걸 앞으로 자동으로 걸러낸다.
