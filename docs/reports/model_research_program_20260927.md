## 3. 공통 사전등록 규약 (모든 트랙)

1. 규칙·피처·아키텍처·기본 파라미터를 **실행 전** 스크립트 docstring에 고정. 튜닝은 학습 구간 내부 교차검증만.
2. 워크포워드(확장창, 보유기간만큼 퍼지). 피처는 결정 시점 이전 정보만 — 공시·실적은 **발표 시각 기준 다음 체결 가능 가격**부터.
3. 결과 = **비용 후 초과수익**(KR 0.25%·US 0.5% 왕복, 규모매칭 또는 IWM/지수 벤치). t는 **날짜 클러스터**(보유 겹침은 Newey-West).
4. 합격 = 기준선보다 나음 + 전·후반 부호 유지 + 트랙 내 검정 수로 보정한 t(기본 t ≥ 3).
5. LLM(Claude) 판정은 **모델 학습 컷오프(2026-06) 이후 사건만** 평가 — 기억한 사건으로 맞히는 것을 막는다.
6. 생존편향: 현재 상장 종목 가격만 있는 트랙(T1·T3·T4)은 한계로 명시하고, 판정은 같은 모집단 내부 비교로만.
