### P3. 손실꼬리 축소 (US LOSS_CAP −43pp/15건)

기존 판정: 낙하체결은 사전변별 불가, 손절은 이미 관리형. 미시도 축 하나: **보유 중 조기경보** — 진입 후 N분 MAE 경로가 loss_cap 코호트 패턴과 일치하면 부분 조기 이탈(shadow). 전제 데이터 = mfe/mae_time → **시간축 백필**(이미 합의된 과제)과 한 세트.

### P4. 안정성·정합성 5건 (사고 방지 = 손실 방지, 전부 소규모)

1. **메인 루프 catch-all + 잡 단위 예외 격리** — 잡 예외 1개로 양 시장 사망하는 구조 제거. 예외는 삼키지 않고 로그+텔레그램+해당 잡 스킵.
2. **watchdog heartbeat hang 감지** — guardian이 봇 heartbeat 나이를 판정에 포함(기존 heartbeat 파일 재사용, 새 배선 없음).
3. **설정 불일치 preflight 승격** — env_vs_start_config 검사를 화이트리스트 밖 전 키 diff로 확장(WARN), 발견된 4건은 운영자 확인 후 정합화.
4. **exit 락 분리** — 하드 스톱(loss_cap/hard_stop)을 소프트 중재와 별도 경로로(손실 방어는 어떤 경우에도 대기열 없음).
5. **WS 구독에 보유 포지션 강제 합집합** — 사실 확인 후 1줄 보강.
1·2·4·5는 라이브 코드 — **장중 편집 금지 원칙상 US 마감(05:00) 후 구현**. 3은 preflight 도구라 즉시 가능.
