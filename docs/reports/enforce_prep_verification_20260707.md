# Enforce 준비 검증 종합 (2026-07-07)

지시: "3번(US 소액검증)은 운영자 직접 설정, 나머지 전부 검증해서 enforce 들어갈 수 있게 준비" + 별도 문서("최종 진행 방향" — 비추격 게이트 제안) 검토.
방식: 병렬 검증 5건(스로틀·비용·배선실험·INTRADAY_SELL·비추격 필터) + 섹터캡·KR포켓. 전부 read-only. 데이터: v2_event_store.db CLOSED dedup (KR 36 / US 222).

---

## 1. 스로틀 재판정 — KR 반사망 확인, 범인은 RR 3중 조합

- KR fill은 7/1 이후 4세션 1건(6월 페이스 대비 ~85% 감소). 단 드라우트 시작은 **6/25**(RR 이전, 국면 게이트) — 후반부가 RR 압착.
- 범인 수학: `PATHB_CONSISTENT_REWARD_RISK=true`(앵커 bzh) × `PATHB_DETERMINISTIC_SELL_TARGET_CAP_PCT=4`(목표 절단) × `PATHB_MIN_REWARD_RISK=1.5` → **stop 거리 ≤2.67% 강제** = KR 통상 stop 폭(2~3.6%)과 정면충돌. 7/6 KR 3건 중 conf 통과 플랜(007680, conf 0.60, 레거시 RR 2.83)이 정확히 이 조합에 사망.
- conf<0.5 층이 실은 최다 킬러(7/1 이후 세션당 2.25건) — 운영자 확인 필수 파라미터라 처방 제외.
- **KR만 푸는 시장별 키는 코드에 없음**(전부 글로벌). 운영자 선택지:
  - 1안(최소): `PATHB_DETERMINISTIC_SELL_TARGET_CAP_PCT` 4→0 — 목표캡 해제(loophole 재개방 부작용)
  - 2안: `PATHB_MIN_REWARD_RISK` 1.5→1.1 — RR 사망 4건 중 3건 복구
  - 3안(롤백): `PATHB_CONSISTENT_REWARD_RISK` true→false — 7/1 이전 복귀
  - 4안(코드): `{MARKET}_` 접두 시장별 키 구현(KR만 완화, US 스로틀 유지) — **소액검증(3번)과 정합적이라 권장 후보**, 구현은 지시 시
  - 어느 안이든 `.env.live`+`config/v2_start_config.json` 양쪽 수정+재시작.

## 2. 비용 실측 — 수수료는 실측완료, FX 0.2는 과대 차감 개연성

- **fee 0.50% RT는 이미 실측 검증된 상수**(6/13 KIS TTTS3039R 207건, 0.497%). 불확실성 ±0.2%p의 실체는 전부 FX.
- **FX 0.20%는 코드 default**(`US_FX_SPREAD_RATE_PER_SIDE=0.001`, env/config 미설정) 이고, **시스템은 달러잔고 회전 중**: 거래별 환전 코드 0건, USD 예수금 $2,650 실측(7/6 스냅샷). → 거래당 0.20% FX 차감은 과대(비관) 개연성. 사실이면 **US 통산 net이 거래당 +0.2%p 상향 정정**(−0.334→−0.134 수준).
- 확정 방법: **운영자 환전내역(MTS/명세서) 1회 대조** — 4~7월 환전 건수·적용환율. 환전≈0건이면 `US_FX_SPREAD_RATE_PER_SIDE`를 0 근처로 정정(운영자 확인 필수 절차, 양쪽 반영)하고 초기환전은 고정비로 분리.
- 수수료 드리프트 감시용 백필 도구 설계 완료(기간손익 API → `fee_pct_round_trip_measured` additive 필드, 기존 backfill 패턴). 구현은 지시 시.

## 3. 배선 실험 3종 — 전부 정상, 첫 forward 표본 발생

| 실험 | 상태 | 표본 | 판독까지 |
|---|---|---|---|
| red-tape (US enforce) | 배선 정상(`_index_history` 채워짐), 7/6 무발동=tape 초록(+0.14%)이라 설계대로 | red 0/20 | 시장 의존(빨간 개장일에만 쌓임) |
| zone-fill shadow | 작동 — 첫 표본 NVDA **zone_pos=1.0**(존 최상단 추격 체결, in-sample 나쁜 패턴 재현) | 1/~50 | 수개월(현 페이스) |
| ladder A/B + floor_shadow | 7/3 복구 후 첫 기록 확증(NVDA weak_mfe_shadow, B그룹) | A/B 2/30 | 2~3개월(현 페이스) |

**공통 병목 = 진입 페이스**(7/6 US 퍼널: TRADE_READY 12 → RR컷 등으로 플랜 2 → 체결 1). 운영자의 3번(소액검증) 설정이 유일한 가속 레버.

## 4. INTRADAY_SELL 분봉 counterfactual — **판정: 유지**

- 15건 측정: counterfactual 13건이 LOSS_CAP행. **Δ 합계 +4.79pp, 13/15 이득** — off하면 더 나빠짐. 드레인 −16.6은 죽을 포지션을 더 싸게 기록한 것.
- 얇은 마진 경고: 13건 소액 절약(+17.7) vs 2건 회복 학살(−12.9, IBM·AAPL TARGET 도달) — fat-tail형. "이익 중 종목은 INTRADAY_SELL 제외" 세분화는 n=2라 판정 불가, 관찰 지점만 기록.

## 5. 섹터캡 — enforce 부활 부당 판정 유지 (설계안 D5 정정)

- 측정 도구 재실행: k≥3 동시발화 일평균 **+1.15 양수**(승자 창구도 동섹터 군집: 5/21·5/22·6/1). enforce는 승자 창구까지 자름. 좌꼬리(p10 −9.68 vs k=1 −2.64)만 계속 관찰. 7/2 갭감사 판정 유지.

## 7. "최종 진행 방향" 문서 검토 — 비추격 게이트(US, 5d<+3% 차단)

**전체 철학(급등 초기 수확+손실 필터, selection·출구 유지, 예측 폐기)은 기존 검증과 정합. 그러나 1번 레버의 "적자→흑자(−67.6→+38.0)"는 재현 실패 — shadow는 정당, enforce는 현 증거로 불가.**

사회자 재계산 (US 222건 전건, 티커별 진입 전일 기준 5일 수익률, no-lookahead):

| 검정 | 결과 | 판정 |
|---|---|---|
| 전체 분리 | 유지(5d≥+3%) n=96 합 **+3.29** / 차단 n=126 합 −77.33 | 방향 재현, **흑자 아닌 본전**(+38.0 재현 안 됨) |
| 월별 통제 | **4월 부호 역전**(추격 −0.85 vs 비추격 +0.50), 5월 둘 다 양수, 6월 둘 다 음수 | "양월 일관" 불성립 — 분리는 6월 주도 |
| outlier | 유지그룹 top-1 제거 시 **−13.31 음전**(+16.61 1건 의존), top-3 −31.37 | 취약 |
| 임계 민감도 | cut=2 → −2.03, cut=3 → +3.29, cut=5 → −4.13, cut=8 → −28.06 | **cut=3 유일 피크 = 커브핏 신호**(단조성 없음) |
| KR 교차 | KR 추격 −0.106 vs **비추격 +1.488 — 완전 역전** | 7/1 패자필터 토론의 KR↔US 부호역전 함정 재현 |
| TARGET 꼬리 | 21건 중 비추격 7건(+33.87)도 차단됨 | 꼬리 1/3 절단 |
| 빈도 | 126/222 = **57% 차단** — 기존 스로틀 위에 겹침 | 3번(표본 재개)·실험 판독과 정면 상충 |

결론: **US 한정 shadow(would-block 로깅)로 채택, enforce 전환 조건 명시** — forward 차단표본 n≥30에서 차단군 net<0 이고 4월형 역전 미재현 + 유지군 outlier 제거 후에도 우위일 때. 문서 스스로 "shadow 며칠"이라 한 것과 일치하며, in-sample 수치(+38.0)는 인용 금지(재현 안 됨).

## 실행 대기 목록 (운영자 결정/승인)

1. **3번 소액검증 설정** — 운영자 직접 (모든 실험 판독의 전제).
2. **RR 압착 완화안 선택** — 1/2/3/4안 중(4안=시장별 키 코드가 소액검증과 정합).
3. **FX 확정** — 환전내역 1회 대조 → `US_FX_SPREAD_RATE_PER_SIDE` 정정 여부.
4. **비추격 shadow 구현 승인** — 진입 게이트라 운영자 확인 필수(would-block 로깅만, 매매 무접촉).
