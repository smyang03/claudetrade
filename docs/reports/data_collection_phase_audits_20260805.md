## C. 월 스위치 3차 탐색(후보 풀 조성) — 기각, 이로써 세 각도 전소진

월 성과(rank1 tp12_sl25, 14개월)와 풀 조성 지표 10종(세션당 후보 수, 평균 낙폭,
급락 비중, 갭 성분, rv20, 거래대금, 산포 등 — 전부 신호 시점 관측 가능값) 상관:

```
최대 |r| = 0.447 (volume_ratio, p=0.109) — 사전 기준(|r|>0.7 && p<0.01) 미달
나머지 전부 |r| < 0.4
```

세 각도 판정 이력:
1. 시장 국면(SPY 수익·변동성·낙폭) — 기각 (좋은 달에 조용한 상승장과 급락장 혼재)
2. 모델 확신(probability) — 기각 (2026-03 단일 이상치의 재포장, no-lookahead에서 소멸)
3. 후보 풀 조성 — 기각 (본 문서)

**결론: 좋은 달을 사전에 식별할 수단이 우리 데이터에 없다. "매일 참가"가 세 번
검증된 유일한 전략이다.** 이후 스위치 탐색은 새 데이터 축적 전까지 중단한다
(같은 14개월을 계속 파면 다중검정으로 가짜만 나온다).
