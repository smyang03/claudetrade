- **대체 신호(목표가 개정 드리프트)는 과거 검정 가능.** 2018-04~ 날짜별 리포트 이력이 약관상 깨끗한 경로로 나온다. 한계는 생존편향·소형주 희소·발표 시각 없음이다. 별도 사전등록 대상이다(순 목표가 상향 비율·개정 폭, 다음 날 시가 진입, H20, 규모매칭 벤치, 날짜 클러스터 t).
- 백필 비용 추정: 100행 상한이라 대형주는 월 단위 창(8.5년 ≈ 100회/종목)이 필요하다. 소형주는 1~2회다. 창에 100행이 차면 반으로 쪼개는 적응형 분할이면 KR 커버 종목 전체로 수천~1만 회 규모다. 1 req/s 장후 한도로 여러 날에 나눠 수행한다(정확한 호출 수는 산출 불가 — 커버 종목 수 미측정).
