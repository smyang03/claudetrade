# 사전등록 — 운영자 예외 슬롯: KR 공개매수 차익 (2026-11-20)

**상태: 등록 (2026-11-20, 운영자 "계속진행 멈추지마" — Q4·2027 Q1 슬롯 소진 상태의 운영자 예외, hi52와 같은 처리).** 아래 기준은 이 커밋 이후 변경 금지 — 변경은 "개정" 섹션 추가로만.
이 문서를 커밋하는 시점에 공개매수 명단은 수집 중이고(OpenDART D004 공시 본문 파싱, 에이전트), 대상 종목의 가격·수익률은 조회하지 않았다.

## 이미 알려진 사실 (사후 맞춤 경계)

- 저장소에 공개매수 판정은 없다(`git grep 공개매수 docs/reports` 0건, 11-20 확인).
- OpenDART D004 공개매수신고서(정정 제외) 2015~2026: 17·11·22·19·5·7·13·5·19·26·21·33건(연도순). 신고인 법인구분은 유가 148·코스닥 93·기타 76(정정 포함 집계, 대상이 비상장일 수 있다).
- 해외 문헌: 현금 인수·공개매수 차익은 연 수 %의 초과가 있으나 실패 꼬리가 크다(합병차익 프록시 MNA는 11-11에 비용 때문에 기각 — US·ETF라 이 등록과 다른 표본).

## 가설

| 항목 | 값 |
|---|---|
| 메커니즘 | 공개매수가(P*)가 고정된 뒤 대상 주식은 P*보다 낮게 거래되고 기간 말로 갈수록 P*로 수렴한다(차익 스프레드 = 실패·안분 위험 보상) |
| 표본 | `data/analysis/kr_tender_offers/kr_tender_offers.csv` 중 대상이 KOSPI·KOSDAQ 상장 보통주이고 공개매수가·기간이 파싱된 원 신고(정정 반영). 자기주식 공개매수 포함 |
| 진입 | 신고서 접수일(rcept_dt) 다음 거래일 시가(장중·장전 접수 구분 없이 보수적으로). **진입 시가 ≥ P*면 그 건은 거래 안 함**(스프레드 없음, 표본 수로 보고) |
| 청산 | 공개매수 기간 종료일(정정 반영 최종값) 종가에 장내 매도. 종료일이 휴장이면 그 이전 마지막 거래일. 응모는 가정하지 않는다(수작업 불필요한 계약) |
| 비용 | 왕복 0.25% |
| 지표 | 규모매칭 초과(L7 엔진 `research_kr_index_inclusion_20261030.py` Book.size_bench)가 주, 원 net(비용 후)이 보조 |
| t | 접수월 클러스터(같은 달 이벤트 평균 = 1관측) |
| IS/OOS | IS 2015~2019 / OOS 2020~ |
| 합격 | 클러스터 t ≥ 2.64 **그리고** IS·OOS 같은 부호(+) **그리고** 양 클러스터 과반 |
| 기각 | 위 셋 중 하나라도 미달 |
| 검정 불가 | 거래한(스프레드 있는) 이벤트 < 40, 또는 진입·청산 봉 있는 비율 < 80% |
| 보조(판정 제외) | ① 전량(상한 없음)·상장폐지 목적 vs 부분(상한) ② 자기주식 vs 제3자 ③ 가격 인상(정정)·경쟁 공개매수 건 ④ 발표 직전 종가 → 진입 시가 갭 ⑤ 실패 건 손실 분포(최악 5건) ⑥ 진입 스프레드(P*/시가−1) 구간별 |
| 통과 후 | KR 격리 레인(L7 도구 패턴)으로 실전 제안 — 건당 금액·동시 보유는 운영자 결정. 명단은 OpenDART D004 자동 수집(공식 API) |
| 반대 근거 | ① 발표 당일 상한가 등으로 진입 시가가 이미 P* 근처 → 거래 건이 줄고 남는 건은 실패 위험 큰 건(역선택) ② 부분 공개매수는 기간 말 안분 확정 후 가격이 원래로 돌아갈 수 있다(장내 매도 계약은 기간 말 종가라 일부 반영) ③ 경영권 분쟁 건(경쟁 공개매수)은 가격이 P*를 넘어 오버슈팅 — 평균을 끌어올리는 소수 건 편중 ④ 생존편향 없음(공시 전수) 대신 파싱 오류 |
| 환산식 | 건당 투입 × 이벤트 평균 net × 연간 거래 이벤트 수 |
