# 가상 운용 → 실투자 승격 게이트 (사전등록 정본, 2026-09-01)

**상태: 운영자 승인 완료 (2026-09-01 저녁, 한 단어 승인). 이 문서가 정본이며, 이후
변경은 골대 이동으로 간주하고 운영자 승인 + 새 epoch에서만 허용한다.**
작성: Claude + Codex(gpt-5.6-sol) 공동, 09-01 검토 2회분.

배경: 09-01 운영자 결정으로 신규 실매수 전면 중단(가상 운용 전환). 가상 북
(`tools/virtual_books.py`, `data/shadow/virtual_books.db`)이 다전략을 병행 운용하며,
이 게이트를 통과한 전략만 실투자 복귀(env 원복 + 운영자 승인) 후보가 된다.

## 2. 표본 규약

- **판정 표본 = forward만** (2026-09-01 이후 진입). 백필(08-12~31)은 배관 검증 전용.
- 운영 무결성: 첫 10세션에서 장부 대사(`reconcile`) 100% 통과, 계약 지문 변경 0건.
- 30건 체크포인트 = 조기 경보 전용(재앙 탐지). 승격 판정 아님.
- 최종 판정(US): **시장 세션 80개 + 정산 50건 + 거래 발생 40세션 + 달력 3개월** 모두 충족 후,
  마지막 진입 코호트 완결 시점.
- 최종 판정(KR): 세션 80 + 정산 30 + 거래 20세션 + 3개월.
- N을 채우고도 허들 미달이면 "실패"가 아니라 가상 운용 지속.

## 3. 승격 지표 (전부 충족)

- 비용 후 건당 평균 net ≥ +0.25%, PF ≥ 1.20
- 같은 세션·같은 K 무작위 널 대비 알파의 95% 블록 LCB > 0
  (entry_session 단위 클러스터, stationary bootstrap 평균 블록 10세션 × 10,000회)
- 비용 스트레스: US 총비용 0.80% / KR +0.20%p 적용 후 평균 net > 0
- 상위 수익 3세션 제외 평균 > 0, 단일 월 기여 ≤ 전체 이익의 50%
- funded 북 MaxDD ≤ 20%, 데이터 결측률 ≤ 1%, 대사 불일치 0건
- K>1 전략은 **한계 슬롯별**로도 위 조건 통과 (총합 아님)
- family 간 Holm + F0 내부 max-stat 통과 시에만 "최종 승자"

## 5. 복귀 방식

게이트 통과 ≠ 전체 SUBMIT 복구. 통과 전략 **1개**만 소액 canary(현행 micro 계약)로
복귀하고, canary 20세션에서 실행 드리프트(가상 대비 shortfall p50/p90)가 가정 비용 안에
들어와야 증액 논의를 시작한다. 복귀·증액 모두 운영자 승인 필수.

## 6. 운영 규율 (Codex 채택분)

- **변경 열차**: 전략 파라미터·정산 코드는 묶음 변경 + 새 contract_hash + 새 epoch.
  엔진이 지문 변경을 감지하면 경고를 찍는다(`sync_strategies`).
- **일일 장부 대사**: `virtual_books.py reconcile` — 불일치 시 그날 성과 확정 금지.
- **겹침/상관 감시**: `overlap_report` — wide 계열은 상관 0.6~0.9로 사실상 단일 엣지임을
  전제로 판정(독립 증거로 중복 계상 금지). 실측(09-01 백필): slow_fallen이 급락 계열과
  음의 상관(−0.6~−0.7) = 유일한 실질 분산축.
- 월 1회 장애 훈련(stale 가격·봉 누락·중복 스케줄·재시작 주입)은 10월 첫 주부터.
