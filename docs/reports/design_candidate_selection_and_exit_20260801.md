# 상세 설계 — 급락 반등 레인의 후보 선정 · 매도 시점 · Claude 역할

2026-08-01 (2차). 운영자 지시: "적용 말고 다양한 측면으로 검토·검증까지. 특히 후보군 선정이 필수. 매도는 지금대로 할지. Claude가 어떻게 떨어진 후보를 잘 고를지. Claude 후보군 선정 방식 변경 포함."

검증 데이터: US 급락 이벤트 **13,818건**(839종목×6개월) / KR **15,234건**(641종목×6개월) / us_swing 모델 신호 70건. 전부 학습(2~4월)·검증(5~7월) 분리.

## 1. 후보군 선정 — "충분히 떨어진 것 중 상승요소가 있는 것"의 실체

### 1-1. US: 상승요소 5개 (학습에서 선정, 검증에서 유지)
낙폭 3%+ 전수 13,818건에 피처 12종을 붙여 4분위 분석. 방향이 검증기간에도 유지된 것:

| 상승요소 | 조건(학습 중앙값 기준) | 의미 |
|---|---|---|
| 낙폭 크기 | drop ≥ 4.7% | 얕은 조정이 아니라 진짜 급락 |
| **장중 하락 비중** | intraday ≥ 3.7%p | **갭(뉴스)이 아니라 장중 투매** |
| 기존 약세 | mom20 ≤ −5.7% | 이미 하락 추세였던 종목 |
| 고점 이탈 | from_high20 ≤ −15.8% | 고점에서 충분히 밀려남 |
| 연속 투매 | cum3d ≤ −5.2% | 3일 누적 하락 (일회성 아님) |

**5조건 AND 결과 (검증기간 5~7월): n=980, 건당 +1.152%, 승률 53.4%** vs 잔여군 +0.16. 월별 +2.12 / −0.15 / +1.68.
프로필 요약: **"이미 무너지던 종목이 뉴스 없이 장중 투매로 3일 연속 밀린 경우"**가 반등한다.

### 1-2. 알파 모델은 같은 프로필의 극단을 고른다 (역공학)
모델 픽 16건 vs 7월 모집단 중앙값: 낙폭 **10.9 vs 4.7** / 장중하락 **8.1 vs 3.7** / mom20 **−32 vs −7** / 고점대비 **−38 vs −19** / cum3d **−16 vs −5.5**. 규칙필터 통과율 62% vs 모집단 19%.
→ 모델의 "상승요소" = 위 5요소의 극단값 + 비선형 결합. **규칙필터는 모델의 해석 가능한 근사이며, 1차 깔때기로 쓰고 최종 랭킹은 모델이 한다.**

### 1-3. KR: 상승요소 8개 — 미국과 부분적으로 정반대
KR 15,234건 동일 분석. 검증기간 기저가 −1.94(학습 +1.03에서 반전 — KR 국면 의존이 US보다 크다).

| KR 상승요소 | 조건 | US와 비교 |
|---|---|---|
| 낙폭 크기 | drop ≥ 5.3% | 동일 방향 |
| **갭 하락 비중** | gap ≥ 0.9%p | **US와 반대** (US는 장중, KR은 갭) |
| 종가 위치 | close_pos ≥ 0.14 | 저가 마감이 아닐 것 |
| 거래 확대 | vol_spike ≥ 0.64 | |
| 모멘텀 | mom20 ≤ +4.7% | 과열 아님(약한 조건) |
| 고점 이탈 | from_high20 ≤ −21% | 동일 방향 |
| **저변동성** | rv20 ≤ 6.2 | 원래 얌전하던 종목의 급락 |
| 가격대 | ≥ 7,110원 | 동전주 배제 |

**8조건 AND 결과 (검증): n=141, 건당 +3.347%, 승률 68.8%** vs 잔여군 −2.01. 월별 +0.29 / +6.83 / +1.46 (3개월 전부 양수).
프로필: **"원래 저변동이던 중가격대 종목이 갭 하락으로 고점 −21% 아래까지 밀렸지만 저가 마감은 아닌 경우"** — 미국(투매 지속형)과 다른, 과잉반응 회복형이다.

### 1-4. 방법론 경고 (정직하게)
- 피처 "유지 여부" 판정에 검증기간을 참조했다(**경미한 누출**). 임계값 자체는 학습 중앙값이지만, **이 규칙들은 forward shadow 검증 전 enforce 금지.**
- KR 8조건은 조건 수가 많아 과적합 위험이 US보다 크다. n=141로 표본도 작다.
- 유니버스는 시스템 관찰 종목(839/641)이라 선택 편향 잔존.

## 2. 매도 시점 — 현행 유지 확정 (검증기간 n=980)

| 검증 | 결과 |
|---|---|
| SL 스윕 | −10% 전멸(−0.04~−0.15) → **넓을수록 단조 개선**, −25 이후 평탄(+1.15→+1.25). 현행 −25 적정 |
| TP 스윕 | **+12가 스윗스팟**(전 SL행에서 최대). 현행 +12 적정 |
| 보유일수 | **D2 −0.35 / D3 −0.34 / D5 +1.15** / D7 +1.07 / D10 +0.86 → 반등에 3~5일 필요, **조기청산이 손실원이라는 기존 실측과 일치** |
| 대안 청산 | 첫 갭업4%+ 시가매도 +1.30(근소 우위, 승률↓) / 트레일링 +0.62(열등) / TP+20·D10 월별 부호 반전 |
| 월별 안정성 | **TP+12/SL−25/D5가 유일하게 안정**(5월 +2.1 / 6월 −0.15 / 7월 +1.7) |

**결론: 매도는 지금대로(TP+12 / SL−25 / D5). 교체 근거 없음.** 유일한 개선 후보(갭업4% 시가매도)는 shadow 관측 항목으로만 등재.

⚠️ 재확인된 규율: 진입 규약(t일 종가정보→t+1 시가)과 같은 규약으로 캘리브레이션했다. KR 청산 파라미터는 KR 자체 스윕 필요(이번엔 US 값 차용 검증만 했고, KR 최적은 별도 확정 전 — K2 단계 항목).

## 3. Claude의 역할 재설계 — "후보를 만들지 말고, 거부하라"

### 3-1. 왜 Claude가 후보를 만들면 안 되는가 (실측 근거)
- 선별의 실체는 **수치 피처의 극단값 결합**이다(§1-2). 이것은 GBM이 하는 일이고 Claude가 실시간으로 흉내낼 이유가 없다.
- 기존 Claude selection은 모멘텀/상승 후보 중심 파이프라인 — 이 레인의 모집단(급락주)과 정반대다.
- "뉴스성 낙폭 회피"조차 계량 피처가 이미 처리한다: US에서 gap_part는 판별력이 불안정하고 intraday_part가 안정 → **갭/장중 분해가 뉴스 필터의 검증된 대용물**이다.

### 3-2. Claude가 실제로 기여할 수 있는 곳 (검증 가능한 형태로 한정)
| 역할 | 내용 | 검증 방법 |
|---|---|---|
| **구조적 악재 거부권(veto)** | 규칙+모델 통과 후보 top-K에 대해서만: 상장폐지/거래정지/횡령·소송/유상증자/감자 등 **회복 불능 사유** 여부 판단. 기술적 판단 금지, 사유 카테고리만 | veto된 후보의 반사실 성과를 shadow 원장에 기록 → veto 순가치 실측 |
| 실적발 낙폭 분류 | 어닝 캘린더 ±1일 낙폭 표시(계량) + Claude는 가이던스 하향 여부만 | 캘린더 데이터 축적 후(현재 7/29~만 보유) 소급 검증 |
| 주간 회고 | 레인 성과·미스 분석 리포트 | — |

**Claude 프롬프트는 시장별로 달라야 한다**: US veto는 "장중 투매의 구조적 사유"를, KR veto는 "갭 하락의 공시 사유"를 본다(§1-3의 반대 프로필).

### 3-3. 후보군 파이프라인 목표 형태
```
[US]  KIS day_losers 랭킹 → 하드필터(5조건, §1-1) → 알파모델 랭킹 top5
      → Claude veto(구조적 악재만) → 슬롯 내 매수 → TP12/SL25/D5
[KR]  전종목 등락률 스크린(낙폭 5~29.7%) → 하드필터(8조건, §1-3) → KR 알파모델(K2에서 학습)
      → Claude veto(공시 사유) → (K3까지 shadow)
```
기존 Claude selection(candidate_pool→selection→judge)은 **이 레인에 관여하지 않는다.** PathB용으로 존속하되 자원 우선순위는 이 레인.

## 4. 검증 로드맵 (enforce 전 필수)

1. **US 하드필터 shadow**: 매일 5조건 통과 종목을 shadow 원장에 기록(주문 없음). 4주 후 forward 평균>0 확인 → 모델 앞단 깔때기로 정식 채택
2. **KR 8조건 shadow**: 동일. KR은 국면 반전(기저 +1.03→−1.94)이 커서 최소 6주
3. **Claude veto shadow**: top-K에 veto 판단만 기록, 실주문 영향 없음 → veto 순가치 측정
4. **KR 청산 스윕**: KR 이벤트 15,234건으로 TP/SL/hold 자체 캘리브레이션 (§2와 동일 방법론, 진입 규약 명시)
5. 기존 로드맵(설계 1차 문서)의 K1 데이터셋·모델 학습과 병렬

**운영자 결정 대기**: 위 shadow 3종의 구현 착수 승인(코드 작업, 주문 무영향).
