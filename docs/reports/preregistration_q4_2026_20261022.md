## 2. T1 + 매출 서프라이즈 같은 방향 (L1 강화 → 통과 시 새 레인 T1-rev)

| 항목 | 값 |
|---|---|
| 메커니즘 | 매출 서프라이즈가 EPS 서프라이즈와 같은 방향이면 이익 변화 지속성이 크고 드리프트가 강하다(Jegadeesh-Livnat 2006) |
| 저장소 사실 | T1 M2 피처 14개에 매출 없음. `us_earnings_dates.jsonl`은 EPS만. Jev 8-K 본문 "예측"은 기각(E1 t 0.47) — 매출 **숫자**를 조건으로 쓴 검정은 없음 |
| 데이터(현재 없음) | SEC companyfacts(`Revenues`·`RevenueFromContractWithCustomerExcludingAssessedTax`·`SalesRevenueNet`, `filed` 일자). Q4는 연간 − 9개월 누적으로 유도, 회계연도 비정렬은 `frame`(CY####Q#) 기준. 서프라이즈 = (분기 매출 − 전년 동분기) / 직전 8분기 변화 표준편차(추정치 불필요) |
| **게이트(먼저)** | 10-Q 공시일은 발표(8-K 2.02)보다 늦다 → 발표 시점에 10-Q 값을 썼다고 가정하면 lookahead. Jev가 수집한 EX-99.1 5,022건으로 "보도자료 매출 = 10-Q 매출" 일치율을 잰다. **≥ 95%일 때만 진행**, 미달이면 검정 불가 |
| 주 행 | T1 I1 선정 이벤트(2017~2026 워크포워드 그대로) 안에서 매출 SUE 같은 방향 하위집합 vs 반대 방향 하위집합. 지표 = IWM 대비 net(0.5%) 차이의 주간 NW t |
| 합격 | 차이 t ≥ 2.64 **그리고** 반기별 같은 부호 **그리고** 같은 방향 하위집합 ≥ 연 25건 |
| 기각 | 위 셋 중 하나라도 미달 |
| 검정 불가 | 게이트 미달, 또는 companyfacts 매핑 가능 종목이 T1 선정 이벤트의 80% 미만 |

## 3. KR 현금배당 증가 공시

| 항목 | 값 |
|---|---|
| 메커니즘 | 배당 변화 = 이익 지속성 신호, 늦게 반영(Michaely-Thaler-Womack 1995). KR 2026~28 고배당 분리과세(배당성향 40% 또는 25%+전년 대비 증가)로 "증가" 자체가 세제 자격 |
| 데이터(현재 없음) | OpenDART `list.json`(pblntf_ty=I, "현금·현물배당결정"(DART 원문은 가운뎃점 호환자모)) + `document.xml`(1주당 배당금, 시가배당률). 전년 DPS는 `alotMatter.json`(전년 사업보고서, PIT 문제 없음). `research_kr_event_20260930.py` KINDS에 배당 없음 → 신규 수집 |

| 주 행 | DPS 전년 대비 ≥ +20% **그리고** 시가배당률 ≥ 2%. 다음 시가 진입, H20, 비용 0.25% |
| 벤치 | 규모매칭이 주, KOSPI200 보조, **공시 종목 전체(T2 기저 h1 −0.66%)** 병기 |
| t | 진입일 클러스터 NW t. IS 2015~2022, OOS 2023~ |
| 합격 | t ≥ 2.64 **그리고** OOS 연도 부호 과반 **그리고** 2024 제외 시 같은 부호(L2 교훈) |
| 기각 | 위 셋 중 하나라도 미달 |
| 검정 불가 | 12-31까지 2015~ 배당결정 공시 수집률이 DART 건수 대비 90% 미만 |

## 개정 1 (2026-10-30) — T1-rev 환산식 정정 · 매핑 조건 실측

하위집합 검정(같은 방향 vs 반대 방향 수익률)은 아직 돌리지 않았다. 아래는 결과를 보기 전의 개정이다.

**환산식 정정.** §2의 "T1 예산 200만 × 건당 개선분 × 연 55건 × 같은 방향 비율"은 거래마다 예산 전체를 투입하는 계산이라 틀렸다(코덱스 지적).
정정식은 **슬롯 금액(현행 `T1_LIVE_SLOT_KRW` 28만) × 조건부 건당 개선분 × 연 실행 건수 × 같은 방향 비율**이다.
연 실행 건수는 판정 때 라이브 근사 시뮬레이션(동시 7슬롯·하루 1건·20세션 보유·거래대금 $5M 이상)으로 잰다. 상한은 7 × 252 / 20 ≈ 연 88건이다.
예: 건당 개선 1%, 88건 전부 해당이면 연 24.6만원이다.

**80% 매핑 조건 실측(10-30).** 10-22 게이트의 커버리지 91.4%는 EX-99.1이 연결된 하위집합 기준이었다. 조건의 분모인 전체 T1 I1 선정 이벤트로 다시 쟀다.
규칙은 게이트와 같다(분기 사실 end ∈ [D−100, D−10], filed ≥ D−3, 원 공시, Q4 = FY − 9M YTD). companyfacts는 CIK 1,435개(404 1개)다.

외국 발행인은 10-Q를 내지 않아 companyfacts에 분기 매출이 구조적으로 없다. 국내 누락 375건은 매출 태그 없음 136·해당 분기 값 없음 163·무매출 76이다.
연도별 확보율은 70~76%로 고르다(특정 연도 편중 없음).

**판정 상태: 원문 기준 검정 불가(73.8% < 80%).** 진행 경로는 둘이며 운영자가 고른다.
- (가) 원문 유지 — §2는 이번 분기 검정 불가로 닫고 슬롯을 다음 분기에 다시 쓴다.
- (나) 대상 축소 개정 — T1-rev를 **국내 발행인 I1 이벤트 전용 오버레이**로 정의한다(외국 발행인은 기존 T1 그대로). 매핑 89.8%로 조건을 넘는다. 합격 기준(t ≥ 2.64·반기 같은 부호·같은 방향 연 25건 이상)은 그대로 둔다.
