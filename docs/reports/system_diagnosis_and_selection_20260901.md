### 0-2. 채택 근거가 지금 재현되는가 — 안 된다

08-01 `e9add64`의 핵심 근거는 **"모델 선별력이 day_losers에서만 유의(p=0.0000), 모델픽 +6.94% vs 단순 하락매수 −0.376%"**였다. 우위 **+7.3%p**다.

같은 비교를 현재 후보 풀(08-12~08-31, 468건)에서 재현:

```
[만기 net 기준 — 당시와 같은 측정 방식]
  모델픽(signals)      -3.05%  승률 27%
  단순 하락매수(나머지)   -2.64%  승률 33%
  → 모델 우위 -0.40%p          ← 부호 반전

[계약 net 기준 — 실제 손익]
  모델픽                -2.99%  승률 27%
  단순 하락매수           -2.29%  승률 32%
  → 모델 우위 -0.70%p

  rank1                -7.16%  승률  8%

**측정 방식 차이가 아니다.** 당시와 같은 만기 net으로 재도 −0.40%p다. 즉 *"shadow 라벨이 계약과 달라서"*가 아니라 **모델 우위 자체가 사라졌다**.

      win_rate            49.5%    ← 승률 50% 미만
      block_bootstrap_LCB -0.152%  ← 음수
```

평균 +1.357%는 소수 대박이 만든 값이다. 그리고 설계 문서의 PROBE 승격 조건이 *"positive block LCB"*인데 **top3는 처음부터 그걸 만족하지 못했다**.

같은 기간 밴드+MAX는 **+2.99%, 승률 61%**다. **모델은 자기 학습 데이터에서조차 밴드+MAX보다 못하다.**

### 4-3. 실측 — 모델은 역선별

우리 후보 풀(정렬 수정 후, 12세션):

```
rank1                    -7.16%  승률  8%
prob >= 0.55 (게이트 통과) -4.50%  승률 17%   t=-3.76
prob <  0.55 (게이트 차단) -1.53%  승률 38%
predicted_net 상위        -2.38%
predicted_net 하위        -0.79%
```

**모델이 확신할수록 더 잃는다.** 예측치와 실제의 상관:

```
계약 net    r = -0.113
만기 net    r = -0.022   ← 학습 라벨 형태와도 무상관
MFE        r = +0.170   ← 유일한 양의 상관
```

모델이 실제로 학습한 것은 수익이 아니라 **변동폭**이다. 변동성 큰 종목은 위아래로 다 크게 움직이는데, TP12가 상방을 자르고 하방은 −25%까지 열려 있어 손실만 온전히 실현된다.

### 4-4. 살리려는 시도 3가지 — 전부 실패

| 시도 | 결과 |
|---|---|
| ① 순서 반전 (밴드+MAX 먼저 → 모델 나중) | rank 상위 −4.77%, rank 하위 −5.92%. 어느 방향도 안 됨 |
| ② TP 도달 타겟으로 재학습 | 교재에서 상위20% **+5.46%**인데 우리 풀에서 **−3.56%** (전체 −2.45%보다 나쁨) |
| ③ 배제 필터로만 사용 | 모델 상위 −3.45%, 하위 −8.07%, 미선정 −3.85%. 구별력 없음 |

②가 핵심이다. **교재에서는 되고 우리 풀에서는 안 된다.** 교재는 128종목 대형주 위주, 우리 풀은 소형 급락주 포함 — 모집단 차이를 모델이 못 넘는다.
