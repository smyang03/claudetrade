# 설계 완성본 — 급락 반등 레인(Fallen-Rebound Lane) 중심 전환

2026-08-01. 운영자 결정: "충분히 떨어진 종목을 골라 멀티 슬롯으로 사서, 넓게 견디다 반등에 파는 방식을 시스템의 중심으로. Claude 실시간 판단 불필요. AXTI 같은 것을 만들어내는 구조."

이 문서는 실측(US 615건 유니버스 + 신호 70건 + KR 598~13,470건)으로 검증된 것과 안 된 것을 구분해, 완성 상태까지의 설계와 순서를 확정한다.

---

## 1. 검증된 사실 (이 설계의 근거)

### 1-1. 원시 "급락주 매수"는 어느 시장에서도 엣지가 아니다
| 시장 | 조건 | n | 건당 평균 net |
|---|---|---|---|
| US | 하락상위5, TP/SL 36조합 전부 | 615 | **−0.38 ~ −0.01 (전부 음수)** |
| US | 진입 t+1/t+2/t+3 지연 모두 | 605~615 | −0.36 ~ −0.005 (지연 무효) |
| KR | 하락상위5, TP/SL 36조합 전부 | 598 | **−0.68 ~ −2.19 (전부 음수)** |

### 1-2. 엣지는 오직 "떨어진 것 중에서 고르는 능력"이다 — 운영자 질문의 답
**"충분히 떨어진 것 중 무엇을 사야 하는가"가 관건이 맞고, 그 답은 Claude 실시간 판단이 아니라 학습된 알파 모델이다.**

- 7월 US day_losers 모집단(단순 하락상위) 평균 **−1.48%** (n=80)
- 같은 모집단에서 **알파 모델이 고른 17건 평균 +6.94%**
- 무작위 17건 추출 20,000회 중 관측치 이상 **0회 (p=0.0000)**, AXTI 제외해도 p=0.0054
- 모델 선별력은 **day_losers에서만** 유효: gainers p=0.28(차이 없음), most_actives p=0.98(**역선별**)

KR에서도 같은 구조가 재확인됐다: 12~20% 낙폭 밴드 전수 평균 +0.31(n=1,098, 승률 61.8%)인데, 같은 밴드에서 "거래대금 상위 5개"로 고르면 **−2.18**. **고르는 방법이 부호를 가른다. 선별기 없는 스크린은 배포 금지.**

### 1-3. 모델의 실체 (이식 가능성)
`tools/us_swing_shadow_runner.py` + `us_daily_alpha_walkforward.py`:
- 피처 27개 — RSI, BB, vol_ratio, MACD, MA20/60 거리, ATR, gap, 당일변동, 모멘텀 5/20/60d, 고점거리, 실현변동성, **QQQ 상대강도 5/20/60d**, SPY/QQQ/IWM 지수 모멘텀
- HistGradientBoosting 회귀+분류 × 3시드 앙상블, alpha = net랭크 50% + prob랭크 50%
- 학습데이터: `us_yahoo_point_in_time` (point-in-time, 5d net 타깃)
- **KR 이식 장애물 없음**: 지수만 KOSPI200/KOSDAQ150으로 교체하면 동일 파이프라인

### 1-4. 청산 규칙과 진입 규약 (이번에 실수로 배운 것)
- **파라미터는 진입 규약과 같은 규약에서 캘리브레이션해야 한다.** 라이브 handoff는 신호당일 개장 진입인데, t+2 진입 시뮬의 최적값(TP10/SL20)을 넣었다가 당일 규약 실측 −0.19/건으로 확인, **TP12/SL25로 원복 완료**(당일 규약 +3.14/건, n=17).
- 넓은 손절이 레인의 필수 조건: AXTI는 −18.8%를 견뎌서 +37.8%가 됐다. SL −25%가 설계값.
- 매도는 이미 작동한다: TP 지정 + 갭이 TP를 넘으면 시가 체결(gap_tp가 최대 수익원).

### 1-5. 실행 병목 — 모델 수익의 1/17만 수확 중
- micro 권한: `max_open_slots=1`, `max_new_per_day=1`, 보유 5일 → **5일에 1건**
- 슬롯 시뮬(신호 17건): 1슬롯 3건 +4.4 / 3슬롯 8건 +30.5 / 5슬롯 12건 +63.9 / 무제한 17건 +123.5
- 1슬롯에서는 어떤 건이 걸리느냐가 사실상 무작위 — AXTI가 걸린 건 행운, 모델이 그런 후보를 내는 건 실력

## 2. 목표 아키텍처

```
[후보 수집]           [선별]                [실행]                  [청산]
KIS 랭킹 API      →  알파 모델(27피처,     →  슬롯 3~5, 건당 30만  →  TP +12% 지정
day_losers 전용      GBM 앙상블) 상위 K       신호당일 개장 진입       SL −25%
(US) / 낙폭밴드                                                      최대 5거래일
8~20% (KR)                                                           갭>TP면 시가 체결
```

- **Claude의 역할**: 실시간 판단 없음. 선별은 모델, 청산은 규칙. Claude는 (선택) 뉴스/공시 거부권(veto)과 주간 회고 분석만.
- **기존 시스템과의 관계**: PathB·코어 sleeve는 유지. 신규 확장 자원은 이 레인에 집중. 중단·폐기 없음(운영자 원칙).
- 이미 라이브 반영됨: `US_SWING_ALLOWED_SOURCES=day_losers`, TP 0.12 / SL 0.25 (원복), authority micro(승격 허들 진행 중: matured 2/3, mean −1.80, PF 0.76 — day_losers 한정 forward가 쌓이면 갱신됨).

## 3. 시뮬레이션 보완점과 처방 (완성 조건)

| # | 결함 | 실측 근거 | 처방 |
|---|---|---|---|
| 1 | **진입 규약 불일치** | t+2 규약 최적값을 당일 규약 라이브에 적용 → −0.19/건 | (완료) 원복. 규율: 시뮬 리포트에 진입 규약 명시 필수, 라이브 규약과 다르면 채택 금지 |
| 2 | **유니버스 생존/선택 편향** | 백테스트 유니버스 = 시스템이 과거 관찰한 839(US)/641(KR) 종목 | KIS 랭킹 스냅샷을 매일 원본 저장 → point-in-time 유니버스 축적. 이미 있는 candidate_audit payload로 소급 가능 여부 확인 |
| 3 | **모델 검증 표본 부족** | 선별력 검증은 7월 1개월·17건뿐 | forward 축적이 유일한 해법. 승격 허들(micro→probe: sessions 15, matured 60, mean≥0.25, PF≥1.2) 유지. **허들 우회 승격 금지** |
| 4 | **체결 현실성** | 갭 시가 체결 가정(보수적), 슬리피지 미반영 | US 대형주는 무시 가능. KR 소형주(밴드 +0.31의 출처)는 슬리피지에 잠식될 수 있음 → KR은 체결가 실측 전 enforce 금지 |
| 5 | **국면 의존** | US 원시: 2월 +2.2 → 6월 −1.9. 모델 검증은 7월 한정 | 월별 forward 분해를 레인 상시 지표로. 2개월 연속 음수 시 축소(자동 아님, 운영자 보고) |
| 6 | **모델 드리프트** | walk-forward 재학습이지만 day_losers 전용 성능은 미추적 | run 리포트에 source별 forward 분해 추가(관측 항목) |
| 7 | **KR 데이터 부재** | KR엔 알파 모델·point-in-time 데이터셋 없음 | 4단계 계획(§4) |

## 4. KR 반영 계획 (검증 완료된 사실 기반)

KR 실측 요약: 원시 스크린 전부 음수. 다만 **낙폭 12~20% 밴드에 구조적 반등이 있고(전수 +0.31, 승률 61.8%, n=1,098)**, 선별 방법이 부호를 가른다. 7월엔 밴드+유동성상위도 +0.42/승률 61.7%로 양수(월별 변동 큼).

**Phase K1 — KR point-in-time 데이터셋** (코드 작업, 승인 필요)
`us_yahoo_point_in_time`과 동일 스키마의 `kr_point_in_time` 구축. 소스 pykrx(일봉·거래대금, 51/51·641 검증됨), 지수 KOSPI200/KOSDAQ150/코스피. 27피처 중 지수 3종만 교체.

**Phase K2 — KR 알파 모델 학습·shadow**
`us_swing_shadow_runner` 구조 재사용. 후보 = 낙폭 8~20% 밴드(하한가 잠김 29.7% 컷, 최소가 1,000원, 거래대금 10억+). 매일 top5 신호를 shadow 기록(주문 없음). 판정 기준: **모집단 대비 선별 리프트**(US와 동일한 무작위 추출 검정), 단순 평균 아님.

**Phase K3 — micro 진입** (운영자 승인 후)
US와 동일 권한 사다리(shadow→micro 1슬롯→probe 3). 청산 파라미터는 KR 자체 스윕으로 별도 캘리브레이션(미정 — US 값 이식 금지, §3-1 교훈).

**Phase K4 — 슬리피지 실측 게이트**
micro 체결가 vs 신호가 격차 20건 실측 후 probe 판단.

## 5. 승격·확장 로드맵 (US)

1. **지금**: micro 1슬롯 유지. day_losers 전용 forward 축적 (신호 일 ~1건 페이스, 허들 sessions 15/matured 60 → 약 3~6주)
2. **probe 승격 시**: 3슬롯/일3건 자동. 슬롯 시뮬 기준 기대 +30.5%p/3주 구간
3. **standard**: forward 40세션/150건 후. 5슬롯 — 자본 388만원 기준 상한(건당 30만 × 5 = 150만, 자본의 39%)
4. 병렬: §3-2 point-in-time 유니버스 축적, §3-6 source별 forward 분해

**운영자 결정 대기 항목**
- (A) micro 슬롯 1→3 선승격: 표본 축적이 3배 빨라지나 허들 우회 — **비권장**, 결정은 운영자
- (B) Phase K1 착수 승인 (코드 작업)
- (C) 이 레인의 자본 상한 (현 US 계좌 388만원 중 얼마까지)
