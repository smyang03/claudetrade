# 12인 토론 판정 — 손실 최소화 방향 (2026-07-04)

명제: "US net 손실을 줄이는 실행 가능한 진입/관리 레버가 남아있다(목표-부풀림 필터·zone-하단·손실측 중 ≥1이 OOS·비용 후 net 유의미 개선)." PRO vs CON 병렬 입론 + 사회자 직접 검증.

## 판정: **부분 찬성**
- **새 SELECTION 레버 = 없다 (CON 승, 재확인)**: confidence 역상관·reward_risk/reward_pct 역전·OOS 부호역전. 승자 예측 죽음.
- **새 EXECUTION(체결가 품질) 레버 = 있다 (PRO 승, 검증 통과)**: top-of-zone 추격체결 회피 = OOS-견고 손실축소.

## 방향 (데이터로 못박음)
1. **★유일 새 손실축소 레버 = 체결가 품질**: buy_zone 상단 추격체결 억제(하단 근처 요구/틸트). 기존 `PATHB_CANCEL_ABOVE_ZONE_MULTIPLIER=1.05` 강화 후보. **red-tape와 같은 방어족**(나쁜 진입조건 회피, selection 아님). 기계적 인과(높은 진입가=헤드룸↓), 같은 모집단 비교라 생존편향 캔슬.
2. **★US 전용**(측정도구가 확인): KR은 정반대(worst-cell 회피 시 −0.226 손해, KR bottom −2.81·top +0.33). red-tape와 동일 구조.
3. **흑자 아님**: 최악셀 회피해도 book −0.28(비용 아래). 흑자는 국면(우호 노출)+비용(FX, 운영자).
4. **버릴 것**: zone-하단 단독(얇음·절대부호역전)·confidence/reward_risk 필터(역상관·가성)·CLAUDE_INTRADAY_SELL(n=15·OOS불가).

## 미검증 → 다음 측정 (양날 = enforce 전 선결)
체결가 조이면 **미체결 미스(승자 놓침)**가 는다 = CLOSED로 측정불가. red-tape forward처럼 **shadow 누적으로만 확증**. 도구 `tools/zone_fill_quality_review.py`(커밋 bffdfb7)로 세션마다 추적. 판정문턱: 최악셀 ≥2월 음수 AND n≥30 AND 회피Δ≥+0.15(현재 통과) → shadow 게이트 논의, but 미체결 양날 forward 확인 후 enforce.

한 줄: 승자 고르기(죽음) 대신 **나쁜 체결가(top-of-zone 추격)를 red-tape처럼 방어**로 걷어내라 — OOS-견고 유일 새 손실축소(US전용, +0.2/거래). 흑자전환은 국면+비용 담당.
