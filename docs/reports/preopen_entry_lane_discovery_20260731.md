# PREOPEN 진입 레인 발견 (2026-07-31)

운영자 지시: "우리가 가진 종목 정보로 우리만의 키를 찾아라 / 최대 수익률 방법을 모든 수단으로 찾아내".

오늘 판정한 축들(예측력 강화·조기진입·capture tier·dud 컷)은 전부 **이미 적용됐거나 반증된** 것이었다.
반면 이것은 **한 번도 시도하지 않은 경로**다.

---

## 1. 자원 — 실거래 316건이 아니라 후보 29만행

| 소스 | 규모 |
|---|---|
| `audit_candidate_rows` | 289,778행 × 215컬럼 (2026-04~07) |
| `audit_candidate_outcomes` | 1,164,799행 (30/60/1440/2880/4320분 forward) |
| dedup 후 고유 종목-일 | **11,194건** (KR 4,184 / US 7,010) |

★ **중복 함정**: `audit_candidate_rows`는 사이클마다 행이 생겨 종목-일당 평균 13배(최대 79배) 중복된다.
dedup 없이 조인하면 자주 등장한 종목이 결과를 지배한다. **반드시 (market,ticker,session_date)로 dedup하고
가장 이른 known_at 행을 쓴다.**

★ **정렬 아티팩트**: 5분위 계산 시 `(값, net)` 튜플을 그냥 sort하면 동률 구간이 net으로 2차 정렬돼
승률이 0%/99%로 갈리는 가짜 신호가 만들어진다. `key=lambda x: x[0]`로 값만 정렬할 것.

## 2. 발견 — PREOPEN_WATCH 레인

`consensus_mode='PREOPEN_WATCH'`는 국면이 아니라 **장전 스캔 상태**다. `known_at`이 **08:52~08:54**(KR 개장 09:00 전),
`candidate_source='volume_rank'`.

### 실현 가능성 검증 (핵심)

outcome의 기준가는 08:53 **장전 예상가**라 그 가격엔 체결이 불가능하다(08:53→09:00 갭 −4.36%~+2.95%).
→ 진입가를 **09:00 실제 시가**로 바꿔 재계산했다. 08:53에 후보를 알고 09:00에 사는 것은 lookahead가 없다.

### 결과 (KR, 09:00 시가 진입, 손절 −2%, 우리 net = gross − 0.21%)

|---|---|---|---|---|---|
| PREOPEN 전체 | 1,390 | **+0.813** | +0.739 | +0.241 | **−0.834** |
| vol≥6.27 | 282 | +1.295 | +1.285 | +0.385 | −1.019 |

**세 가지가 동시에 성립한다:**
1. PREOPEN 후보 자체가 양수 — volume_ratio는 강화 요인일 뿐
2. **손절 −2%가 필수 구성요소** — 제거하면 음전
3. **단기 청산** — 30분 +0.813 → 세션마감 +0.241로 감쇠. 1440분(1일) 지평은 KR·US 전부 음수

## 4. 현재 시스템의 공백 — 배선은 절반 있고, 09:00 시가 진입만 없다

2026-07-31 실제 로그:

```
08:53:14 [preopen rank diff]   KR phase=preopen_watch records=60
08:53:15 [candidate quality]   KR phase=preopen_watch rows=80 counts={'NOT_IN_PROMPT':51,'WATCH':29}
08:53:17 [preopen watch ready] KR: watch=[29종목] trade_ready=[]
09:05:00 [preopen pin]         KR hard_tickers=[5] soft_tickers=[5]
09:06    스크리너 첫 실행
09:07    early_judge 첫 호출
```

| 시각 | 상태 |
|---|---|
| 08:53 | preopen watch 29종목 + 랭킹 데이터 생성 — **있음** |
| **09:00** | **시가 — 아무 동작 없음** ← 이 레인 |
| 09:05 | `_load_preopen_pin_candidates` (hard 5 / soft 5) — 있음 |
| 09:06~ | 스크리너·judge — 있음 |

`PREOPEN_PLANB_BRIDGE_ENABLED=true`이나 `MIN_ELAPSED_MIN=5`, `RUN_INTERVAL_MIN=5`라 **개장 5분 후부터** 돈다.
즉 데이터·랭킹·pin 배선은 이미 존재하고, **09:00 시가에 주문을 내는 경로만 없다.**

## 5. 제안 — shadow 관측부터

**08:53 PREOPEN 후보 중 volume_ratio 상위 5종목의 09:00 시가 진입을 기록만 하고, 30분 후 결과를 실측한다.**

- 리스크 0(주문 없음), 편향 없는 forward 표본이 하루 5건씩 축적
- 2주 50건 / 한 달 100건 — 실거래 316건 대비 빠른 축적
- 관측 항목: 09:00 실제 체결가, 30/60분 결과, 손절 발동 여부, 08:53→09:00 갭
- 전환 조건: 30건 이상에서 net 양수 + 월별 재현 + 갭 손실이 예측 범위 내

**전환 판단은 운영자 몫이다.** 이 문서는 근거만 정리한다.
